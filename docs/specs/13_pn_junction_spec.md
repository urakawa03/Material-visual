## 1. 学習目標

読了・操作後に、読者が次のことをできるようになる。

1. n 型と p 型を接触させると、キャリアの拡散と再結合によって**動けないイオンだけが残る空乏層**ができ、その電荷が**拡散を押し戻す向きの電場**を作ることを説明できる。
2. 熱平衡で $E_F$ が接合を貫いて一直線になることから、**$E_F$ を揃えるためにバンドが曲がる**(逆ではない)という順序で、内蔵電位 $V_{bi}$ を説明できる。
3. 空乏層の幅がドーピングでどう変わるか、とくに**濃くドープした側ほど空乏層が薄い**理由(両側の電荷が等しい必要がある)を述べられる。
4. 順バイアスが坂を下げ、乗り越えられるキャリアが**指数関数的に**増えること(室温で 0.1 V ごとに約 50 倍、1 桁あたり約 60 mV)を、I-V 特性 $J = J_0[\exp(qV/k_BT) - 1]$ と結び付けて説明できる。
5. 逆バイアスでは多数キャリアが越えられず、少数キャリアによるごくわずかな飽和電流しか流れないこと、空乏層が広がることを述べられる。
6. (発展)同じ構造が LED(再結合で光る)・太陽電池(光で電流を作る)・トンネルダイオードになること、Si が光らない理由が間接遷移であることを言える。

### 2.3 表記と慣習(記事全体の約束)

**向き**: **p 型を左($x < 0$)、n 型を右($x > 0$)**、接合面を $x = 0$ とする(標準的な教科書の向き。#12 図7 の既定と同じ)。**バイアス $V$ は p 側が正のとき正**(= 順方向)。

**単位**: 長さは μm(空乏層の読み取りだけ nm も併記)、電場は kV/cm、電位は V、エネルギーは eV、電流密度は A/cm²、密度は cm⁻³。

**モデル材料**: #12 §2.3 の `SILICON`(300 K)をそのまま使う。本記事で追加する値は `pn-junction/lib/constants.ts` に置く:

各節の要旨:

**1. くっつける** — フェルミ準位記事の最後で、$E_F$ の違う 2 つの Si をくっつけるとバンドが曲がるのを見た。その曲がった部分で何が起きているのかを、今度は粒子の目で見る。図1 で「接触させる」を押すと、右の n 型の電子と左の p 型の正孔が、**濃度差があるので**相手側へ拡散し始める。カーケンドール効果の記事で見たとおり、個々の粒子は濃度差を知らずにランダムに動いているだけだが、統計として濃い方から薄い方へ流れる。相手側に入った電子と正孔は出会って消える(再結合)。

**2. 空乏層ができる** — 消えたキャリアの跡には、**動けない**イオン化したドーパントが取り残される: p 側の接合面近くにはマイナスのアクセプタイオン、n 側にはプラスのドナーイオン。キャリアが払底したこの領域が**空乏層**である。取り残された電荷は電場を作り、その向きは**拡散を押し戻す向き**になっている(n 側のプラスから p 側のマイナスへ向かう電場は、電子を n 側へ、正孔を p 側へ押し返す)。拡散が進むほど電場が強くなり、拡散を止めにかかる。図2 で、電荷密度・電場・電位を縦に並べて、ガウスの法則(電荷のあるところで電場が変わる)でつながっていることを確かめる。

**3. つり合いと、一直線の $E_F$** — 拡散電流(濃度差が押す)とドリフト電流(電場が押し戻す)がつり合ったところで、正味の電流はゼロになる。これが熱平衡で、図1 の粒子はそこで落ち着く。このとき $E_F$ は接合を貫いて一直線になる — フェルミ準位記事 S7 の回収。**論理の順序を明確にする**: $E_F$ は平衡で一直線でなければならない。一方、p 側と n 側では $E_F$ に対するバンド端の位置が違う。両方を同時に満たすには、**バンドが曲がるしかない**(図3)。バンドが曲がるから $E_F$ が揃うのではなく、$E_F$ が揃うためにバンドが曲がる。

**4. 坂の高さ — 内蔵電位** — 曲がりの総量が内蔵電位 $V_{bi}$ で、$qV_{bi}$ は両側の「$E_F$ と $E_i$ の差」の和に等しい(式 E1)。フェルミ準位記事の図5 で読んだ値(10¹⁶ cm⁻³ で 0.355 eV)の 2 倍で約 0.71 eV になることを確かめさせる。ドーピングを変えると $V_{bi}$ は**対数的に**しか変わらないが、空乏層の幅は大きく変わる。とくに**濃くドープした側ほど空乏層が薄い** — 両側の取り残された電荷の総量が等しくないと、空乏層の外で電場がゼロにならないため(式 E2)。図2・図3 で $N_A = 10^{18}$、$N_D = 10^{15}$ にすると、空乏層のほぼ全部が n 側に広がる(p 側は 1 nm)ことを体感させる。

**5. 順バイアス — 坂を下げる** — p 側に正の電圧 $V$ をかけると、坂の高さが $q(V_{bi} - V)$ に下がる。図4 では電子と正孔がバンド端のすぐ上(下)に熱的に分布しており、**坂の上まで届くエネルギーを持つものだけが向こう側へ越えられる**。その割合は $\exp[-q(V_{bi}-V)/k_BT]$ — 坂が 1 $k_BT$ 低くなるたびに $e$ 倍になる。$k_BT$ が室温で 26 meV しかないので、**0.1 V 変えるだけで電流は約 50 倍**。0.5 V まではほとんど何も越えず、0.6 V を過ぎると急に流れ出す。この急峻さがダイオードの本質である。越えたキャリアは相手側で少数キャリアとなり、拡散しながら再結合して消える。

**6. 逆バイアス — 坂を上げる、I-V 特性** — 逆向きにかけると坂が高くなり、多数キャリアはほぼ越えられない。流れるのは、空乏層の縁にたまたまやって来た少数キャリアが坂を「転がり落ちる」ごくわずかな電流(飽和電流 $J_0$)だけで、電圧によらずほぼ一定。空乏層は広がる。順・逆をまとめると I-V 特性(式 E9)になる。図5 は**1 つのバイアスの値から、バンド図・空乏層・I-V 曲線上の動作点が同時に動く**、本記事で最も価値のある図版である。順方向では、空乏層の中で $E_F$ が電子の分と正孔の分(擬フェルミ準位)に分かれ、その差がちょうど $qV$ になる — 「$np = n_i^2$ は熱平衡でのみ」というフェルミ準位記事の但し書きがここで効く。強い逆バイアスで電流が急増する降伏(なだれ・ツェナー)は本文で触れるにとどめる。

**7. 同じ構造から生まれるもの(発展)** — pn 接合は整流だけの部品ではない。順バイアスで注入された電子と正孔が再結合するとき、ギャップに相当するエネルギーの光を出せば **LED** になる — **材料のギャップが光の色(波長)を決める**。Si は間接遷移なので光をほとんど出さない(バンド理論記事の図7)。逆に光でキャリアを作り、内蔵電場で引き離して電流にすれば**太陽電池**になる(I-V 曲線が下へずれ、電力を取り出せる象限ができる)。極端に濃くドープすると空乏層が数 nm まで薄くなり、キャリアが坂を越えずに**すり抜ける**ようになる(トンネルダイオード — [トンネル効果と STM](/articles/tunneling-stm/))。この節は読み飛ばし可能である旨を冒頭に書く。

**8. まとめ** — 静的図 S-2(平衡・順バイアス・逆バイアスの 3 つのバンド図で、坂の高さだけが変わる 1 枚絵)で振り返る。「バンドの曲がりが作る坂」で回収し、カテゴリ D(バンド → フェルミ準位 → pn 接合)が一周したことを述べる。

### 5.1 図1 `junction-formation` — くっつける(中心図版)

**表示するもの / 初期状態**
上段(高さ 62%): 横長の結晶の帯(左半分 p 型・右半分 n 型、境目に薄い縦線)。固定イオン(左 = アクセプタ「−」の輪、右 = ドナー「+」の輪、`--mat-solute`)を各 120 個、層状に並べる。その上に自由キャリア(左 = 正孔 `--mat-hole`、右 = 電子 `--mat-electron` の塗り丸)を各 120 個。**イオンの上にキャリアが重なっている間は中性**、キャリアが去ると輪だけが「むき出し」になる。
下段(高さ 38%): 2 本の細いグラフを同じ $x$ 軸で — 電荷密度 $\rho(x)$(棒グラフ、ヒストグラム 80 区間、プラス側は上・マイナス側は下)と、電場 $\mathcal{E}(x)$(曲線)。電場は上段の空乏層の位置に小さな矢印(`--color-text-2`、向きは n → p)としても描く(「電場を表示」で on/off)。
初期は**接触前**(左右の帯の間に細い隙間があり、キャリアは自分の側に閉じ込められている)、一時停止。

**操作パラメータ**

| 名前            | 部品                       | 範囲 | 初期値 | 単位 |
| --------------- | -------------------------- | ---- | ------ | ---- |
| 接触させる      | button(押すと再生も始まる) | —    | —      | —    |
| 再生 / 一時停止 | playPause                  | —    | 停止   | —    |
| 電場を表示      | toggle                     | —    | on     | —    |
| リセット        | reset(接触前に戻る)        | —    | —      | —    |

読み取り値: 再結合した対の数、むき出しのイオンの数(左右それぞれ — 常に等しい)、接合面付近($\lvert x \rvert < 0.1$)の自由キャリアの数、坂の高さ(熱エネルギーの何倍か)。

**背後のモデルと簡略化**
`lib/formation.ts` の `FormationSim`(純クラス・シード固定。位置は $-1 \le x \le 1$ の無次元):

- 運動: `_shared/carriers1d.ts` の `thermalStep`(速さの目安 0.4/秒、方向の記憶時間 0.2 秒 — #12 図4 と同じ)+ `addDrift`(電場による力。正孔は電場の向き、電子は逆向き)。両端で反射。
- 電場: 400 区間で電荷(イオン・正孔 +1、電子 −1)を数え、$\mathcal{E}(x) = A\sum_{x' < x}\rho$(1 次元のガウスの法則。左端で 0)。係数 $A = 0.24$。総電荷がゼロなので右端でも自動的に 0 になる。
- 再結合: #12 図4 と同じ規則(捕獲幅 $w = 0.01$ 以内の正孔の数 $k$ に対し確率 $1 - (1-p_c)^k$、$p_c = 0.05$)。
- 熱生成は無視する(Si では $E_g/k_BT \approx 43$ で生成は極めてまれ。#12 図4 の注記と整合)。

**試作で確認済みの振る舞い**(本仕様の作成時に同じ規則を Python で 60 秒ぶん回した結果): 約 5 秒で 17 対が再結合し、10 秒以降は 20〜23 対で**自己停止**する。接合面付近($\lvert x\rvert < 0.1$)の自由キャリアはバルク換算 22 個から 0〜3 個に減り(空乏層の形成)、坂の高さは熱エネルギーの 7〜10 倍で落ち着く。総電荷ゼロと両端の電場ゼロは全ステップで成り立った。実装の振る舞いがこれから大きく外れたら、規則の転記ミスを疑う。

**誠実な簡略化(図注に明示)**: 粒子の数・電場の強さ・時間を大きく縮めた無次元モデルで、空乏層の幅は定性的(実際の値は図2 以降)。1 次元。熱生成を無視。坂の高さは実際の Si(熱エネルギーの約 27 倍)より低い。

**実装方式**: 2D Canvas / `onFrame`。接触前と平衡後は粒子が熱運動しているだけなので、再生中は描き続ける(画面外・タブ非表示で停止)。省モーション時は自動再生せず、「接触させる」を押すと内部で 20 秒ぶん進めた平衡状態を 1 フレームで描く。

**図注(案)**: 「図1. p 型(左)と n 型(右)を接触させると、正孔と電子が相手側へ拡散し、出会って消える。跡にはドーパントのイオンが動けずに残り(輪)、その電荷が拡散を押し戻す電場を作る。押し戻しと拡散がつり合うと、接合面の付近にキャリアのいない空乏層が残る。粒子の数・電場の強さ・時間を縮めた 1 次元の模型で、空乏層の幅は定性的である。」

**alt(案)**: 「左半分に正孔、右半分に電子が詰まった横長の帯。接触させると両者が境目を越えて混ざり、出会ったものから消えていく。境目の両側には符号の付いた輪(動けないイオン)がむき出しで残り、やがて境目の付近だけキャリアのいない帯ができて落ち着く。下のグラフには境目の左にマイナス、右にプラスの電荷と、境目で最大になる電場が描かれる。」

**受け入れ基準**

- [ ] 左右のむき出しのイオンの数が常に等しい(総電荷ゼロ)
- [ ] 電場が両端でゼロ(グラフの両端が 0 に戻る)
- [ ] 20 秒後に $\lvert x \rvert < 0.1$ の自由キャリアがバルク換算の 20% 未満、再結合数が 20 秒〜40 秒で 5 以上増えない(§5.8 T6)
- [ ] `reset` で接触前・同じ乱数列に戻る
- [ ] 中位スマホで 60fps(粒子 480 個)

**背後のモデルと簡略化**
階段接合の空乏層近似(式 E2〜E5)。**簡略化(図注に明示)**: 接合は急峻(ドーピングが境目で階段状に切り替わる)、空乏層の中にキャリアは 1 個もなく外は完全に中性(実際の縁はなだらか)。

**図注(案)**: 「図2. 空乏層の電荷(上)、電場(中)、電位(下)。取り残されたイオンの電荷は左右で総量が等しく、電場は接合面で最大の三角形になり、その面積が内蔵電位 $V_{bi}$ になる。濃くドープした側ほど空乏層は薄い。空乏層の中は完全にキャリアがない、とする近似で描いた。」

**alt(案)**: 「縦に 3 段のグラフ。上段は接合面の左にマイナス、右にプラスの長方形で、面積が等しい。中段は接合面で最大になる三角形の電場。下段は左から右へ滑らかに上がる電位で、全体の高さが内蔵電位。片側のドーピングを濃くすると、その側の長方形が高く細くなり、反対側に空乏層の大部分が広がる。」

### 5.4 図4 `forward-bias` — 坂を越える

**表示するもの / 初期状態**
バンド図(図3 と同じ描き方、$E_F$ の代わりに p 側・n 側の擬フェルミ準位を中性領域だけに短く描く)。n 側の中性領域の伝導帯の底のすぐ上に電子の丸が熱的に分布し、p 側の価電子帯の頂上のすぐ下に正孔の丸が分布する(**縦位置 = そのキャリアのエネルギー**)。キャリアは横に動き、坂に当たると**エネルギーが坂の高さより大きいものだけ**が越えて向こう側へ進み(越えたキャリアは同じ高さのまま進む — エネルギー保存)、相手側でしばらく進んだのちランダムな時刻に消える(少数キャリアの再結合)。越えられないものは跳ね返る。
右上に「1 秒あたりに越えた数」のカウンタと、小さな片対数グラフ(横軸 $V$、縦軸 越えた数 / 秒)— 理論曲線 $\propto \exp(qV/k_BT)$ を常時表示し、現在の測定値を点で重ねる。
初期は $V = 0$(何も越えない)。

**操作パラメータ**

| 名前            | 部品      | 範囲                | 初期値 | 単位 |
| --------------- | --------- | ------------------- | ------ | ---- |
| バイアス $V$    | slider    | 0〜0.65(step 0.005) | 0      | V    |
| 再生 / 一時停止 | playPause | —                   | 再生   | —    |
| リセット        | reset     | —                   | —      | —    |

読み取り値: 坂の高さ $q(V_{bi} - V)$ [eV] と熱エネルギーの何倍か、越える割合の理論値 $\exp[-q(V_{bi}-V)/k_BT]$、越えた数 / 秒(直近 5 秒の平均)。

**背後のモデルと簡略化**
`lib/barrier.ts` の `BarrierSim`(シード固定):

- 各側 300 個のキャリア。横方向は `thermalStep`、中性領域の端でキャリアが坂に当たったら判定する。
- **坂に当たるキャリアのエネルギーを指数分布(平均 $k_BT$)から引く**。1 次元で面を横切る粒子のエネルギー分布(流束で重み付けしたもの)はちょうど指数分布になるので、越える割合は厳密に $\exp(-B/k_BT)$($B$ = 坂の高さ)になる(§5.8 T7)。
- 画面上の縦位置はそのエネルギーで描く。エネルギーは**実際の eV のスケール**(拡大しない)。室温の $k_BT$ は 0.026 eV なので、キャリアはバンド端のすぐ上に薄く溜まって見え、坂の上まで届く粒子が稀であることがそのまま見える。
- 越えたキャリアは相手側で寿命(平均 1.2 秒の指数分布)ののち消え、同数を自分の側の外端から補給する(電極からの供給)。
- 坂の高さは図3 と同じ `junction.ts` から。

**誠実な簡略化(図注に明示)**: 越える過程を「坂を飛び越える」形(熱電子放出)で描いている。実際の Si ダイオードの電流は、越えたあとの少数キャリアの拡散で決まる(式 E10)が、**電圧への指数関数の依存は同じ**である。1 次元・時間は加速・粒子数は縮めている。

**実装方式**: 2D Canvas / `onFrame`。省モーション時は自動再生せず、各 $V$ での静止フレーム(粒子の分布 + 理論の割合)を表示。

**図注(案)**: 「図4. 電子(右)と正孔(左)は熱でバンド端の近くに分布し、坂の高さを超えるエネルギーを持つものだけが向こう側へ越えられる。順バイアスで坂が低くなると、越えられる割合は指数関数的に増える。0.5 V まではほとんど越えないが、0.6 V を過ぎると急に流れ出す。越える過程を坂を飛び越える形で描いた簡略模型で、時間は加速している。」

**alt(案)**: 「曲がったバンド図の右側の伝導帯の底に電子の点が薄く集まり、左側の価電子帯の頂上に正孔の点が集まっている。バイアスを上げると坂が低くなり、坂を越えて向こう側へ渡る点が急に増える。右上のグラフでは、越えた数の測定点が指数関数の理論曲線に乗る。」

**受け入れ基準**

- [ ] $V = 0$ では 1 分間回しても越える粒子がほぼない(理論的な割合は $10^{-12}$)
- [ ] $V = 0.55, 0.60, 0.65$ V で越えた数 / 秒の比が理論($\approx 6.9$ 倍ずつ)と 25% 以内(§5.8 T7 で決定的に担保)
- [ ] キャリアの縦位置が実際の eV スケールで描かれている(拡大していない)
- [ ] 粒子の総数が補給により一定に保たれる

### 5.5 図5 `bias-and-iv` — バイアス 1 つで、全部が動く

初期は $V = 0$、$N_A = N_D = 10^{16}$、線形軸。

**操作パラメータ**

| 名前             | 部品                   | 範囲                   | 初期値    | 単位 |
| ---------------- | ---------------------- | ---------------------- | --------- | ---- |
| バイアス $V$     | slider                 | −5.0〜+0.65(step 0.01) | 0         | V    |
| 電流の軸         | segmented: 線形 / 対数 | —                      | 線形      | —    |
| ドーピング(両側) | slider(対数)           | $10^{15}$〜$10^{18}$   | $10^{16}$ | cm⁻³ |
| リセット         | reset                  | —                      | —         | —    |

読み取り値: $V$、坂の高さ [eV]、$W$ [μm]、$J$ [A/cm²]、区分(順方向 / 逆方向 / ゼロ)、(順方向のとき)$E_{Fn} - E_{Fp}$ [eV]。

**背後のモデルと簡略化**
**1 つのバイアス状態 $V$ から、バンド図・空乏層・動作点を同時に更新する**(3 つを別々のウィジェットにしない — 本図の存在理由)。I-V は理想ダイオード式(式 E9・E10)。順方向は $V_{bi}$ に近づくと空乏層近似が成り立たなくなり、実際には直列抵抗も効くので、**+0.65 V で打ち切る**(図注で明示)。降伏は描かない(本文で触れる)。擬フェルミ準位の差 $= qV$ は `quasiFermiSplit` と整合する。

**実装方式**: 2D Canvas / `requestRender`。

**図注(案)**: 「図5. バイアスを 1 つ動かすと、バンドの坂・空乏層の幅・I-V 曲線上の動作点が同時に動く。順方向では空乏層の中で電子と正孔の擬フェルミ準位が分かれ、その差がちょうど $qV$ になる。逆方向では坂が高くなって空乏層が広がり、ごくわずかな飽和電流しか流れない。理想ダイオードの模型で、$V_{bi}$ に近い強い順方向と降伏は描いていない。」

**alt(案)**: 「左にバンド図、右に電流と電圧のグラフ。電圧を順方向に上げると、左では坂が低くなり、空乏層が狭くなり、電子と正孔のフェルミ準位が分かれる。右では動作点が曲線に沿って右上へ移り、0.6 V 付近から電流が急に立ち上がる。逆方向では坂が高くなり空乏層が広がり、電流はほぼゼロのまま。対数軸にすると、逆方向の小さな一定の電流と、順方向の直線的な立ち上がりが見える。」

**受け入れ基準**

- [ ] $V = 0$ で $J = 0$、擬フェルミ準位が 1 本に重なる
- [ ] 対数軸で順方向の傾きが「1 桁あたり 59.5 mV」(300 K。読み取り値から確認)
- [ ] 逆方向で $J \to -J_0$($-1.76\times10^{-11}$ A/cm²)に飽和する
- [ ] $W$ が $\sqrt{V_{bi} - V}$ に比例する(−5 V で 1.215 μm、+0.5 V で 0.233 μm)
- [ ] 順方向で $E_{Fn} - E_{Fp} = qV$(表示桁で一致)
- [ ] 3 つの表示(バンド図・空乏層・動作点)が同一フレームで更新される

### 5.6 図6 `led-solar` — 同じ構造から生まれるもの(発展)

**表示するもの / 初期状態**
モード切り替えの 2 画面。

- **LED**: 順バイアスのバンド図。空乏層の付近で電子が正孔の高さへ縦に落ち(再結合)、そのとき直接遷移の材料なら**光子**(`--mat-beam` の短い波線の矢印)が外へ飛ぶ。間接遷移の Si では、落ちても光子はほとんど出ず(10 回に 1 回未満の表示上の目安)、代わりに格子の振動(小さな「〜」の記号、`--color-text-2`)が出る。下端に**波長の目盛り**(灰色の帯に 300〜1200 nm、可視域 380〜780 nm を括弧で示す)と、発光波長の位置に `--mat-beam` の印。**虹色の帯は使わない**(母体仕様 §2-7・意味パレットの原則)。
- **太陽電池**: 光子が空乏層に入って電子・正孔の対を作り、内蔵電場で電子は n 側へ、正孔は p 側へ引き離される。右に I-V 曲線(光あり / なし)を重ね、光ありの曲線が下へずれて**電力を取り出せる象限**ができることを薄い塗りで示す。動作点を曲線上でドラッグでき、そのときの電力 $|JV|$ を読み取りに出す。

初期は LED、材料 GaAs、バイアス 0.6 V 相当。

**操作パラメータ**

| 名前                   | 部品                                 | 範囲            | 初期値     | 単位 |
| ---------------------- | ------------------------------------ | --------------- | ---------- | ---- |
| モード                 | segmented: LED / 太陽電池            | —               | LED        | —    |
| 材料(LED のみ)         | segmented: Si / GaAs / InGaN         | —               | GaAs       | —    |
| 光の強さ(太陽電池のみ) | slider                               | 0〜1(step 0.05) | 1          | 太陽 |
| 動作点(太陽電池のみ)   | 曲線上のドラッグ点(キーボードは矢印) | 0〜$V_{oc}$     | 最大電力点 | V    |
| 再生 / 一時停止        | playPause                            | —               | 再生       | —    |
| リセット               | reset                                | —               | —          | —    |

読み取り値: LED — $E_g$ [eV]、発光波長 [nm]、遷移の型(直接 / 間接)、「光る割合」の目安。太陽電池 — 短絡電流 $J_{sc}$ [mA/cm²]、開放電圧 $V_{oc}$ [V]、動作点の電力 [mW/cm²]。

**背後のモデルと簡略化**
LED の材料: Si($E_g$ = 1.12 eV、間接、1107 nm)、GaAs(1.42 eV、直接、873 nm、赤外)、InGaN(2.7 eV、直接、約 460 nm、青 — 組成で変わる代表値として図注に明記)。波長は式 E12。「光る割合」は表示上の目安(直接 ≫ 間接)であり、内部量子効率の計算ではないことを図注に明示する。太陽電池は $J = J_0[\exp(qV/k_BT) - 1] - J_L$(式 E13、$J_L$ は光の強さに比例、1 太陽で 35 mA/cm²)。この理想模型の $V_{oc}$ は約 0.55 V で、実際の Si 太陽電池(0.6〜0.7 V)より低い(図注に明示 — $J_0$ を小さくする工夫を省いているため)。

**実装方式**: 2D Canvas / `onFrame`(光子・キャリアの粒子)。I-V の描画とドラッグは `requestRender` と同じ扱いで、粒子の更新とは独立。

**図注(案)**: 「図6. 左: LED。注入された電子と正孔が再結合するとき、直接遷移の材料はギャップに相当する波長の光を出す。Si は間接遷移なので、ほとんど光らずに格子の振動として熱を出す。右: 太陽電池。光が作った電子と正孔を内蔵電場が引き離し、電流を取り出す。I-V 曲線が下へずれた分が取り出せる電力になる。光る割合は表示上の目安、太陽電池は理想模型である。」

**alt(案)**: 「LED モードでは、接合面の付近で電子が正孔の高さへ落ちるたびに光の矢印が外へ飛び、下の波長の目盛りに発光波長の印が付く。Si に切り替えると光の矢印はほとんど出なくなる。太陽電池モードでは、光が入って生まれた電子と正孔が左右に引き離され、右のグラフの曲線が下へずれて電力を取り出せる領域ができる。」

**受け入れ基準**

- [ ] 波長の読み取りが $1239.84/E_g$ と一致(Si 1107 nm・GaAs 873 nm)
- [ ] Si では光子がほとんど出ず、GaAs・InGaN では毎回出る
- [ ] $J(V_{oc}) = 0$、$J(0) = -J_L$(§5.8 T8)
- [ ] 動作点のドラッグで電力の読み取りが変わり、最大電力点で極大になる
- [ ] 虹色の表現がどこにもない(波長は数値と灰色の目盛りのみ)
