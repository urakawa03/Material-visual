## 0. 叩き台からの変更点と、その理由

プロンプト 08 からの主な変更は 1 点で、**既存 2 記事との整合のため**である。

**「消滅則は格子ではなく基底の性質」という断定をやめる。** プロンプトは「BCC を単純立方格子 + 2 原子基底と見るのが正しく、この記事の主張そのもの」としていたが、実装済みの逆格子空間記事(05)は、体心・面心立方の「現れない点」を**基本並進ベクトルから作った逆格子(格子の言葉)**で説明済みである(05 §5.7、記事本文の図7)。単原子の BCC は「BCC 格子 + 1 原子」とも「単純立方格子 + 2 原子の基底」とも記述でき、**どちらも正しい同じ事実の 2 つの見方**であって、一方を誤りとすると 05 と矛盾する。

本記事はこう組み直す:

1. 05 で見た「現れない点」を、**慣用単位胞 + 基底(構造因子の言葉)**で説明し直し、**格子の言葉と同じ答えになる**ことを確かめる(S3〜S4)。これは 05 本文の「系統的消滅として再登場します(仕組みの説明は回折の記事に)」と、エヴァルト球記事末尾の「構造因子は前の記事の『現れない点』の正体でもある」の両方の予告を回収する。
2. そのうえで、**格子の言葉では説明できない消滅**を見せる: ダイヤモンド構造(Si)は格子としては面心立方なのに、(200)・(222) が消える(S1 の謎・S4 の山場)。また CsCl や規則化した合金のように、**消えるのではなく弱まる**反射もある(S5・S7)。構造因子の言葉はこれらを統一的に扱える — これが本記事の主張である。

その他の変更: 図7 を CuZn だけでなく **Cu₃Au との比較**にした(CuZn は Cu と Zn の電子数がほぼ等しく、X 線では規則化の反射がほぼ見えない。この「見えなさ」自体を S5 の原子散乱因子・中性子と結び付ける)。

## 1. 学習目標

読了・操作後に、読者が次のことをできるようになる。

1. 構造因子 $F_{hkl} = \sum_j f_j\,e^{2\pi i(hx_j + ky_j + lz_j)}$ を、**単位胞の中の各原子が出す波の矢(長さ $f_j$、向き = 位相)を継ぎ足した和**として説明できる(逆格子空間記事の「矢の足し合わせ」の続き)。
2. 体心立方・面心立方の消滅則を、慣用単位胞 + 基底の構造因子から 2 行で導け、それが逆格子空間記事の「格子の言葉」での説明と**同じ答え**になることを言える。
3. ダイヤモンド構造で、格子(面心立方)としては許される (200)・(222) が消える理由を構造因子で説明できる。
4. 原子散乱因子 $f$ が電子数にほぼ比例し、散乱角とともに減ることから、**軽元素が X 線で見えにくい理由**と、中性子回折では事情が違うことを述べられる。
5. 粉末回折図形の強度が $|F|^2$・多重度・ローレンツ偏光因子の積で決まることを、図を組み立てながら説明できる。
6. (発展)規則化で**超格子反射**が現れること、その強さが $\eta^2(f_A - f_B)^2$ に比例するため CuZn は X 線では見えにくく Cu₃Au でははっきり見えることを説明できる。

### 2.3 表記と慣習(記事全体の約束)

**結晶学の慣習**(05・04 と同一。ここがずれると 3 記事がつながらない):

- 波は $|\mathbf{k}| = 1/\lambda$、逆格子ベクトルは $|\mathbf{g}_{hkl}| = 1/d_{hkl}$。$2\pi$ は付けない。
- 構造因子の位相は分率座標 $(x_j, y_j, z_j)$ を使って $2\pi(hx_j + ky_j + lz_j)$。**この $2\pi$ は慣習によらず付く**(分率座標を角度に直すための $2\pi$ であって、波数の定義の $2\pi$ ではない)。05 の式 E2・E4 の $e^{2\pi i\,\mathbf{q}\cdot\mathbf{r}_j}$ と同じ形であることを本文で指摘する。
- 散乱角の量は $s = \sin\theta/\lambda = 1/(2d)$ [nm⁻¹]。原子散乱因子の表(Å⁻¹ で書かれることが多い)は内部で nm⁻¹ に換算する。

**単位**: 長さは nm、角度は度、X 線の波長は Cu Kα の 0.15406 nm を既定とする(エヴァルト球記事の波長範囲 0.1〜0.3 nm に含まれる)。

**モデル物質**(`lib/structures.ts` に分率座標と格子定数を 1 箇所だけ置く):

各節の要旨:

**1. 欠けている線(導入・謎)** — エヴァルト球の記事で、粉末にした結晶は同心円(デバイ・シェラー環)を作り、その半径は面間隔で決まることを見た。図1 で、同じ X 線で測った Fe(体心立方)・Cu(面心立方)・Si(ダイヤモンド)の粉末回折図形を並べる。体心立方と面心立方の欠けた線は、逆格子空間記事の「現れない点」として説明済みである(読者は覚えているはず)。ところが **Si では、面心立方として許されるはずの (200) と (222) まで欠けている**。Si の格子は面心立方なのに、である。格子の言葉では説明できないこの欠けを、記事の問いとして立てる。

**2. 格子点には何が置いてあるか** — 逆格子空間記事で「結晶 = 格子 + 基底」と学んだ。ここで単位胞の中を見る。体心立方の Fe は「立方体の角 + 体の中心」、面心立方の Cu は「角 + 各面の中心」の原子をもつ慣用単位胞で描ける。そして Si(ダイヤモンド構造)は、面心立方の各点に **2 個 1 組の原子**(もう 1 個は体対角線の 1/4 だけずれた位置)が置かれている — 格子は面心立方、基底が 2 原子。図2 の 3D で単位胞を回し、各原子の分率座標 $(x, y, z)$ を読み取らせる。**体心立方を「単純立方の格子 + 2 原子の基底」と見ることもできる**(角と体心を 1 組とみなす)ことを示し、次節の伏線にする。

**3. 散乱波を足し合わせる — 構造因子(中心図版)** — 逆格子空間記事の図2 で、「各原子の位置での縞の位相を単位円上の矢として足し合わせた長さ」を見た。同じことを単位胞の中の原子だけで行い、**矢の長さを原子ごとの散乱の強さ $f_j$ にする**と構造因子になる(式 E1)。$(hkl)$ の反射では、原子 $j$ の矢は $2\pi(hx_j + ky_j + lz_j)$ の向きを向く。図3 で原子の矢を頭と尾でつないでいくと、終点が $F_{hkl}$ になる。$(hkl)$ を変えると矢の向きが変わり、**ぴったり閉じた多角形になって和がゼロになる組み合わせ**がある — これが消滅の正体である。強度は矢の長さの 2 乗 $|F|^2$ に比例する(式 E2)。

**4. 消滅則を自分で見つける** — 図4 で、逆格子の 1 枚の層($l$ 一定の面)の点を、$|F|^2$ に比例した大きさで描く — **逆格子に明るさの重みが付いた地図**である。読者に層と構造を切り替えさせ、表を埋めるように規則を見つけさせる(「測定 → 法則の発見」: フランク・リード源 図6、カーケンドール 図5 と同じ設計)。見つけてから式で 2 行で確かめる($e^{i\pi n} = (-1)^n$):

- 体心立方: $h + k + l$ が奇数のとき $F = 0$
- 面心立方: $h, k, l$ の偶奇がそろわないとき $F = 0$
- **ダイヤモンド**: 面心立方の規則に加えて、**すべて偶数でも $h + k + l = 4n + 2$ のとき $F = 0$**((200)・(222)・(420)…)

体心・面心の規則は、逆格子空間記事で基本並進ベクトルから導いた存在則と**完全に一致する**ことを確認させる(図4 で「格子の言葉の答え」を重ねて比べる)。2 つの見方は同じ事実の言い換えだった。しかしダイヤモンドの追加の消滅は、格子(面心立方)の言葉からは出てこない — **基底の 2 原子がちょうど打ち消し合う**ことでしか説明できない。S1 の謎はここで解ける。

**5. 原子ごとの散乱能 — 原子散乱因子** — ここまで $f_j$ を「原子ごとの矢の長さ」としてきた。X 線は電子に散乱されるので、$f$ はおよそ**電子の数**で、散乱角 0 では原子番号 $Z$ に等しい。角度が大きくなると、原子の中の電子雲の各部分からの散乱波の位相がずれて打ち消し合い、$f$ は減る(電子雲の広がりが波長と同じくらいだから)。図5 で元素ごとの $f(s)$ を比べると、**水素のような軽元素は X 線でほとんど見えない**ことがわかる。中性子は原子核に散乱されるので、散乱の強さ(散乱長 $b$)は原子番号と無関係にばらばらで、水素(重水素)も見える。この違いが S7 で効く。KCl では K⁺ と Cl⁻ がどちらも 18 電子なので X 線ではほぼ同じ原子に見え、NaCl 型なのに奇数指数の反射がほぼ消える、という実例にも一言触れる。

**6. 回折図形を組み立てる** — 粉末回折の強度は、$|F_{hkl}|^2$(構造)× 多重度 $m$(同じ面間隔の面の数)× ローレンツ偏光因子 $L_p(\theta)$(測定の幾何)で決まる(式 E5)。図6 で 3 つの因子を 1 つずつオンにしながら図形が組み上がるのを見せ、S1 の Si の図形が完全に再現されることを確かめる — 謎の回収。現実の Si では、結合の電子が原子のまわりに球対称でないため、「禁制」の (222) がごく弱く観測される(図注の但し書き — 母体仕様 §2-5)。

**7. 消えていた反射が現れるとき — 超格子反射(発展)** — CuZn(β 黄銅)は、高温では Cu と Zn がランダムに座る(どのサイトも平均すると同じ原子 → 体心立方 → $h + k + l$ 奇数は消える)。低温で規則化すると、Cu と Zn が別々のサイトを占めて基底が変わり(CsCl 型)、**消えていたはずの (100) が現れる**(超格子反射)。その強さは規則度 $\eta$ の 2 乗と $(f_\text{Cu} - f_\text{Zn})^2$ に比例する(式 E6)。ところが Cu(29 電子)と Zn(30 電子)は X 線にはほとんど同じに見えるので、**CuZn の超格子反射は X 線ではほぼ見えない**(基本反射の 1/3000)。中性子(散乱長 7.7 fm と 5.7 fm)なら見える(2%)。一方 Cu₃Au(Au は 79 電子)では X 線ではっきり見える(9%)が、中性子では Au と Cu の散乱長がほぼ等しいので逆にほとんど見えない。図7 で規則度を動かし、反射が $\eta^2$ で育つ様子と、2 つの合金・2 つの放射線で見え方が逆転することを確かめる — **どちらの放射線で見るかは、何と何を区別したいかで決まる**。原子が並べ替わるのは拡散によるので、カテゴリ C への橋として一言触れる。この節は読み飛ばし可能である旨を冒頭に書く。

**8. まとめ** — 「格子が場所を決め、基底が明暗を決める」で回収。静的図 S-2 で、逆格子(05)→ エヴァルト球(04)→ 構造因子(本記事)の 3 枚をつないで、カテゴリ A が一周したことを示す。

| リセット             | reset                                       | —                      | —       | —    |

読み取り値: 強い順に 6 本の $(hkl)$・$2\theta$・相対強度、選んだ線の 3 因子の値。

**背後のモデルと簡略化**
$I \propto |F_{hkl}(s)|^2 \cdot m \cdot L_p(\theta)$、$L_p = (1 + \cos^2 2\theta)/(\sin^2\theta\cos\theta)$(式 E5)。熱振動・吸収・試料の配向(粉末が完全にランダムでないこと)は入れていない。**現実の Si では (222) がごく弱く観測される**(結合の電子の分布が球対称でないため。「禁制反射」)ことを図注で但し書きする。KCl は K⁺ と Cl⁻ が同じ電子数のため奇数指数の線がほぼ消える実例として入れる(イオンの $f$ を中性原子で代用しているので、図では K と Cl の差が少し残る — 図注で明示)。

**実装方式**: 2D Canvas / `requestRender`。

**図注(案)**: 「図6. 粉末回折の強度は、構造(構造因子の 2 乗)、多重度(同じ面間隔の面の数)、測定の幾何(ローレンツ偏光因子)の積で決まる。3 つを順に入れると図形が組み上がる。熱振動・吸収は入れていない。実際の Si では、結合の電子の偏りのため『消えるはず』の (222) がごく弱く見える。」

**alt(案)**: 「最初はすべての線が同じ高さで並ぶ。構造を入れると Si の (200) と (222) の線が消え、多重度を入れると (220) などが伸び、測定の幾何を入れると低角側の線が強くなって、実際の図形に近づく。」

**受け入れ基準**

- [ ] 線の位置が図1 と同じ計算で一致し、$\lambda$ を変えると全線が連動して動く
- [ ] 多重度が立方晶の値と一致({100} 6、{110} 12、{111} 8、{210} 24、{211} 24、{220} 12、{311} 24、{222} 8)(§5.8 T7)
- [ ] 因子を 1 つずつ有効にすると、強度がその因子の比で変わる
- [ ] Cu で (111) が最強線になる

### 5.7 図7 `superlattice` — 消えていた反射が現れるとき(発展)

**表示するもの / 初期状態**
左(幅 40%): 2 種類の原子の配置の絵(2 次元の断面、8×8 サイト)。規則度 $\eta$ に応じて、各サイトの原子をシード固定の乱数で決める($\eta = 0$ で完全にランダム、$\eta = 1$ で完全な規則配列)。
右(幅 60%): 粉末図形。基本反射(`--mat-recip`)と**超格子反射**(同色・中抜きの山 → $\eta$ とともに塗りが濃くなる)。超格子反射の高さを読みやすくするため、**縦軸の拡大**(×1・×10・×100・×1000)を segmented で選ぶ(倍率は常に表示)。
初期は CuZn、X 線、$\eta = 0$、拡大 ×1(→ $\eta$ を 1 にしても超格子反射が見えない、という体験から始める)。

**操作パラメータ**

| 名前          | 部品                               | 範囲            | 初期値 | 単位 |
| ------------- | ---------------------------------- | --------------- | ------ | ---- |
| 合金          | segmented: CuZn / Cu₃Au            | —               | CuZn   | —    |
| 規則度 $\eta$ | slider                             | 0〜1(step 0.01) | 0      | —    |
| 放射線        | segmented: X 線 / 中性子           | —               | X 線   | —    |
| 縦軸の拡大    | segmented: ×1 / ×10 / ×100 / ×1000 | —               | ×1     | —    |
| リセット      | reset                              | —               | —      | —    |

読み取り値: 最も強い超格子反射の $(hkl)$ と、最も強い基本反射に対する相対強度、$(f_A - f_B)^2/(f_A + f_B)^2$ の値(放射線ごと)。

**背後のモデルと簡略化**
占有率つきの構造因子: サイト $\alpha$ の平均の散乱能 $\bar{f}_\alpha = p_{\alpha A} f_A + p_{\alpha B} f_B$、占有率は $\eta$ で線形に決める(CuZn: $p = (1 \pm \eta)/2$、Cu₃Au: L1₂ の 4 サイトについて同様)。超格子反射の $F$ は $\eta(f_A - f_B)$ に比例し、強度は $\eta^2$ に比例する(式 E6)。本仕様の作成時の計算値($s = 0$、超格子 / 基本の強度比):

| 合金  | X 線                             | 中性子                         |
| ----- | -------------------------------- | ------------------------------ |
| CuZn  | $2.9\times10^{-4}$(ほぼ見えない) | 0.023(見える)                  |
| Cu₃Au | 0.091(はっきり見える)            | $8\times10^{-6}$(ほぼ見えない) |

**X 線と中性子で見え方が逆転する**(Au と Cu は電子数は大きく違うが、中性子の散乱長は 7.63 fm と 7.72 fm でほぼ等しい)。「どちらの放射線で見るかは、何と何を区別したいかで決まる」 — 本文 S7 の締めの一文にする。**規則度と温度の関係(秩序-無秩序転移)は扱わない**($\eta$ を直接動かす — 図注に明示)。左の絵は占有率に従うランダムな配置の 1 例であって、長距離秩序の厳密な表現ではない。

**実装方式**: 2D Canvas / `requestRender`。

**図注(案)**: 「図7. CuZn や Cu₃Au は、高温では 2 種類の原子がランダムに座り、低温で規則的に並ぶ。規則化すると基底が変わり、消えていた反射(超格子反射)が規則度の 2 乗に比例して現れる。その強さは 2 種類の原子の散乱能の差で決まるので、Cu と Zn がほぼ同じに見える X 線では CuZn の超格子反射はほとんど見えず、中性子や、Au を含む Cu₃Au でははっきり見える。規則度は温度と結び付けずに直接動かしている。」

**alt(案)**: 「左に 2 色の原子が並んだ格子、右に回折図形。規則度を上げると左の配置が市松模様にそろっていき、右では新しい小さな山が育つ。CuZn と X 線の組み合わせでは、縦軸を 1000 倍に拡大しないと新しい山が見えない。中性子に切り替えるか Cu₃Au を選ぶと、拡大しなくても見える。」

**受け入れ基準**

- [ ] $\eta = 0$ で超格子反射の強度がちょうど 0、$\eta^2$ に比例して育つ(§5.8 T8)
- [ ] 上の表の 4 つの比が表示桁で一致し、X 線と中性子で見え方が逆転する
- [ ] 縦軸の拡大倍率が常に表示され、倍率を変えても読み取りの相対強度は変わらない
- [ ] `reset` で同じ配置の絵に戻る
