## 0. 叩き台からの変更点と、その理由

依頼書(`docs/prompts/04_ewald_sphere_prompt.md`)§3 の叩き台に対して、本仕様書では次の 3 点を変更した。いずれも「物理的な正しさ」と「前提記事との一貫性」を優先した結果である。

1. **$2\pi$ を付けない(結晶学の慣習を採用する)。** 叩き台は $|\mathbf{k}| = 2\pi/\lambda$、$\Delta\mathbf{k} = \mathbf{G}_{hkl}$、球の半径 $2\pi/\lambda$ で書かれているが、前提記事「逆格子空間」は仕様書 05 §2.3・付録 A-1 で**結晶学の慣習**($\mathbf{a}_i\cdot\mathbf{b}_j = \delta_{ij}$、$|\mathbf{g}_{hkl}| = 1/d_{hkl}$、$q = 1/\lambda$)を採用し、記事末尾で $\mathbf{k}' - \mathbf{k} = \mathbf{g}$($|\mathbf{k}| = 1/\lambda$)と予告済みである。依頼書 §4 の「$2\pi$ の有無は逆格子空間の記事と必ず一致させる」に従い、**本記事は全編を通じて $|\mathbf{k}| = 1/\lambda$、球の半径 $1/\lambda$、限界球の半径 $2/\lambda$** で書く。物理学の慣習($\mathbf{G} = 2\pi\mathbf{g}$、半径 $2\pi/\lambda$)は S3 のコラムで 1 回だけ対応を示す。
2. **「逆格子点は少し広がっている」を図注の一言ではなく、図3 の操作パラメータにした。** 依頼書 §4 は形状因子(shape factor)への言及を求めているが、S3 の中心図版で「厳密に球面に乗る点は原理的に存在しない」という壁に読者が最初にぶつかる以上、そこで**結晶の厚さ $t$ を触らせて、許容幅 $|s| \lesssim 1/t$ が広がる/狭まるのを見せる**のがいちばん誠実で、かつ体感が残る。S4 の図注でも再度明示する。
3. **図6(粉末法)を「3D + 2D」ではなく「3D 2 ビューポート」で実装する。** 母体仕様 §8.1 は 1 図版 = 1 canvas であり、WebGL canvas に 2D の検出器像を重ねるには canvas を 2 枚にするか描画系を混在させる必要がある。`_shared3d.ts` の scissor による 2 ビューポート機構をそのまま使い、**第 2 ビューポートを「検出器を正面から見た固定カメラのシーン」**とすることで、既存基盤の再利用だけで「逆空間の作図」と「検出器上の環」を並べられる。このために `_shared3d.ts` へ「ビューごとにカメラ連動を切る」拡張を入れる(§5.0・付録 A-2)。

節構成・図版の枚数・各図版の狙いは叩き台のとおりである。

## 1. 学習目標

読了・操作後に、読者が次のことをできるようになる。

1. ブラッグ則 $2d\sin\theta = \lambda$ とラウエ条件 $\Delta\mathbf{k} = \mathbf{g}$ が**同じ条件の言い換え**であることを、$|\mathbf{g}| = 1/d$ を橋渡しにして自分で示せる。
2. 弾性散乱では $|\mathbf{k}'| = |\mathbf{k}| = 1/\lambda$ であることから、散乱ベクトル $\Delta\mathbf{k}$ の先端が**球面上にしか来られない**ことを説明でき、それがエヴァルト球の正体だと言える。
3. 逆格子の原点 O から $-\mathbf{k}$ だけ戻った点を中心とする半径 $1/\lambda$ の球を描き、**球面に乗った逆格子点だけが回折する**という作図規則を、自分で紙に描ける。
4. 「静止した単結晶では、ふつう何も光らない」ことを理解し、回転結晶法・ラウエ法(白色 X 線)・粉末法が、それぞれ**どの自由度を振ることで条件を満たしにいく方法か**を区別できる。
5. 電子線の波長が極端に短いために球面が逆格子面に対してほぼ平面となり、TEM の回折図形が逆格子の断面図に見える理由を、$1/\lambda$ の大小で説明できる。

## 2. 前提知識と関連記事

### 2.1 前提知識

- **仮定するもの**: 逆格子(reciprocal lattice)・逆格子ベクトル $\mathbf{g}_{hkl}$・面間隔 $d_{hkl} = 1/|\mathbf{g}_{hkl}|$・ミラー指数。いずれも前提記事「逆格子空間」で扱った範囲。ベクトルの和・差と内積。
- **記事内で復習するもの**: 波長と空間周波数の関係($|\mathbf{k}| = 1/\lambda$)は S2 の冒頭で 1 段落。ブラッグ則は S1 で「見たことがある式」として再導入し、導出は行わない(光路差 $2d\sin\theta$ の図で済ませる)。
- **仮定しないもの**: 構造因子・回折強度・消衰・装置構成。本記事は**幾何条件だけ**を扱い、「どれが光りうるか」に答える。「どれくらい強く光るか」は扱わないことを S1 の末尾と各図注で明示する。

各節の要旨:

**1. 同じ条件を、二つの言葉で** — 前の記事の最後の 1 行(回折とは $\mathbf{k}' - \mathbf{k} = \mathbf{g}$ が満たされる現象)を受けて始める。ただし多くの読者はブラッグ則 $2d\sin\theta = \lambda$ の方を先に習っている。そこで図1 で両者を左右に並べ、$|\mathbf{g}| = 1/d$ を橋渡しにして**同じ条件の言い換え**であることを見せる。左パネルで $\theta$ を動かすと右パネルの $\Delta\mathbf{k}$ が伸び縮みし、$2d\sin\theta = \lambda$ が成り立つ瞬間に $\Delta\mathbf{k}$ の先端が逆格子点に着地する。ここで本記事の守備範囲(幾何条件だけを扱い、強度は扱わない)を宣言する。

**2. 波を矢で書く** — 波を 1 本の矢 $\mathbf{k}$ で表す($|\mathbf{k}| = 1/\lambda$、向き = 進行方向)。回折は弾性散乱(elastic scattering)なので、エネルギーが変わらない = **波長が変わらない** = $|\mathbf{k}'| = |\mathbf{k}|$。図2 で散乱方向をドラッグさせると、$\mathbf{k}'$ は長さを変えられず向きだけが変わる。その結果 $\Delta\mathbf{k} = \mathbf{k}' - \mathbf{k}$ の先端が描く軌跡は円(3 次元では球)になる。**エヴァルト球は、この拘束の幾何的な姿にすぎない** — 節の最後にこう言い切る。

**3. 球を描く(中心節)** — 作図の手順を 3 行で与える: ① 逆格子の原点 O に $\mathbf{k}$ の**先端**が来るように入射波の矢を描く。② その矢の根元 C を中心に、半径 $1/\lambda$ の球を描く。③ **球面に乗った逆格子点 G だけが回折する**。回折波は C から G へ向かう矢である。図3 は初期状態で 1 点も球面に乗っておらず、何も光らない。ここが本記事の山場: 「静止した単結晶に単色光を当てても、ふつうは何も起きない」。読者が結晶方位を回して点を球面に乗せると反射が点灯する。続けて「厳密に球面に乗る確率はゼロではないか」という当然の疑問に、**結晶が有限の厚さ $t$ をもつために逆格子点は $\sim 1/t$ だけ広がっている**(励起誤差 $s$ の許容)と答え、スライダーで $t$ を触らせる。以降の 3 つの節は、この「めったに満たされない条件」を満たしにいく 3 通りの方法だと予告する。

**4. 結晶を回す — 回転結晶法** — 結晶を連続的に回すと逆格子も一緒に回り、点が次々と球面を横切る。**横切った一瞬だけ反射が光る**。図4 を再生し、点灯の記録が溜まっていくのを眺めさせる。回折は「常に起きている」のではなく「条件を満たした一瞬に起きる」という感覚を作る。回転を止めて手で角度を送れば、1 つの反射が現れて消えるまでを追える。ここで図注として、点灯している幅がゼロでないのは S3 の $1/t$ の広がりのおかげであること(誠実な簡略化)を再掲する。

**5. 波長を変える — 限界球とラウエ法** — $\lambda$ を変えると球の半径 $1/\lambda$ が変わる。短波長 → 大きな球 → 拾える点が増える。球は必ず原点 O を通るので、$\lambda$ をどう選んでも届かない点がある: 原点を中心とする半径 $2/\lambda$ の**限界球**(limiting sphere)の外側である。図5 でこれを見せ、$|\mathbf{g}| \le 2/\lambda$ すなわち $d \ge \lambda/2$ という有名な制限を読み取らせる。続いて「白色 X 線」モードに切り替えると、球は $1/\lambda_{max}$ から $1/\lambda_{min}$ までの**殻**に太り、静止した単結晶からでも多数の反射が同時に出る — ラウエ法(Laue method)。

**6. 粉末にする — なぜ環になるのか** — 多結晶(粉末)ではあらゆる方位の結晶が含まれる。1 つの逆格子点 $\mathbf{g}_{hkl}$ は、方位を全部集めると**原点まわりの半径 $|\mathbf{g}_{hkl}|$ の球殻**に塗り広げられる。この球殻とエヴァルト球の交わりは 1 つの円で、C からその円へ向かう回折波は**円錐**をなす。検出器上ではこれが環(デバイ・シェラー環, Debye–Scherrer ring)として現れる。図6 で環を 1 本選ばせ、その半径から $2\theta$ を読み、$d = \lambda/(2\sin\theta)$ で面間隔を計算させる。答え合わせとして (hkl) が表示される。格子を体心立方・面心立方に切り替えると、消える環がある(前提記事で見た「現れない点」の帰結)ことにも触れる。

**7. 球が平らに見えるとき — 電子線回折** — 200 kV の電子線は $\lambda \approx 2.5$ pm。$1/\lambda \approx 400$ nm⁻¹ で、逆格子の間隔(数 nm⁻¹)より 2 桁大きい。球の半径が桁違いに大きいので、原点付近では**球面が逆格子面に対してほぼ平面**になる。図7 で X 線と電子線の球を同じ逆格子の上に並べ、原点から $|\mathbf{g}|$ 離れた位置での球面の落ち込み(たわみ)$\Delta \approx |\mathbf{g}|^2\lambda/2$ を読み比べる。だから TEM の回折図形は、晶帯軸(zone axis)に垂直な逆格子の**断面図そのもの**に見える。ここまでの 3 つの方法(回す・波長を振る・粉末にする)に対して、電子線は「球を平らにして一気に当てる」第 4 の道だとまとめる。

**8. まとめ** — 静的図 S2 で回収する。逆格子 = 「回折が起こりうる場所の地図」、エヴァルト球 = 「その地図の上を走る探照灯」。探照灯の**大きさ**は波長が決め($1/\lambda$)、**向き**は入射方向が決め、**地図の向き**は結晶方位が決める。この 3 つのうちどれを振るかが回転結晶法・ラウエ法・粉末法の違いだった、と 1 枚にまとめる。最後に、本記事が答えなかった問い(どれくらい強く光るのか = 構造因子)を次の課題として置く。

- **座標系(3D 図版で共通)**: 逆空間 nm⁻¹。原点 O = 逆格子の 000 を three.js の原点に置く。**入射波は +x 方向に進む**(画面のおおむね左から右へ)。したがってエヴァルト球の中心は $C = -\mathbf{k} = (-1/\lambda,\,0,\,0)$ で、球は O を必ず通る。初期カメラは `_shared3d.ts` の既定(方位 30°・仰角 20°)。

- **格子**: 単純立方、格子定数 $a = 0.40$ nm 固定(前提記事と同値)。逆格子点は $|h|,|k|,|l| \le 3$。図6 のみ体心立方・面心立方も選べる(`isAllowed` を再利用)。
- **色**: §2.3 の割当のみ。エヴァルト球は `--mat-sphere-fill` の半透明球(`depthWrite: false`、両面描画)+ `--mat-sphere-line` のワイヤ輪郭。**内部の逆格子点が透けて見えることを最優先**し、不透明にしない。点灯した反射は**発光ではなく、半径・彩度・ラベル**で区別する(母体仕様 §2-7「動くのは物理だけ」)。
- **描画方式**: 図4 以外はすべて `requestRender` 型(`host.onRender` に登録し、パラメータ変更・視点変更のときだけ 1 フレーム描く)。図4 のみ `onFrame`。省モーション時は engine の既定動作(自動再生せず、再生ボタンで開始)に委ねる。

- **アクセシビリティ**: 全図版に `alt`。3D の stage は `role="application"` + `aria-label`(`_shared3d.ts` が付与)。全パラメータはネイティブ部品(slider / stepper / toggle / segmented / button)で、キーボードのみで操作できる。
- **乱数は不使用**(全図版とも決定論的)。`reset` はパラメータ・視点・記録をすべて初期値へ戻す。

### 5.1 図1 `bragg-vs-laue` — 同じ条件を、二つの言葉で

**表示するもの / 初期状態**

2 パネル。左 = **実空間のブラッグの絵**、右 = **逆空間のラウエの絵**。

- 左パネル: 間隔 $d$ の水平な格子面 5 枚(`--mat-matrix` の細線 + 面上の原子)。左上から入射する光線と、鏡面反射で右上へ抜ける光線(`--mat-beam` の 2 本、先端に矢印)。入射角 $\theta$ は面**から**測る(結晶学の流儀)。隣り合う 2 面で反射した光線の光路差を、垂線の足を結ぶ短い線分 2 本($d\sin\theta$ ずつ)で示し、「光路差 = $2d\sin\theta$」のラベルを置く。波長 $\lambda$ の物差し(長さ $\lambda$ の水平バー)を光路差の真下に並べて置き、**両者の長さを目で比べられる**ようにする。
- 右パネル: 逆空間。原点 O と、$\mathbf{g} = (1/d)\hat{y}$ の位置の逆格子点(`--mat-recip`)。入射波の矢 $\mathbf{k}$(`--mat-beam`、先端が O)、散乱波の矢 $\mathbf{k}'$(`--mat-beam`、根元が C = O − k)、両者の差 $\Delta\mathbf{k}$(`--mat-recip`、O を根元に描く)。エヴァルト球の断面円は**まだ描かない**(球は S3 で導入する)。
- 一致したとき(下記の判定)、左は反射光線を太く、右は逆格子点をひと回り大きくして `(1 0)` のラベルを出す。両パネルの上部に「回折が起きる」のバッジを 1 つだけ表示する。
- 初期状態: $\lambda = 0.154$ nm(Cu Kα)、$d = 0.200$ nm、$\theta = 15.0°$。このとき $2d\sin\theta = 0.104$ nm < $\lambda$ で**一致していない**。$\theta$ を上げていくと $\theta = 22.7°$ で一致する。

**操作パラメータ**

| 入射角 θ | slider | 5〜75(step 0.1) | 15.0 | ° | 線形 |
| 面間隔 d | slider | 0.12〜0.40(step 0.005) | 0.200 | nm | 線形 |
| 波長 λ | slider | 0.05〜0.30(step 0.002) | 0.154 | nm | 線形 |
| ブラッグ角に合わせる | button | — | — | — | — |
| リセット | reset | — | — | — | — |

読み取り値(tabular-nums): `2d sinθ`(nm)、`λ`(nm)、`|Δk|`(nm⁻¹、recip 色)、`|g| = 1/d`(nm⁻¹、recip 色)、判定(「一致」/差の表示)。

**背後の物理モデルと式**

- ブラッグ則(式 E2): $2d\sin\theta = \lambda$。$\lambda > 2d$ のときは解が存在しない — このとき「この面間隔ではこの波長は回折できません($\lambda > 2d$)」と表示し、「ブラッグ角に合わせる」ボタンを無効化する(限界球の予告)。
- 散乱ベクトルの大きさ(式 E6): $|\Delta\mathbf{k}| = 2\sin\theta/\lambda$。逆格子ベクトルの大きさ(式 E7): $|\mathbf{g}| = 1/d$。
- 等価性(式 E8): $|\Delta\mathbf{k}| = |\mathbf{g}| \iff 2\sin\theta/\lambda = 1/d \iff 2d\sin\theta = \lambda$。**右パネルの向きの一致は作図で保証する**: 鏡面反射の幾何から $\Delta\mathbf{k}$ は必ず面の法線方向(= $\mathbf{g}$ の方向)を向くので、判定は大きさの比較だけでよい。
- 一致判定: $|\,|\Delta\mathbf{k}| - |\mathbf{g}|\,| \le 0.02$ nm⁻¹(スライダー分解能に対して十分細く、かつ指で当てられる幅)。
- **簡略化(図注に明示)**: 2 次元の断面で描いている。原子は点として描き、熱振動・吸収は無視する。**強度は扱わない** — 光線の太さは一致したかどうかを示す印であって、強度ではない。左の「鏡」の絵は結果を説明する便法であり、実際に起きているのは各原子による散乱の重ね合わせである。

**実装方式**

2D Canvas / `requestRender`。`_shared2d.ts` の `splitPanels` / `makeMapper` / `drawArrow` / `drawAtoms` / `drawScaleBar` / `createReadout` を使う。`aspect="2/1"`、`aspectNarrow="10/13"`。

**図注(案)**: 「図1. 同じ 1 つの条件を、実空間(左)と逆空間(右)で書いたもの。θ を動かして、光路差 2d sinθ が λ に一致する角度を探そう。一致した瞬間、右では Δk の先端がちょうど逆格子点に着地する。2 次元の断面で描いており、強度は扱っていない。」

**alt(案)**: 「左に等間隔の格子面と入射・反射の光線、右に逆格子の原点・逆格子点と 3 本のベクトル。入射角を変えると光路差と散乱ベクトルの長さが同時に変わり、光路差が波長に一致したとき、散乱ベクトルの先端がちょうど逆格子点に重なる。」

**受け入れ基準**

- [ ] $\theta$ を動かすと左の光路差と右の $|\Delta\mathbf{k}|$ が同時に変わり、一致は必ず同時に起きる
- [ ] 読み取り値が $2d\sin\theta$ と $\lambda$、$|\Delta\mathbf{k}|$ と $1/d$ の 2 組で同時に等しくなる(数値誤差 0.5% 以内)
- [ ] $\lambda > 2d$ の設定でメッセージが出て、「ブラッグ角に合わせる」が無効になる
- [ ] 「ブラッグ角に合わせる」で $\theta = \arcsin(\lambda/2d)$ に正確に移動する
- [ ] 全操作がキーボードのみで可能、`reset` で初期値に完全復帰する

**背後の物理モデルと式**

- 作図(式 E9): エヴァルト球は $|\mathbf{g} - C| = 1/\lambda$、$C = -\mathbf{k}$。$\mathbf{g} = 0$(原点)は常にこの式を満たす — 球は必ず原点を通る。
- 回折条件のスカラー形(式 E10): $|\mathbf{g}|^2 + 2\,\mathbf{k}\cdot\mathbf{g} = 0$。これは $|\mathbf{k} + \mathbf{g}| = |\mathbf{k}|$、すなわちラウエ条件 $\mathbf{k}' = \mathbf{k} + \mathbf{g}$ と $|\mathbf{k}'| = |\mathbf{k}|$ を同時に書いたものである。
- 励起誤差(excitation error, 式 E12): $s = |\mathbf{g} - C| - 1/\lambda$。$s = 0$ が厳密な回折条件。厚さ $t$ の結晶では逆格子点が $\pm 1/t$ 程度に広がるため、点灯条件を $|s| \le 1/t$ とする。**これは幾何を「甘くする」ための便法ではなく、有限サイズの結晶で実際に起きていること**であり、そう図注に書く。
- 結晶方位: 逆格子全体を $R = R_z(\chi)\,R_y(\varphi)$ で回す(球と入射波は動かさない)。実験としては「結晶を回す」のと等価。

**実装方式**

3D。`_shared3d.ts` の単一ビュー(§5.0 の拡張)。`requestRender` 型 — パラメータ変更と視点変更(慣性減衰中を含む)のときだけ 1 フレーム描く。判定ループは 343 点 × 1 回で、スライダーのドラッグ中も 60fps を保てる。

**図注(案)**: 「図3. エヴァルト球。中心は入射波の矢の根元、半径は 1/λ。球面に乗った逆格子点だけが回折する。初期状態では 1 つも乗っていない — 結晶の向きを回して探そう。点が『乗った』と判定される幅は、結晶の厚さ t による逆格子点の広がり(およそ 1/t)である。強度は扱っておらず、幾何条件を満たす点はすべて同じ大きさで点灯する。」

**alt(案)**: 「逆格子の点が立方状に並ぶ中に、原点を通る半透明の球が描かれている。結晶の向きのスライダーを動かすと点の配列だけが回り、球面に乗った点が大きくなって、球の中心からその点へ回折波の矢が伸びる。」

**受け入れ基準**

- [ ] 初期状態で点灯中の反射が 0 個で、その旨が読み取り値に出る
- [ ] $\varphi$ を回すと反射が現れて消え、点灯中は必ず $|s| \le 1/t$ を満たす(内部検証)
- [ ] 「いちばん近い反射に合わせる」を押すと 1 個以上が点灯する($\lambda$・$\chi$ が既定の範囲内である限り)
- [ ] $t$ を大きくすると点灯する角度範囲が狭くなり、小さくすると広くなる
- [ ] 球を半透明にしたまま、内部の逆格子点が視認できる(不透明にしない)
- [ ] 静止時にレンダリングが止まり、画面外・タブ非表示で完全停止する
- [ ] キーボードのみで視点操作を含む全操作ができる

### 5.4 図4 `rotation-method` — 結晶を回す

**表示するもの / 初期状態**

図3 と同じ単一 3D ビュー・同じシーン部品(`_scene3d.ts` を共用)。差分は次のとおり。

- 結晶方位 $\varphi$ が時間とともに増える(自動回転)。$\chi$ は固定。

**背後の物理モデルと式**

- 限界球(式 E11): エヴァルト球は必ず原点を通り、中心は原点から $1/\lambda$ の距離にある。したがって球面が到達しうる点は $|\mathbf{g}| \le 2/\lambda$、言い換えると $d \ge \lambda/2$ に限られる。結晶方位をどう振っても、$\lambda$ を固定するかぎりこの外側は永久に観測できない。
- 白色 X 線(ラウエ法): 波長が連続に分布すると、各 $\lambda$ に対して 1 つずつ球が引ける。全部重ねると半径 $1/\lambda_{max}$ 〜 $1/\lambda_{min}$ の**殻**になる。殻の中に入った点はどれかの波長で条件を満たすので、静止した単結晶からでも多数の反射が同時に出る。点灯条件は $1/\lambda_{max} - 1/t \le |\mathbf{g} - \hat{C}\,|\cdots$ ではなく、実装上は「$\mathbf{g}$ に対して条件を満たす $\lambda$ が存在するか」で判定する: 式 E10 より $\lambda_{hkl} = -2\,\hat{\mathbf{k}}\cdot\mathbf{g}\,/\,|\mathbf{g}|^2$($\hat{\mathbf{k}}$ は入射方向の単位ベクトル)。これが $[\lambda_{min}, \lambda_{max}]$ に入れば点灯する。**この式が本図の実装の核**であり、殻の描画は同じことの見える化である。
- 2 本のスライダーの可動域を重ねていないので、$\lambda_{min} < \lambda_{max}$ は常に成り立つ(クランプ処理は不要)。
- **簡略化(図注に明示)**: 図3 と同じ簡略化に加えて、白色モードでは各波長の強度分布(制動輻射の連続スペクトルの形)を無視し、範囲内の波長を等価に扱っている。

**実装方式**

3D / `requestRender`。単色モードと白色モードで判定関数を差し替えるだけで、シーン部品は共通(`_scene3d.ts`)。限界球のワイヤは `SphereGeometry` + `WireframeGeometry` を `LineSegments` として 1 個持ち、半径はスケールで変える(ジオメトリを作り直さない)。

**図注(案)**: 「図5. 波長を変えると球の大きさが変わる。球は必ず原点を通るので、届く範囲は原点まわりの半径 2/λ の限界球の内側だけ。白色 X 線に切り替えると球が殻に太り、静止した結晶からでも多数の反射が同時に出る(ラウエ法)。連続スペクトルの強度分布は無視している。」

**alt(案)**: 「逆格子の点の配列に、原点を通る半透明の球と、原点を中心とする大きなワイヤの球が重なっている。波長を短くすると内側の球が大きくなって多くの点を拾い、外側の限界球も大きくなる。白色モードでは球が厚い殻になり、殻に入った点が一斉に点灯する。」

**受け入れ基準**

- [ ] $\lambda$ を短くすると球と限界球が同時に大きくなり、「観測しうる点の数」が増える
- [ ] $|\mathbf{g}| > 2/\lambda$ の点は、$\varphi$ をどう回しても点灯しない
- [ ] 「測定できる最小の d」が $\lambda/2$ と一致する
- [ ] 白色モードで、静止したまま複数の反射が同時に点灯する
- [ ] $\lambda_{min} < \lambda_{max}$ が常に保たれる
- [ ] 図3 と同じ性能・停止・キーボード要件を満たす

### 5.6 図6 `powder-rings` — 粉末にする(推奨)

**表示するもの / 初期状態**

- 左ビュー(逆空間): エヴァルト球(図3 と同じ)+ 入射波の矢 + 原点。
  - 「粉末にする」トグルが on(既定): 選択中の反射 $(hkl)$ に対応する**球殻** — 原点中心・半径 $|\mathbf{g}_{hkl}|$ の半透明球(`--mat-matrix` の低不透明度)。エヴァルト球との交線の円を `--mat-beam` の太線で描き、C からその円上の 12 点へ向かう回折波の矢で**円錐**を作る。

読み取り値: `選択中の環`((h k l))、`2θ`(°)、`測った d = λ/(2 sinθ)`(nm)、`式の d = a/√(h²+k²+l²)`(nm)、`環の半径 / L`(無次元)。**測った d と式の d が一致することが、この図の答え合わせ**である。

**背後の物理モデルと式**

- 粉末(多結晶)では結晶方位が一様に分布するので、1 つの逆格子ベクトル $\mathbf{g}_{hkl}$ は原点まわりの半径 $|\mathbf{g}_{hkl}|$ の球殻に写る。
- 球殻(半径 $G$、原点中心)とエヴァルト球(半径 $1/\lambda$、中心 $C$、原点を通る)は、$G \le 2/\lambda$ のとき 1 つの円で交わる。この円へ向かう回折波は頂角 $2\theta$ の円錐をなし、$\sin\theta = G\lambda/2 = \lambda/(2d)$(= ブラッグ則)。
- 検出器上の環の半径(式 E16): $r = L\tan 2\theta$($L$ = 試料〜検出器距離)。本図では $L$ を単位長とし、$r/L$ を表示する(装置固有の値には踏み込まない — 前提記事 付録 A-6 と同じ方針)。
- 存在則は `lattice.ts` の `isAllowed` を再利用する(SC: 全整数、BCC: $h+k+l$ が偶数、FCC: $h,k,l$ の偶奇が揃う)。同じ $h^2+k^2+l^2$ をもつ反射は 1 本の環にまとまる(多重度)ため、**$h^2+k^2+l^2$ の値で環をグループ化**して 1 本ずつ描く。

**実装方式**

3D / `requestRender`、2 ビューポート(左 = オービット連動、右 = 固定カメラ、`_shared3d.ts` の拡張)。環は `LineLoop`(円周 128 分割)を必要本数だけ確保して `visible` と `scale` で切り替える(毎回ジオメトリを作らない)。円錐の矢は `createArrow3D` を 12 本再利用する。

**図注(案)**: 「図6. 粉末ではあらゆる方位の結晶が含まれるので、1 つの逆格子点は原点まわりの球殻に塗り広げられる。球殻とエヴァルト球の交わりは円で、そこへ向かう回折波は円錐をなし、検出器では環になる。環を 1 本選んで 2θ を読み、d = λ/(2 sinθ) が計算どおりか確かめよう。強度は扱っていないので、環の濃さはすべて同じである。検出器までの距離を 1 として半径を表示している。」

**alt(案)**: 「左は逆空間の作図で、原点を中心とする球殻とエヴァルト球が円で交わり、その円へ向かう回折波が円錐をつくる。右は検出器を正面から見た図で、中心の透過スポットのまわりに同心の環が並ぶ。環を選ぶと、その 2θ から計算した面間隔が表示される。」

**受け入れ基準**

- [ ] 選択した環について「測った d」と「式の d」が 0.5% 以内で一致する

### 5.7 図7 `electron-vs-xray` — 球が平らに見えるとき(発展)

**表示するもの / 初期状態**

2 パネル(2D)。左 = X 線、右 = 電子線。**同じ逆格子の同じ断面**(hk0 面、$a = 0.40$ nm、$|h|,|k| \le 6$)を同じ縮尺で描き、それぞれのエヴァルト球の断面円の**原点付近の弧**を重ねる。

- 各パネル: 逆格子点(`--mat-recip`)、原点 000(大きめ)、球の弧(`--mat-sphere-line`、球の内側を `--mat-sphere-fill` で薄く塗る)、入射波の矢 $\mathbf{k}$(`--mat-beam`、原点へ向かう)。
- 弧の落ち込み(サジッタ)を示す寸法線: 原点から水平に $|\mathbf{g}| = 5.0$ nm⁻¹ 離れた位置で、逆格子面($g_x$ 軸)と弧の距離 $\Delta$ を測る破線 + ラベル。
- 点灯条件 $|s| \le 1/t$ を満たす点は `--mat-beam` で塗り、パネル下部に点灯数を出す。電子線側では**一列にずらりと点灯する**(TEM の回折図形が断面図に見える理由)。
- 初期状態: 左 = Cu Kα($\lambda = 0.15406$ nm)、右 = 200 kV($\lambda = 2.508$ pm)、$t = 30$ nm。

**操作パラメータ**

| 名前 | 部品 | 範囲 | 初期値 | 単位 | スケール |
|---|---|---|---|---|---|
| X 線源 | segmented: Cu Kα(0.1541 nm)/ Mo Kα(0.0711 nm) | — | Cu Kα | — | — |
| 加速電圧 V | slider | 60〜300(step 5) | 200 | kV | 線形 |
| 結晶の厚さ t | slider | 5〜100(step 1) | 30 | nm | 線形 |
| 表示範囲 | slider(両パネル共通。同一縮尺は常に保つ) | 5.5〜12(step 0.5) | 8 | nm⁻¹ | 線形 |
| リセット | reset | — | — | — | — |

読み取り値: `λ(X 線)`(nm、beam 色)、`λ(電子線)`(pm、beam 色)、`1/λ の比`(電子線 / X 線、sphere 色)、`Δ(X 線)` / `Δ(電子線)`(nm⁻¹、$|\mathbf{g}| = 5$ nm⁻¹ での落ち込み)、`点灯数`(左 / 右)。

**背後の物理モデルと式**

- 電子の波長(式 E15、相対論補正あり): $\lambda = \dfrac{h}{\sqrt{2 m_e e V\left(1 + \dfrac{eV}{2 m_e c^2}\right)}}$。200 kV で 2.508 pm、100 kV で 3.701 pm、300 kV で 1.969 pm。**相対論補正を落とすと 200 kV で 2.74 pm となり 9% ずれる**ので、補正込みで計算する。
- 球面の落ち込み(サジッタ、式 E14): 原点で逆格子面に接する球面が、面に沿って $g$ 離れた位置でどれだけ離れるかは $\Delta = R - \sqrt{R^2 - g^2} \approx \dfrac{g^2}{2R} = \dfrac{g^2\lambda}{2}$。$g = 5$ nm⁻¹ のとき、Cu Kα では $\Delta = 2.35$ nm⁻¹(逆格子間隔 2.5 nm⁻¹ と同程度 = まったく平らでない)、200 kV 電子線では $\Delta = 0.031$ nm⁻¹(逆格子間隔の 1.3%)。この 2 桁の差が「球が平らに見える」の中身である。
- 本図では、ずれを**入射方向に沿って**測る(電子回折で使う偏差パラメータの流儀。図で描く縦の寸法線と一致する)。図3〜図5 で使う $s = |\mathbf{g} - \mathbf{C}| - R$ とは、$g \ll R$ ではどちらも $g^2/(2R)$ に一致する。
- 点灯条件は $\Delta \le 1/t$。$t = 30$ nm で $1/t = 0.033$ nm⁻¹ なので、電子線側では $g = 5$ nm⁻¹ まで条件を満たし続ける — 一列に点灯する理由がそのまま数値で追える。X 線側はこの断面では 0 個で、図3 の「静止した単結晶では何も光らない」がそのまま効いている。
- **簡略化(図注に明示)**: 2 次元の断面。電子線の実際の回折では動力学的効果(多重散乱)が効くが、ここでは幾何条件だけを見ている。X 線と電子線で散乱の強さ・吸収がまったく違うことも扱わない。

**実装方式**

2D Canvas / `requestRender`。`_shared2d.ts` の 2 パネル分割を使う。弧は `ctx.arc` で描き、半径が巨大(電子線: $R = 399$ nm⁻¹ に対して表示範囲 ±8 nm⁻¹)になるため、**近似式で置き換えず `ctx.arc` に大きな半径をそのまま渡してブラウザ側に任せる**(半径が表示幅の 100 倍程度までは Canvas 2D で問題なく描ける)。両パネルは常に同一縮尺で、「表示範囲」スライダーが両方に効く。`aspect="2/1"`、`aspectNarrow="10/13"`。

**図注(案)**: 「図7. 同じ逆格子に、X 線(左)と 200 kV の電子線(右)のエヴァルト球の弧を重ねたもの。電子線の波長は 2 桁短く、球の半径は 2 桁大きい。その結果、原点付近では球面が逆格子の面とほとんど区別できなくなり、一枚の断面上の点が一斉に条件を満たす — TEM の回折図形が逆格子の断面図そのものに見える理由である。2 次元の断面で描いており、多重散乱は扱っていない。」

**alt(案)**: 「左右に同じ逆格子の断面が並び、左には強く湾曲した X 線のエヴァルト球の弧、右にはほとんど直線に見える電子線の弧が重なっている。右では原点から左右に並ぶ点が一列に点灯し、左では原点付近の 1〜2 点しか条件を満たさない。」

**受け入れ基準**

- [ ] 200 kV で $\lambda = 2.51$ pm と表示される(相対論補正込み。誤差 0.5% 以内)
- [ ] $\Delta$ の読み取りが $R - \sqrt{R^2 - g^2}$ と一致する(0.5% 以内。Cu Kα・$g=5$ で 2.35 nm⁻¹、200 kV で 0.0314 nm⁻¹)

- [ ] $V$ を下げると右の弧の曲率が目に見えて増える
