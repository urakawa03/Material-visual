## 0. 位置づけの補足(重要)

カテゴリ C は「拡散と組織の変化」だが、マルテンサイト変態は**拡散しないのに組織が変わる**唯一の例である。これは矛盾ではなく、**カテゴリの締めくくり**として効く: カーケンドール(拡散が格子を動かす)→ GP ゾーン(拡散で溶質が集まる)→ オストワルド成長(拡散で大が小を食う)→ スピノーダル分解(拡散が濃度差を広げる)と、拡散で組織が変わる話を重ねてきた最後に、「**拡散に頼らずに組織を変える方法がある**」で締める(プロンプト 10 の方針)。

本記事の主張の背骨は 1 つ: **焼入れで鋼が硬くなるのは、炭素に動く時間を与えないから**。そのために、

- 「時間を与えるとどうなるか(拡散変態 = パーライト)」を図1・図2 で先に見せ、
- 「時間を与えないとき、原子は運ばれずに格子ごと変形する(無拡散変態)」を図3〜図5 で見せ、
- 「閉じ込められた炭素が硬さになる」「あとから時間を少し与え直す(焼戻し)」を図6・図7 で回収する。

プロンプトからの変更点: 図1 の冷却と組織の判定を、**C 曲線(TTT 図の変態開始線)+ シャイルの加算則**という標準的な簡略模型で行うことにした(プロンプトは「冷却速度と硬さ」としか決めていなかった)。この模型は、共析鋼の臨界冷却速度を約 150 ℃/秒と、文献値(約 140 ℃/秒)に近い値で再現する(§5.1、本仕様の作成時に計算で確認)。

前提: `90_remaining_work.md` §3 の P0(`src/core/units.ts`・`src/core/plot.ts`・`src/core/anim.ts`)がマージ済み。新規の色トークン・KaTeX マクロはない。

## 1. 学習目標

読了・操作後に、読者が次のことをできるようになる。

1. 同じ組成の鋼が、冷やす速さだけで硬さが数倍違うことを、「**炭素が拡散して炭化物を作る時間があるかどうか**」で説明できる(C 曲線と冷却曲線の交差として読める)。
2. オーステナイト(面心立方)とフェライト(体心立方)の炭素の溶け方の違いと、温度とともに炭素の跳躍が桁違いに遅くなることを、カーケンドール記事の空孔なし(格子間)拡散と結び付けて説明できる。
3. **ベイン対応**で、面心立方の中に潜む体心正方の胞を縮め・伸ばすだけで体心立方に変わること、そのとき**原子は隣との関係を保ったまま協調して動く**(無拡散)ことを述べられる。
4. マルテンサイト変態が**温度で進み、時間では進まない**(非熱的)ことを、拡散変態(待てば進む)との対比で説明でき、$M_s$・$M_f$ と残留オーステナイトの関係を言える。
5. 硬さの源が 1 つでないこと — **過飽和炭素による正方晶ひずみ**、変態で導入される高密度の転位・双晶、微細な組織 — を述べ、炭素のない鉄は焼入れても硬くならないことを言える。
6. 焼戻しで炭素が動けるようになり、硬さと引き換えに靭性が戻ること(硬さと靭性のトレードオフ)を、温度と時間の組み合わせ(ホロモン・ジャッフェのパラメータ)で説明できる。

## 2. 前提知識と関連記事

### 2.1 前提知識

- 仮定するもの: GP ゾーン記事の「焼入れ = 不安定な状態に閉じ込める仕込み」「状態図の上を動く点」(推奨)。カーケンドール記事の S2(跳躍頻度 $\propto e^{-Q/RT}$、侵入型は隙間を通るので速い)。
- **再説明しないもの**: 拡散の機構、跳躍頻度の式、転位(フランク・リード源記事)、炭素原子が鉄の格子の隙間に入ること(コットレル雰囲気記事)。
- 記事内で最小限だけ補うもの: Fe–C 状態図の共析点の付近だけ(オーステナイト γ、フェライト α、セメンタイト Fe₃C、共析温度 A₁ = 727 ℃)。

### 2.2 関連記事

- [GP ゾーン](/articles/gp-zones/)(推奨)— 「焼入れで閉じ込める」の文脈を共有する。GP ゾーンは閉じ込めた溶質が**あとで拡散して集まる**話、本記事は**拡散させずに格子を変える**話、と対比させる。
- [カーケンドール効果](/articles/kirkendall-effect/) — S2 で、同記事 S2 の跳躍頻度の温度依存をそのまま使う。
- [コットレル雰囲気](/articles/cottrell-atmosphere/) — 炭素原子の描き方(`--mat-solute` の侵入型原子、八面体位置)を共有する。S6 で「閉じ込められた炭素が格子を歪ませる」を同記事の「炭素が転位の下に集まる」と並べる。
- [フランク・リード源](/articles/frank-read-source/) — S6 の「転位が動きにくい = 硬い」と、図1 のパーライトの「組織が細かいほど硬い」(ホール・ペッチの方向感覚)で参照する。
- [スピノーダル分解](/articles/spinodal-decomposition/) — カテゴリ C の流れの中で、まとめで一言触れる。

各節の要旨:

**1. 冷やす速さで別物になる(導入・謎)** — 同じ共析鋼(0.8% C)を 850 ℃ から、炉の中でゆっくり・空気中で・油で・水で冷やして硬さを測る。**組成が同じなのに、水冷は炉冷の約 4 倍硬い**。図1 で冷やし方を選ぶと、温度と時間(対数)のグラフの上に冷却曲線が引かれ、それがパーライトの**変態開始線(C 曲線)**を横切るか、横切らずに $M_s$ まで下りきるかで結果が分かれる。「時間が何を変えているのか」を問いに立てる。遅いほど高い温度でパーライトになり、組織が粗く柔らかい(細かい組織ほど硬い — フランク・リード源記事のホール・ペッチの方向感覚)ことも読み取らせる。

**2. 炭素が逃げられない** — 高温のオーステナイト(面心立方)は炭素をよく溶かすが、低温のフェライト(体心立方)はほとんど溶かせない。ゆっくり冷やせば炭素は拡散して集まり、炭化物(セメンタイト Fe₃C)になる — これがパーライトの縞。図2 で温度を下げていくと、炭素の跳躍はカーケンドール記事 S2 と同じ式で**桁違いに**遅くなる: 900 ℃ では 1 秒に数百万回跳ぶ炭素が、300 ℃ では数秒に 1 回、100 ℃ ではほぼ止まる。炭化物を作るには、炭素が長い距離を動いて集まり、新しい相の核ができる時間が要る — 急冷はその時間を与えずに低温まで下ろしてしまう。**炭素はその場に閉じ込められる**。

**3. 原子を運ばずに構造を変える — ベイン対応** — では炭素が動けないのに、どうやって面心立方から体心立方になるのか。答えは**格子そのものを変形させる**こと。面心立方の格子の中には、少し縦長の体心正方の胞が最初から埋まっている($c/a = \sqrt2$)。それを縦に約 20% 縮め、横に約 13% 伸ばすと、体心立方になる(ベイン対応)。図3 の 3D で変形量を動かし、**どの原子も隣の原子との関係を保ったまま、全体で協調して動く**ことを確かめる。拡散変態を「人々がそれぞれ好きな方向へ歩いて並び替わる」、マルテンサイト変態を「隊列が号令で一斉に向きを変える」にたとえる古典的な比喩を静的図 S-2 で示す。

**4. 音速で進む — 非熱的変態** — この変態は原子の熱的な跳躍に頼らないので、**温度を下げたその瞬間に進む**。$M_s$(変態開始温度)以下で始まり、$M_f$ でほぼ終わる。決定的なのは、**変態量は温度で決まり、その温度に保っても増えない**こと(非熱的)。図4 で到達温度と保持時間を動かし、マルテンサイトは保持時間に反応しないのに、隣のパネルの拡散変態(同じ温度に保てば時間とともに進む)は反応することを見比べる。炭素が多いほど $M_s$ は下がり、高炭素鋼では $M_f$ が室温より下になって、変態しきれなかったオーステナイトが残る(残留オーステナイト。深冷処理で減らせる)。

**5. 形が変わる — 表面起伏と自己調整** — せん断を伴うので、変態した領域は**表面に起伏を作る**(研磨した平らな面が傾く。無拡散変態の古典的な証拠)。一方、まわりの母相はその変形を拘束するので、1 枚の板だけが大きくせん断すると大きなひずみのエネルギーがたまる。そこでマルテンサイトは、**向きの違う板(バリアント)が互いのせん断を打ち消すように**交互に並んで成長する(自己調整)。図5 でバリアントを 1 種類 / 交互にして、表面の起伏と、たまるひずみのエネルギーを比べる。

**6. なぜ硬いのか** — 硬さの源は 1 つではない。① 閉じ込められた炭素が、体心の格子の特定の隙間(八面体位置の 1 種類)に並んで入り、格子を縦長に歪ませる(正方晶ひずみ、$c/a > 1$)。② 変態のせん断で、転位や双晶が高密度に入る。③ 組織が非常に細かい。図6 で炭素量を変え、$c/a$ と硬さがともに増えることを確かめる。**炭素のない鉄は焼入れても硬くならない**(硬さはほぼ 150〜200 HV のまま)ことを試させる。コットレル雰囲気の記事で炭素が転位を捕まえたのと同じ色の炭素が、ここでは格子全体を歪ませている、と並べる。

**7. 硬すぎるものを使えるようにする — 焼戻し** — 焼入れままのマルテンサイトは硬いが脆く、そのままでは使えない。再加熱(**焼戻し**)すると炭素が動けるようになり、微細な炭化物として析出する(GP ゾーン記事の析出と同じ構図)。硬さは下がるが靭性が戻る — **硬さと靭性のトレードオフ**。図7 で温度と時間を変えると、温度と時間の組み合わせ(ホロモン・ジャッフェのパラメータ)が同じなら同じ硬さになることを確かめる。締めとして、マルテンサイト変態が可逆に起きる材料(Ni–Ti)が**形状記憶合金**であることに触れる。

**8. まとめ** — 「拡散に頼らず組織を変える」で回収する。静的図 S-3 で、カテゴリ C の 5 記事を「拡散で変わる(カーケンドール・GP・オストワルド・スピノーダル)」と「拡散させずに変える(本記事)」の 1 枚にまとめる。

**`lib/kinetics.ts` の C 曲線**(共析鋼のパーライト変態の開始時間。拡散の項 × 核生成の項という物理的な形の簡略模型)

$$t_s(T) = C_1\,\exp\!\left(\frac{Q}{RT}\right)\exp\!\left(\frac{K}{T\,(A_1 - T)^2}\right)$$

$Q = 148$ kJ/mol(オーステナイト中の炭素の拡散)、$A_1 = 1000$ K。鼻を 550 ℃・0.8 秒に合わせると $K = 6.72\times10^{7}$ K³、$C_1 = 2.39\times10^{-11}$ 秒。**$A_1$ の近くで指数の引数が巨大になるので、引数が 700 を超えたら $1/t_s = 0$(変態は始まらない)として扱う**(そのまま計算すると浮動小数点のオーバーフローで例外になる — 本仕様の作成時に実際に起きた)。

冷却はニュートン冷却 $T(t) = T_\text{env} + (T_0 - T_\text{env})e^{-t/\tau}$($T_0 = 850$ ℃、$T_\text{env} = 25$ ℃)。$A_1$ 以下で**シャイルの加算則** $\sum \Delta t / t_s(T) \ge 1$ になった時点でパーライト変態が始まったとみなす。$M_s$ に先に達したらマルテンサイト。

**本仕様の作成時の計算結果**(共析鋼):

| 冷やし方 | $\tau$  | 550 ℃ での冷却速度 | 結果                              |
| -------- | ------- | ------------------ | --------------------------------- |
| 塩水     | 0.3 秒  | 約 1750 ℃/秒       | マルテンサイト(加算和 0.08)       |
| 水       | 0.6 秒  | 約 875 ℃/秒        | マルテンサイト(加算和 0.17)       |
| 油       | 6 秒    | 約 88 ℃/秒         | パーライト(521 ℃ で開始 — 細かい) |
| 空気     | 100 秒  | 約 5 ℃/秒          | パーライト(602 ℃ で開始)          |
| 炉       | 3600 秒 | 約 0.1 ℃/秒        | パーライト(632 ℃ で開始 — 粗い)   |

臨界の $\tau$ は約 3.5 秒(550 ℃ で約 150 ℃/秒)で、共析の普通鋼の臨界冷却速度の文献値(約 140 ℃/秒)に近い。**普通の炭素鋼が油ではなく水で焼き入れられる理由**がそのまま再現される(本文で一言)。

**共通規約**

- 乱数は図2 の炭素の跳躍のみ(`mulberry32`、シード固定)。`reset` で同じ初期状態に戻る。
- 時間の軸はすべて対数(P0 の `src/core/plot.ts` の `logTicks` / `fmtPow10`)。
- 経験則・実測値の補間に基づく数値(硬さ・$M_s$・焼戻し曲線)は、図注で「目安」と明示し、出典を §8 に挙げる。

### 5.3 図3 `bain-distortion` — ベイン対応(3D)

**表示するもの / 初期状態**
3D: 面心立方の慣用単位胞 2×2×1 個分の鉄原子(`createInstancedAtoms`、`--mat-matrix`)。その中に潜む**体心正方の胞**の稜線を太線(`--color-accent`)で強調する。変形量 $s$(0 → 1)を動かすと、体心正方の胞を縦($c$)に縮め、横($a$)に伸ばし、$s = 1$ で体心立方($c/a = 1$)になる。**変形前の最近接の原子どうし(1 原子あたり 12 本)を結ぶ細い線**を常時表示し、変形中も**同じ原子どうしに張ったまま付け替えない**(隣どうしの関係が保たれる — 原子は入れ替わらない)ことを見せる。変形後、その 12 本のうち 8 本が体心立方の最近接、4 本がわずかに遠い第 2 近接になることを、線の長さの読み取りで示す(「隣の関係は保たれるが、距離の順位は少し組み替わる」)。
「炭素を入れる」が on のとき、$c$ 軸方向の八面体位置の一部に炭素(`--mat-solute`)を置き、$s = 1$ での $c/a$ が 1 より大きく残る(体心正方のマルテンサイト)ことを示す(図6 の伏線)。
初期は $s = 0$(面心立方)、炭素 off。

**操作パラメータ**

| 名前               | 部品                                                    | 範囲            | 初期値 | 単位 |
| ------------------ | ------------------------------------------------------- | --------------- | ------ | ---- |
| 変形量 $s$         | slider                                                  | 0〜1(step 0.01) | 0      | —    |
| 体心正方の胞を強調 | toggle                                                  | —               | on     | —    |
| 炭素を入れる       | toggle                                                  | —               | off    | —    |
| 視点               | ドラッグ・ピンチ・キーボード(`createSingleView` の標準) | —               | —      | —    |
| リセット           | reset(パラメータ + 視点)                                | —               | —      | —    |

読み取り値: $c$ 方向のひずみ [%]、$a$ 方向のひずみ [%]、$c/a$、体積変化 [%]。

**背後のモデルと簡略化**
面心立方の格子定数 $a_\gamma$ の中の体心正方の胞は $a = a_\gamma/\sqrt2$、$c = a_\gamma$。$s$ に対して格子定数を線形補間し、体心立方 $a_\alpha$ に到達させる。ベインひずみは $c$ 方向 $a_\alpha/a_\gamma - 1 \approx -20\%$、$a$ 方向 $\sqrt2\,a_\alpha/a_\gamma - 1 \approx +13\%$($a_\gamma = 0.359$ nm、$a_\alpha = 0.2866$ nm、本仕様の作成時の計算値)。**誠実な簡略化(図注に明示)**: ベイン対応は**格子の対応**の説明であって、実際の原子の経路そのものではない。実際の変態は、母相と一致する面(晶癖面)を保つために格子不変せん断(すべり・双晶)を伴い、マルテンサイト結晶学の現象論(PTMC)で記述される。

**実装方式**: 3D / `requestRender`(視点・スライダーの変更時のみ 1 フレーム)。three.js はこの図版への接近時に読み込む。

**図注(案)**: 「図3. 面心立方の格子の中には、縦長の体心正方の胞(太線)が最初から埋まっている。これを縦に約 20% 縮め、横に約 13% 伸ばすと体心立方になる(ベイン対応)。原子は隣どうしの関係(細線)を保ったまま、全体で協調して動く — 原子を運ばない変態である。実際の変態では、これに格子不変せん断が加わる。」

**alt(案)**: 「回転できる立方体の格子の中に、太線で縦長の箱が描かれている。変形量を増やすと箱が縦に縮んで横に広がり、最後はサイコロ形の体心立方になる。原子を結ぶ細い線は変形の間ずっと同じ原子どうしを結んでいる。」

**受け入れ基準**

- [ ] $s = 0$ で $c/a = \sqrt2$、$s = 1$ で $c/a = 1$(炭素なし)
- [ ] 変形の全過程で線の結び先が不変(付け替えなし — §5.8 T4)、$s = 1$ で 12 本が 8 本(最近接)+ 4 本(第 2 近接)に分かれる

### 5.4 図4 `athermal-transformation` — 温度で進み、時間で進まない

**表示するもの / 初期状態**
左右 2 パネル。

| 炭素量   | slider       | 0.2〜1.2(step 0.05) | 0.8    | wt%  |
| リセット | reset        | —                   | —      | —    |

読み取り値: $M_s$、$M_f$、マルテンサイト量、残留オーステナイト(室温で)、右パネルの拡散変態の量。

**背後のモデルと簡略化**
左: $f = 1 - \exp[-0.011(M_s - T)]$(式 E5)。$M_s$ は §2.3 の表の補間。**保持時間を動かしても左の点が動かないのはバグではなく物理である** — 実装者が「動かないバグ」と誤解しないよう、コードのコメントと図注に明記する。右: アブラミ式 $f = 1 - \exp[-(t/t_0)^n]$(式 E6、$n = 2.5$、$t_0$ は §5.0 の C 曲線から)。

読み取り値: 表面の最大の起伏(板の厚さに対する比)、全体のせん断ひずみ、たまったひずみエネルギー(相対値)。

**背後のモデルと簡略化**
板のせん断ひずみを $\gamma$ = 0.2(目安)とし、1 種類では全体のせん断が $\gamma \times$ 板の体積分率、交互では $\pm\gamma$ が打ち消して全体のせん断がほぼ 0。ひずみエネルギーは全体のせん断の 2 乗に比例するとした**模式**(図注に明示)。

**実装方式**: 2D Canvas / `requestRender` + `tween`。

**図注(案)**: 「図5. マルテンサイトの板はせん断で形が変わるので、研磨した表面に起伏ができる。1 種類の向きの板だけだと大きなひずみがまわりにたまるが、向きの違う板が交互に並ぶと互いのせん断が打ち消し合い、ひずみは小さくなる(自己調整)。母相とマルテンサイトはどちらも鉄なので同じ色で描き、内部の線の向きで区別した。ひずみのエネルギーは模式的な見積もり。」

**alt(案)**: 「断面の中に板が現れ、1 種類の向きのときは表面が大きく傾いて段差ができ、まわりに広くひずみの色が広がる。交互の向きに切り替えると、表面は小さなジグザグになり、ひずみの色は板の近くだけに限られる。」

**受け入れ基準**

- [ ] 交互の並びで全体のせん断がほぼ 0、ひずみエネルギーが 1 種類のときより大幅に小さい
- [ ] 母相とマルテンサイトが同じ色で、内部の線の傾きで区別されている

### 5.6 図6 `tetragonality-hardness` — なぜ硬いのか

**表示するもの / 初期状態**
左(幅 45%): 体心正方の胞(2D の斜め投影)と、$c$ 軸方向の八面体位置に入った炭素(`--mat-solute`)。炭素量に応じて胞の縦横比 $c/a$ が変わる(誇張倍率を表示 — 実際の $c/a$ は 1.04 程度なので、見えるように 5 倍に誇張し、「×5 に誇張」と明記)。胞のまわりにひずみの場(`--mat-tension` / `--mat-compression`)。
右(幅 55%): 横軸 炭素量(0〜1.2 wt%)、縦軸 硬さ [HV]。100% マルテンサイトの硬さの実測値(点)と補間曲線、現在の炭素量の点。参考に、同じ炭素量のパーライト(徐冷)の硬さを細い線で。炭素量 0 の点に「炭素のない鉄: 焼入れても硬くならない」のラベル。
初期は 0.4 wt% C。

**操作パラメータ**

| 名前             | 部品   | 範囲              | 初期値 | 単位 |
| ---------------- | ------ | ----------------- | ------ | ---- |
| 炭素量           | slider | 0〜1.2(step 0.05) | 0.4    | wt%  |
| ひずみの場を表示 | toggle | —                 | on     | —    |
| リセット         | reset  | —                 | —      | —    |

読み取り値: $c/a$(実際の値)、硬さ [HV]、$M_s$、室温の残留オーステナイトの目安、硬さの源の内訳(言葉で: 「炭素による格子のひずみ」「転位・双晶」「細かい組織」)。

**背後のモデルと簡略化**
$c/a = 1 + 0.045\,C$(式 E4)。硬さは §2.3 の実測値の補間で、**内訳を数値に分解しない**(3 つの源の寄与を正確に分けることは研究上も難しい — 本文と図注で正直に書く)。0.6% C 以上で硬さが頭打ちになるのは、残留オーステナイトが増えることも効いている(図注)。

**実装方式**: 2D Canvas / `requestRender`。

**図注(案)**: 「図6. 閉じ込められた炭素は、体心の格子の決まった隙間に並んで入り、格子を縦長に歪ませる(胞の形は 5 倍に誇張)。炭素が多いほど歪みも硬さも増える。炭素のない鉄は焼入れても硬くならない。硬さには転位や双晶、組織の細かさも効いており、それぞれの寄与は分けて示していない。硬さの値は実測に基づく目安。」

**alt(案)**: 「左に縦長の箱の形の格子と、その縦の辺の中ほどの隙間に入った炭素。炭素量を増やすと箱がさらに縦長になる。右のグラフでは、炭素量とともに硬さが急に増え、0.6% 付近から頭打ちになる。炭素 0 の点は低い硬さのまま。」

**受け入れ基準**

- [ ] $c/a$ が 0.8 C で 1.036(表示桁で)、0 C で 1.000
- [ ] 炭素量 0 で硬さが低いまま(150〜200 HV の範囲)
- [ ] 誇張倍率が常に表示されている

### 5.7 図7 `tempering` — 焼戻し(発展)

**表示するもの / 初期状態**
左(幅 40%): 組織の模式 — 焼戻しの程度に応じて、マルテンサイトの針の中に微細な炭化物(`--mat-precip`)が析出し、次第に粗くなる(GP ゾーン・オストワルド成長の記事の析出物と同じ色)。
右(幅 60%): 横軸 ホロモン・ジャッフェのパラメータ $P = T(20 + \log_{10} t)$(T は K、t は時間)、縦軸 左 = 硬さ [HV]、右 = 靭性(衝撃吸収エネルギーの相対値)。2 本の模式曲線と、現在の $P$ の縦線。**同じ $P$ を与える別の温度・時間の組**(例: 600 ℃ × 1 時間 ≈ 550 ℃ × 約 16 時間 — 本仕様の作成時の計算値)を読み取りに出す。
初期は 共析鋼、焼戻し温度 400 ℃、1 時間。

**操作パラメータ**

| 名前       | 部品         | 範囲              | 初期値 | 単位 |
| ---------- | ------------ | ----------------- | ------ | ---- |
| 焼戻し温度 | slider       | 100〜700(step 10) | 400    | ℃    |
| 焼戻し時間 | slider(対数) | 0.01〜100         | 1      | 時間 |
| リセット   | reset        | —                 | —      | —    |

読み取り値: $P$、硬さの目安、靭性の目安(相対)、同じ $P$ になる別の温度と時間の組。

**背後のモデルと簡略化**
ホロモン・ジャッフェのパラメータ(式 E7、定数 20)。硬さは $P$ の単調減少のシグモイド、靭性は単調増加の**模式曲線**で、焼戻し温度 250〜400 ℃ 付近の**焼戻し脆性**(靭性の一時的な落ち込み)を小さなくぼみとして描き、ラベルを付ける(図注で「模式」と明示)。曲線の両端は図6 と図1 の値(焼入れまま約 820 HV、十分に焼き戻すと約 250 HV)に合わせる。形状記憶合金は本文で一言触れるにとどめる(図にはしない)。

**実装方式**: 2D Canvas / `requestRender`。

**図注(案)**: 「図7. 焼戻しの温度と時間を変えると、炭素が動けるようになって微細な炭化物が析出し、硬さが下がって粘り強さ(靭性)が戻る。温度と時間の効き方は 1 つのパラメータにまとめられ、同じ値なら同じ硬さになる。曲線は模式で、250〜400 ℃ 付近の靭性のくぼみ(焼戻し脆性)も描いた。」

**alt(案)**: 「左に、針状の組織の中に小さな粒が析出し、次第に大きくなっていく模式図。右に、横軸がパラメータ、左の縦軸が硬さ、右の縦軸が靭性の 2 本の曲線。焼戻し温度を上げると硬さの曲線が下がり、靭性の曲線が上がる。途中に靭性の小さなくぼみがある。」

**受け入れ基準**

- [ ] 同じ $P$ を与える温度・時間の組で硬さの読み取りが一致する(§5.8 T6)
- [ ] 硬さが $P$ に対して単調に減少、両端が図1・図6 の値と一致
- [ ] 焼戻し脆性のくぼみにラベルがあり、図注に「模式」とある
