# 記事仕様書 02 — フランク・リード源(v1.0)

**slug**: `frank-read-source` | **カテゴリ**: B. 転位と材料の強さ | **主な描画**: 2D Canvas

本書は母体サイト仕様書(`00_base_site_spec.md`)§12 のフォーマットに従う個別仕様書である。デザイン原則・図版契約・意味パレット等はすべて母体仕様書に準拠する。

**記事仮題**: 「フランク・リード源 — 転位はどこから湧いてくるのか」

**位置づけの補足**: 本記事は前提記事を持たず、**サイト全体の実質的な「転位入門」を兼ねる**(コットレル雰囲気・GPゾーンの各記事が転位の基礎説明を本記事に委ねる)。したがって S1〜S2 は転位そのものの導入に充て、S3 以降で本題の増殖機構に進む。

---

## 1. 学習目標

読み終えた読者が、次のことをできるようになる。

1. 理想強度(〜GPa)と実測の降伏応力(〜MPa)の約 1000 倍の開きを、「一斉のすべり」と「転位による一列ずつのすべり」の違いで説明できる。
2. 転位を線張力 $T \approx \mu b^2/2$ をもつ弦とみなし、応力下の張り出し半径 $R = T/(\tau b)$ を使って考えられる。
3. 両端を固定された転位が半円になる瞬間が「引き返せない点」である理由($\tau_{req}$ が半円で最大になること)を、図を操作しながら説明できる。
4. フランク・リード源の 1 サイクル — 張り出し → 固定点の回り込み → 逆向き線分どうしの相殺 → ループ放出 → 元の線分の再生 — を順に説明できる。
5. 作動応力 $\tau_c \approx \mu b / L$ を使い、源の長さや障害物間隔と材料の強さの関係(析出強化・オロワン機構への入口)を見積もれる。

## 2. 前提知識と関連記事

- **仮定する知識**: 高校物理(力のつり合い、応力の初歩)。結晶=原子の規則配列、というイメージ。
- **前提記事**: なし(本記事がサイトの転位入門を兼ねる)。
- **相互リンク**:

  - [GPゾーン](/articles/gp-zones/) — S6 の「障害物間隔が強さを決める」から析出強化への接続として言及。

## 3. 章立てとナラティブ

記事全体の筋: **2 つの謎を順に解く。謎①「金属はなぜ理論値より 1000 倍も弱いのか」→ 転位。謎②「では転位はすぐ結晶の外へ抜けて尽きてしまうはずなのに、なぜ大きなすべりが起き、しかも変形すると転位は増えるのか」→ フランク・リード源。** 弦の物理(線張力)を1つずつ積み上げ、半円の不安定化という力学的な山場を越えて、増殖の一部始終を見せる。

### S1. 金属はなぜ「柔らかい」のか(導入・謎①)

スプーンを曲げると元に戻らない — そのとき内部で何かが起きている、という日常のフックから入る。結晶のすべりを「原子面を一斉に滑らせる」モデルで見積もると必要応力は $\tau_{th} \approx \mu/30 \sim$ 1 GPa 級。ところが高純度アルミ単結晶は 1 MPa 前後で塑性変形を始める。読者自身に両方を「引かせて」約 1000 倍の開きを体感させ、じゅうたんのしわの比喩(静的図 S-1)とともに、しわ=転位を導入する。

- 使用図版: 図1 `theoretical-strength`、静的図 S-1
- 必ず触れる点: フレンケルの見積もりの考え方(桁の話であること)。「一斉」対「一列ずつ」。ゲージが対数目盛である理由。

### S2. 一列ずつ滑る — 転位の歩き方

刃状転位の正体(余分な半原子面の端、⊥記号)と、1 ステップの動き = 結合のつなぎ替えを、コマ送りで観察させる。転位が結晶を横断し終えると上下が $b$ だけずれ、表面に段差が生まれる。バーガース回路のトグルで、ずれの単位 $b$(バーガースベクトル)が転位に「刻印」されていることを確認する。転位線に向き(線方向 $\xi$)を付けて考えると後で整理しやすいことを一言添える(S5 の伏線)。らせん転位・混合転位の存在は静的図と本文で軽く紹介するに留める。

- 使用図版: 図2 `glide-step`
- 必ず触れる点: $b$ の定義(回路の閉じ残り)。転位が通過した数 × $b$ = すべり量。すべり面の概念。

### S3. 転位は張られた弦 — 線張力

転位はまわりの格子を歪ませるため、単位長さあたりのエネルギー $E \approx \mu b^2/2$ を持つ。だから短く・まっすぐでいたい — これが線張力 $T$ である。一方、応力は転位線を単位長さあたり $F = \tau b$ で押す(ピーチ・ケーラー力の平面版)。実際の結晶では転位は析出物や他の転位(林転位)との交点で**両端を固定**されている。固定された長さ $L$ の線分に応力をかけると円弧に張り出し、$\tau = T/(bR)$ が成り立つことをスライダーで確かめる。応力を上げるほど $R$ は小さくなる… どこまで小さくなれるのか? と問いを残して次節へ。

- 使用図版: 図3 `line-tension-bow`
- 必ず触れる点: $T \approx \mu b^2/2$ の由来(桁)。固定点の実体(析出物・林転位・節点)。$R$ の下限への疑問の提示。

### S4. 引き返せない半円

弧の幾何から、固定点間隔 $L$ の弧が取れる最小の半径は $R = L/2$(半円)である。形を保つのに必要な応力 $\tau_{req}(h) = T/(bR(h))$ をたわみ $h$ の関数として描くと、**半円でピーク**になる山型になる — 半円を越えると、同じ応力がむしろ過剰になり、転位は自発的に広がり続ける。ゴム風船(膨らませ始めが一番硬い)の比喩を添える。臨界応力 $\tau_c = 2T/(bL) \approx \mu b/L$ をここで導く。

- 使用図版: 図4 `critical-semicircle`
- 必ず触れる点: 山型カーブの読み方(左側=安定、右側=引き返せない)。$\tau_c \approx \mu b/L$ の導出と、$L=1\,\mu\mathrm{m}$ のとき約 7 MPa(アルミ)という実感的な数値 — S1 の「MPa で降伏する」事実と桁が合うこと。

### S5. ループが湧き出す — 源の一回転(中心節)

半円を越えた転位の運命をシミュレーションで最後まで見届ける。張り出した線は固定点を回り込み、固定点の背後で左右の腕が出会う。ここで鍵になるのが S2 で仕込んだ「線の向き」: 出会う 2 本は**同じ $b$・逆向きの線方向**なので互いに打ち消し合い(相殺)、その瞬間に外側は閉じたループとして切り離され、内側には元の線分が再生する。応力がかかり続ける限りこのサイクルは繰り返され、同心円状のループが次々と放出される — 転位の「泉」である。応力を 0 に戻すとループが線張力で縮んで消えることも試させる(摩擦のない理想結晶での話であることを図注で明示)。

- 使用図版: 図5 `source-operation`(本記事の中心図版)、静的図 S-2(ループ上の刃状/らせん成分と線の向き)
- 必ず触れる点: 相殺の理由(同じ $b$・逆の $\xi$)。1 ループ = すべり $b$ の寄与。放出カウンタと「すべり量 $n b$」の読み。

### S6. 源の長さが強さを決める

図5 のミニ版で「実験」する: 長さ $L$ を変えて臨界応力を測り、グラフに点を打っていくと $\tau_c \propto 1/L$ が浮かび上がる(横軸を $1/L$ に切り替えると直線に乗る)。これはそのまま材料設計の言葉になる — 障害物の間隔を詰めれば転位は張り出しにくくなり、材料は強くなる(オロワン機構、GPゾーン記事への接続)。すべり線の段差が数百〜数千 $b$ に達するという古典的観察も、1 つの源が繰り返し働いた足跡として回収する。

- 使用図版: 図6 `critical-stress-explorer`
- 必ず触れる点: 測定→法則発見の流れ(理論線は点が 3 つ以上たまってから重ねる)。$\tau_c = \mu b/L$ の数値感覚。析出強化への一言。

### S7. 増えた転位のゆくえ(発展)

湧き出したループは無限に走れるわけではない。結晶粒界などの壁に堰き止められると、後続のループと押し合って**パイルアップ**をつくり、その反発(背応力)が源に届いて源を止める。壁までの距離が短いほど源は早く止まる — 結晶粒を細かくすると強くなる(ホール・ペッチ則)方向感覚がここから得られる。増えた転位どうしの絡み合いが加工硬化の入口であること、シリコン中で実際に観察されたフランク・リード源(Dash の古典実験、静的図 S-3)にも触れ、机上の機構ではないことを示す。

- 使用図版: 図7 `pileup-backstress`、静的図 S-3
- 必ず触れる点: 背応力で源が「自己停止」すること。発展節であり読み飛ばし可能である旨を冒頭に明記。

### まとめ

謎①(1000 倍弱い→転位)と謎②(転位は湧く→フランク・リード源)を 5 行で回収し、$\tau_c \approx \mu b/L$ を「材料の強さのものさし」として再掲。続きとして [コットレル雰囲気](湧いた転位を捕まえる話)と [GPゾーン](障害物を人工的に撒く話)へ誘導。

### 5.1 図1 `theoretical-strength` — 一斉すべり vs 転位すべり

**表示するもの / 初期状態**
- 2D 結晶ブロック(格子 約 20×10、側面視)。中央の水平面がすべり面。上半分に「取っ手」。
- 応力ゲージ: **対数目盛**(0.1 MPa〜3 GPa)。目盛上に「実測の降伏(〜MPa)」「理想強度(〜GPa)」の 2 つの参照マークを常時表示。
- 初期状態: モード=一斉にすべらせる。静止。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| モード | segmented | 一斉にすべらせる / 転位ですべらせる | 一斉 |
| 上半分を引く | ドラッグ(ポインタ)+ 代替の自動再生 playPause | — | — |
| リセット | reset | — | — |

**モデルと式**
- **一斉モード**: 上ブロック位置 $x$ の抵抗はフレンケル型 $\tau(x) = \tau_{th}\sin(2\pi x/b)$。ドラッグは「カーソルとブロックをバネで繋ぐ」準静的モデル: $k(x_{cursor}-x) = \tau(x)A$ の安定解にブロックを置く。ピークを越えた瞬間に次の谷へスナップ(スティック・スリップ)。ゲージはバネ力から換算した応力を表示し、ピークで GPa 帯に達する。
- **転位モード**: 同じ結晶の左端に刃状転位を挿入。小さな応力(見かけ上 MPa 帯)で転位が右へ走り抜け、通過後に上下が $b$ ずれ、右表面に段差。ドラッグ量→転位位置の対応は簡略で良い(定数の小さな摩擦のみ)。
- どちらのモードでも**最終状態は同一**($b$ のずれ)であることを、完了時に短いメッセージで明示。
- 簡略化の明示(図注): 2D・フレンケル正弦モデル・桁を示すための模式であること。

**実装方式**: 2D / onFrame(スナップとドラッグ応答)。

**受け入れ基準**
- [ ] 一斉モードでスティック・スリップ(粘って→一気に滑る)が体感できる
- [ ] ゲージ上でピーク値が転位モードの約 1000 倍(対数目盛で 3 目盛差)と読める
- [ ] 2 つのモードの最終状態が同じずれになる
- [ ] ドラッグ不能環境(キーボードのみ)でも自動再生で全内容を確認できる

### 5.2 図2 `glide-step` — 転位の歩き方

**表示するもの / 初期状態**
- 2D 格子 約 24×12(側面視)、中央に刃状転位(⊥)。すべり面を破線で表示。応力の向きを示す矢印ペア(上向き=右、下向き=左)。
- 読み出し: 「上下のずれ: n b」。転位が右端に到達すると表面に段差(レッジ)を描画。
- 初期状態: 転位は左寄り 1/4 の位置。静止。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| 1 格子ぶん動かす | button(← / → の 2 方向) | — | — |
| 連続再生 | playPause(2 ステップ/秒) | — | 停止 |
| バーガース回路を表示 | toggle | on/off | off |
| リセット | reset | — | — |

**モデルと式**
- 1 ステップ = 転位芯の隣の原子列の結合つなぎ替え。該当する原子(2〜3 個)をハイライトし、約 250ms のイージングで新位置へ移動。⊥マーカーが 1 格子分移動。厳密な原子軌跡は要求しない(半面の受け渡しが伝わる模式で良い)。
- バーガース回路: 転位を囲む長方形回路(例 8×8 原子)を右回りに描き、閉じ残りの矢印を `--mat-defect` で表示、ラベル「$\vec b$」。比較用に、完全結晶側にも同じ回路を薄く描き「閉じる」ことを見せる。
- 簡略化の明示(図注): 2D 単純格子。パイエルス障壁(1 ステップごとの小さな峠)は本文で一言触れるが描画しない。

**実装方式**: 2D / onFrame(遷移アニメ中のみ実描画、待機中はアイドル)。

**受け入れ基準**
- [ ] ステップ実行のたびに「ずれ」カウンタが増え、⊥ が 1 格子動く
- [ ] 右端到達で段差が現れ、左右往復もできる
- [ ] 回路トグルで閉じ残り= $b$ が明確に見える(完全結晶側は閉じる)
- [ ] ボタン連打しても遷移が破綻しない(キュー処理 or 遷移中は無効化)

### 5.3 図3 `line-tension-bow` — 張られた弦

**表示するもの / 初期状態**
- 上面視。固定点 2 つ(間隔 $L$、`--mat-precip`)。その間に転位線(`--mat-defect`)。
- 読み出し: $R/L$、$\tau/\tau_c$(%)。
- 初期状態: τ=0(直線)。ガイド off。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| せん断応力 τ | slider | 0〜0.95 τ_c(MPa 併記) | 0 |
| 力を表示 | toggle | on/off(線上に分布力 τb の矢印列+固定点に接線方向の張力 T 矢印) | off |
| 半径の円を表示 | toggle | on/off(弧を含む半径 R の円を薄く表示) | off |

**モデルと式**
- 準静的・解析解: 与えられた τ に対し $R = T/(\tau b)$、弧は固定点を通る半径 R の円弧(たわみ $h = R - \sqrt{R^2 - L^2/4}$)。τ 変更時は現在形状から目標形状へ 150ms のイージング。
- 簡略化の明示(図注): 線張力一定の近似(刃状/らせんでエネルギーが異なる効果は無視)。

**実装方式**: 2D / requestRender。

**受け入れ基準**
- [ ] τ を上げると弧が深くなり、R 読み出しが単調減少する
- [ ] 「半径の円」トグルで弧と円の一致が確認できる
- [ ] τ=0.95τ_c で弧が半円の一歩手前で止まる(次図への引き)

### 5.4 図4 `critical-semicircle` — 引き返せない半円

**表示するもの / 初期状態**
- 左パネル: 図3 と同じ上面視の弧。頂点にドラッグハンドル(上下)。
- 右パネル: 横軸 $h/L$(0.05〜1.2)、縦軸 $\tau_{req}$ のカーブ。$h=L/2$ のピークに「$\tau_c$」注記。ピークより右の領域を薄く塗り、ラベル「引き返せない(同じ応力で加速し続ける)」。現在の形状に対応するマーカーがカーブ上を動く。
- 初期状態: モード=形を操作、$h/L = 0.2$。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| モード | segmented | 形を操作(h) / 応力を操作(τ) | 形を操作 |
| たわみ h | ドラッグハンドル+slider | 0.05〜1.2 L | 0.2 L(形モードのみ) |
| せん断応力 τ | slider | 0〜1.1 τ_c | 0.4 τ_c(応力モードのみ) |

**モデルと式**
- 弧の幾何: $R(h) = \dfrac{L^2}{8h} + \dfrac{h}{2}$(全 h で有効。h>L/2 は優弧)。$\tau_{req}(h) = T/(b\,R(h))$。ピークは $h=L/2$ で $\tau_c = 2T/(bL)$。
- 応力モード: τ<τ_c では安定解(小さい方の根)$h_s(\tau)$ に 150ms で整定。τ≥τ_c にすると h が増加し続ける短いランナウェイ演出(1.5 秒)ののち「半円を越えました → 続きは次の図で」のメッセージとともに自動で τ=0.9τ_c に戻す。
- 簡略化の明示: 図3 と同じ。

**実装方式**: 2D / requestRender + 整定・ランナウェイの短い遷移のみ onFrame。

**受け入れ基準**
- [ ] ハンドルを動かすと左右パネルのマーカーが完全連動する
- [ ] ピーク位置が h=L/2 にあり、τ_c 注記と図3 の τ_c 表示が一致する
- [ ] 応力モードで τ を τ_c 未満に戻すと安定形状へ戻る(可逆)、τ_c 以上でランナウェイ演出が出る
- [ ] ドラッグはタッチでも操作でき、キーボード(スライダー)でも全操作可能

### 5.5 図5 `source-operation` — 源の一回転(中心図版)

**表示するもの / 初期状態**
- 上面視の広いステージ。中央に固定点 2 つ(間隔 L=ステージ幅の 1/4 程度)と転位線。放出済みループも同スタイルで描画。
- 読み出し: 放出ループ数 $n$、すべり量 $nb$(nm 換算)。τ スライダーには τ_c の位置に目盛マーク。
- 初期状態: τ = 1.1 τ_c、再生中(reduced-motion 時は停止)。線の向き表示 off。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| せん断応力 τ | slider | 0〜1.5 τ_c(MPa 併記、τ_c に目盛) | 1.1 τ_c |
| 線の向きを表示 | toggle | on/off(線上に矢羽根) | off |
| 再生/一時停止・リセット | playPause / reset | — | — |

**モデルと式(節点法・過減衰)**
- 転位線を節点列 $P_i$ で表す。各節点: 接線 $\hat t$、法線 $\hat n$($\hat t$ を +90° 回転)、符号付き曲率 $\kappa$(隣接 3 点の外接円で評価)。
- 速度: $v_i = M\,(\tau b - T\kappa_i)\,\hat n_i$(過減衰、明示オイラー+`fixedStep`。無次元 $M=1$、dt は安定側に固定)。円弧平衡 $\tau b = T/R$ を自動的に満たす。
- **リメッシュ**: 目標間隔 $s_0 = L/40$。1.5$s_0$ 超の線分は分割、0.5$s_0$ 未満は結合(固定点隣接は除外)。
- **相殺(再結合)**: 非隣接の線分ペアで、距離 < $1.2 s_0$ かつ接線がほぼ逆向き($\hat t_a\cdot\hat t_b < -0.7$)のとき、つなぎ替えを実行 → 「固定点間の新しい開いた線分」+「閉じたループ」に分離する。ループの向きは符号付き面積で検査し、法線が外向き(拡大方向)になるよう必要なら反転。
- ループ: 同じ運動則で拡大。ステージ余白を越えたらフェードアウトして除去、$n{+}{+}$(「結晶表面へ抜けた」扱い)。τ を下げると $R < T/(\tau b)$ のループは**縮んで消える**(格子摩擦ゼロの理想化。図注に明示し、本文でも一言)。
- 乱数不使用・完全決定論(reset 再現)。数値安全策: 速度クランプ、NaN 検出時は自動 reset(開発時ログ)。

**実装方式**: 2D / onFrame + fixedStep。節点数の目安: 源 40〜80 点、同時ループ 2〜3 本(各 60〜120 点)。相殺判定は総当たりで可(点数が小さい)。

**受け入れ基準**
- [ ] τ=1.1τ_c で周期的にループが放出され、同心状に 2〜3 本が画面内に共存する
- [ ] 相殺の瞬間、向き表示 on で「出会う 2 本の矢羽根が逆向き」なのが確認できる
- [ ] τ<τ_c に下げると: 源は弧のまま静止し、既存ループは縮んで消える。τ=0 で完全に直線へ戻る
- [ ] カウンタとすべり量表示がループ消滅(外側到達)のタイミングで増える
- [ ] 5 分間の連続動作で破綻(NaN・自己交差の暴走)なし、モバイルで 60fps(最低 30fps)

### 5.6 図6 `critical-stress-explorer` — τ_c を測る

**表示するもの / 初期状態**
- 左: 図5 の縮小版ステージ(現在の L で源のみ表示。ループは 1 本目の放出を検出したら即フェード)。
- 右: 散布図。横軸 $L$(0.2〜3 μm)、縦軸 $\tau$(0〜40 MPa)。測定点が溜まっていく。
- 初期状態: L=1.0 μm、点なし、理論線 off。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| 源の長さ L | slider | 0.2〜3.0 μm(step 0.1) | 1.0 μm |
| 臨界応力を測る | button(押すと自動ランプ開始) | — | — |
| 横軸を 1/L にする | toggle | on/off | off |
| 理論線 τ=μb/L を重ねる | toggle | on/off(**測定点が 3 点未満のときは無効化**) | off |
| 測定をやり直す | reset(点を全消去) | — | — |

**モデルと式**
- 測定: τ を 0 からゆっくり自動ランプ(遅いほど真値に近づく。既定レートは τ_c を約 3 秒で通過する程度)し、**最初の相殺イベント**発生時の τ を記録して点を打つ。測定値が理論よりわずかに高側に出る(動的効果)ことは許容し、図注で一言。

- [ ] 理論線トグルは 3 点未満で無効(発見が先、式が後 — デザイン原則 4)
- [ ] 測定中は操作をロックし、進行中の τ 値が読める
- [ ] L=0.2 μm と 3 μm で測定時間が極端に変わらない(ランプレートを L に応じ調整)

### 5.7 図7 `pileup-backstress` — 押し戻される源(発展)

**表示するもの / 初期状態**
- 上面視を 1 次元に簡約: 左端に源(⊥ とミニ弧のアイコン)、右端に壁(結晶粒界、太い縦線)。源から放出された転位を ⊥ マークの列で表示(位置のみの 1D モデル)。
- 読み出し: 放出数 $n$、源に届く背応力 $\tau_{back}$ のゲージ(τ_app との比較バー)。
- 初期状態: d=2 μm、τ_app=1.5τ_c、再生中。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| 壁までの距離 d | slider | 0.5〜5 μm | 2 μm |
| 加える応力 τ_app | slider | 1.0〜3.0 τ_c | 1.5 τ_c |
| 再生/一時停止・リセット | playPause / reset | — | — |

**モデルと式(1D パイルアップ)**
- 転位位置 $x_i \in (0, d)$。過減衰運動: $\dot x_i = M\big(\tau_{app} b - \sum_{j\ne i} \dfrac{K b}{x_i - x_j} - f_{wall}(x_i)\big)$、$K = \dfrac{\mu b}{2\pi(1-\nu)}$(同符号刃状転位の反発)。壁は不可侵(強い短距離反発)。
- 源: $\tau_{eff} = \tau_{app} - \sum_j \dfrac{K b}{x_j}/b$ が $\tau_c$ を上回っている間、一定間隔で新しい転位を $x=0^+$ に追加(図5 の詳細動作は既習として省略した旨を図注に明示)。$\tau_{eff} < \tau_c$ で停止 → 「源が止まった」表示。
- 観察点: 壁際ほど間隔が詰まる古典的パイルアップ形状。d 大 → 停止までの n 大(粒径と強さの関係の入口。ホール・ペッチ則は名前の紹介に留める)。
- 簡略化の明示: 1 次元・直線転位の弾性相互作用のみ。

**実装方式**: 2D / onFrame + fixedStep(n ≤ 30 程度、総当たりで十分)。

**受け入れ基準**
- [ ] 放出が進むにつれ τ_back ゲージが上がり、τ_eff < τ_c で放出が自動停止する
- [ ] d を 2 倍にすると停止時の n が明確に増える
- [ ] 壁際の間隔圧縮(パイルアップの形)が見て取れる
- [ ] reset 再現(決定論)
