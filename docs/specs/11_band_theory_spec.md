## 1. 学習目標

読了・操作後に、読者が次のことをできるようになる。

1. 自由電子の $E = \hbar^2k^2/2m$ の放物線を出発点に、**周期ポテンシャルがブリルアンゾーン境界 $k = \pm\pi/a$ でバンドギャップを開く**ことを、逆格子空間記事のブラッグ条件と結び付けて説明できる。
2. ギャップの正体を「ゾーン境界で作れる 2 つの定在波($\cos$ 型・$\sin$ 型)が、原子核とどう重なるかでエネルギーが分かれること」として説明できる(**曖昧な「束縛されるから」で済ませない**)。
3. クローニッヒ・ペニー模型を操作し、ポテンシャルの深さ・幅・周期がバンド幅とギャップ幅をどう変えるか、また **ポテンシャル → 0 で自由電子の放物線に戻る**ことを確かめられる。
4. 拡張ゾーン表示と還元ゾーン表示が同じものの別の描き方であることを、$\mathbf{k} \to \mathbf{k} + \mathbf{G}$ の周期性から説明できる。
5. 金属・半導体・絶縁体の違いが**電子の数ではなくバンドの埋まり方(空席の有無)とギャップの大きさ**で決まることを述べ、半導体と絶縁体の境界が連続的であることも言える。
6. (発展)実際の半導体のバンド図で直接遷移と間接遷移を読み分け、バンドの曲率が有効質量になることを説明できる。

### 2.3 表記と慣習(記事全体の約束)

**この記事は $\mathbf{k}$ に $2\pi$ を付ける物理学の慣習を採用する。** 逆格子空間記事は結晶学の慣習($q = 1/\lambda$、$|\mathbf{g}| = 1/d$、$2\pi$ なし)を採用しているので、両者の橋渡しを **S2 の本文とコラムで明示的に行う**(式 E3)。

| 量 | 本記事(物理学の慣習) | 逆格子空間記事(結晶学の慣習) | 関係 |
|---|---|---|---|
| 波数 | $k = 2\pi/\lambda$ [nm⁻¹] | $q = 1/\lambda$ [nm⁻¹] | $k = 2\pi q$ |
| 逆格子ベクトル | $G = 2\pi/a$ | $g = 1/a$ | $G = 2\pi g$(記事 05 の式 E11 と同じ) |
| ゾーン境界 | $k = \pi/a$ | $q = 1/(2a) = g/2$ | ブラッグ条件「$g$ の半分」と同じ位置 |

$E = \hbar^2k^2/2m$ と $k = \pm\pi/a$ を書くために $2\pi$ 付きの $k$ が要る、というのが採用理由である。**この対応表は記事本文(S2)にも同じ形で載せる**。ここがずれると読者は 2 記事を繋げられない(母体仕様 §2-1)。

**単位**: エネルギーは eV、波数は nm⁻¹、長さは nm。定数は

$$\frac{\hbar^2}{2m_e} = 0.0380998\ \text{eV·nm}^2$$

を `lib/constants.ts` に 1 箇所だけ置き、全図版がこれを参照する(母体仕様 §4 マジックナンバー禁止)。既定の格子周期は $a = 0.50$ nm(ゾーン境界 $\pi/a = 6.28$ nm⁻¹、そこでの自由電子エネルギー 1.50 eV)。

**記号と色**: 電子 `--mat-electron`、許容帯 `--mat-band`、バンド端・準位線 `--mat-level`、原子核・周期ポテンシャル `--mat-matrix`、$k$ 空間のゾーン境界 `--mat-recip`、光子 `--mat-beam`。$\cos$ 型と $\sin$ 型の定在波は**新色を作らず**、実線 / 破線と濃淡で区別する(§5.0)。

## 3. 章立てとナラティブ

本文は h2 × 7 節 + まとめ + もっと知るには。各節で新しく導入する要素は 1 つに絞る(母体仕様 §2-2)。

|---|---|---|---|

| 2 | 周期ポテンシャルを入れる | 図2 | ゾーン境界でのブラッグ反射とギャップの発生 |
| 3 | 2 つの定在波 — 隙間の正体 | 図3 | $\cos$ 型 / $\sin$ 型定在波と電子密度、$2\lvert V_1\rvert$ |
| 4 | 模型で確かめる | 図4 | クローニッヒ・ペニー模型、許容帯 / 禁制帯 |

各節の要旨:

**1. まず自由な電子から** — 同じ「原子が規則正しく並んだ固体」なのに、銅は電気を通しダイヤモンドは通さない。組成でも密度でもないなら何が違うのか、と問いを立てる。まずポテンシャルがゼロの箱に電子を入れる。許されるエネルギーは $E = \hbar^2k^2/2m$ の放物線で、$k$ は逆格子空間記事で扱った波数そのもの($2\pi$ の有無だけが違う — §2.3)。電子を下から詰めるとフェルミ波数 $k_F$ まで埋まる。**この段階では隙間がない**: どんなエネルギーも取れる。金属の電子はおおよそこれで説明できてしまう、と述べて次節へ。

**2. 周期ポテンシャルを入れる — ゾーン境界で何かが起きる** — 原子核が周期 $a$ で並ぶと、電子波はそれを感じる。ここで逆格子空間記事の回折条件がそのまま効く: $k = \pm\pi/a$(ブリルアンゾーン境界)で電子波はブラッグ反射を受け、進行波でいられなくなる。まず $2\pi$ の対応表(§2.3)を提示して 2 記事の記号を繋ぎ、そのうえで図2 のスライダーでポテンシャルを 0 から上げ、放物線がゾーン境界で割れる様子を見せる。**ポテンシャル 0 のとき図1 の放物線と完全に一致していること**を読者に確認させてから上げさせる。

**3. 2 つの定在波 — 隙間の正体(記事の山場)** — ゾーン境界では、右向きと左向きの進行波が同じ重みで混ざるので、定在波が 2 通り作れる。$\cos$ 型は腹が原子核の上に来て引力を強く感じ、**エネルギーが低い**。$\sin$ 型は節が原子核の上に来て引力を感じにくく、**エネルギーが高い**。同じ $k$ なのにエネルギーが 2 通りある — **この差がバンドギャップである**。図3 で両方の波動関数と電子密度を重ねて描き、原子核の位置との関係を読者自身に確かめさせる。ギャップの大きさが周期ポテンシャルの第 1 フーリエ成分 $V_1$ の 2 倍になること(式 E6)も示す。

**4. 模型で確かめる — クローニッヒ・ペニー(中心図版)** — 定性的な話を、実際に計算できる 1 次元模型で確かめる。周期 $a$ の障壁(高さ $U_0$・幅 $b$)を並べ、$\cos(ka) = f(E)$ という 1 本の式から許容帯と禁制帯が出る。$\lvert f(E)\rvert > 1$ の $E$ には波数が存在しない = 禁制帯である。障壁を深くするとギャップが広がり、周期を変えるとゾーンの幅が変わり、**ポテンシャルを 0 に戻すと S1 の放物線に戻る**(連続性の確認は必ず行わせる)。1 次元の理想模型であることを図注で明示する。

**5. 折りたたむ — 拡張ゾーンと還元ゾーン** — バンドは $\mathbf{k} \to \mathbf{k} + \mathbf{G}$ の周期性を持つので、第 1 ブリルアンゾーンに折り返して表示できる。トグルで拡張ゾーン ⇄ 還元ゾーンを切り替え、同じものの別の描き方であることを見せる。ここで 3D のブリルアンゾーン(FCC の逆格子 = BCC 配列と、その第 1 BZ = 切頂八面体)を出し、逆格子空間記事の図7 と接続する。$\Gamma$・X・L という対称点の名前をここで導入し、S7 の横軸の準備とする。

**6. 3 つに分かれる — 金属・半導体・絶縁体** — バンドを電子で埋めていく。1 次元の 1 バンドには 1 原子あたり 2 個(スピン 2 通り)入るので、**価電子数が奇数なら途中まで、偶数ならちょうど埋まりきる**。途中まで = すぐ上に空席がある = 電場で加速できる = 通す(金属)。埋まりきり + 隙間が大きい = 通さない(絶縁体、ダイヤモンド 5.5 eV)。埋まりきり + 隙間が小さい = 熱で少数が飛び越える(半導体、Si 1.1 eV)。**「通す / 通さない」は電子の数ではなく空席の有無で決まる**ことを強調し、半導体と絶縁体の境界は連続的で、1.1 eV と 5.5 eV は例であって定義ではないことも述べる。

**7. 本物のバンド図を読む(発展)** — 実際の半導体のバンド図は、$\Gamma$-X-L のような対称点に沿った $E$-$k$ 図として描かれる。GaAs は価電子帯の頂上と伝導帯の底が同じ $k$(直接遷移)で、光を出すのが得意。Si はずれている(間接遷移)ので、光を出すにはフォノンの助けが要る — LED やレーザーが Si でなく化合物半導体で作られる理由である。バンドの曲率が電子の「重さ」になること($m^* = \hbar^2/(d^2E/dk^2)$)、価電子帯の頂上では曲率が逆符号 = **負の有効質量**になり、これが次々記事の正孔の概念に繋がることにも触れる。バンド理論全体が **1 電子近似**の上に立っていることをここで明かす。この節は読み飛ばし可能である旨を冒頭に書く。

**8. まとめ** — 「隙間の有無が世界を分ける」で回収する。静的図 S2(自由電子 → 周期ポテンシャル → 3 分類の 1 枚絵)で全体を振り返り、次記事 [フェルミ準位](/articles/fermi-level/) へ「では隙間があるとき、電子は実際にどこまで埋まっているのか」として渡す。

### 5.4 図4 `kronig-penney` — 模型で確かめる(中心図版)

**表示するもの / 初期状態**
3 領域構成(1 枚の canvas を分割)。
上帯(高さ 26%): 周期ポテンシャル $V(x)$ の断面(`--color-hairline` の階段 + `--mat-matrix` の原子。障壁部分に薄い塗り)。周期 $a$・障壁幅 $b$・高さ $U_0$ の寸法ラベル。

右下(幅 96px): $E$ 軸の帯。許容帯を `--mat-band` の塗り + バンド端線、禁制帯を塗りなし + `--color-hairline` の破線で示し、第 1 ギャップに幅の寸法線を付ける。
初期は $U_0 = 4$ eV、$b = 0.15$ nm、$a = 0.50$ nm。

**操作パラメータ**

| 名前 | 部品 | 範囲 | 初期値 | 単位 |
|---|---|---|---|---|
| 障壁の高さ $U_0$ | slider | 0〜10(step 0.1) | 4 | eV |
| 障壁の幅 $b$ | slider | 0.02〜0.30(step 0.01) | 0.15 | nm |
| 周期 $a$ | slider | 0.30〜0.80(step 0.01) | 0.50 | nm |
| 自由電子の放物線を重ねる | toggle | — | on | — |
| リセット | reset | — | — | — |

読み取り値: 第 1 バンド幅 [eV]、第 1 ギャップ [eV]、ゾーン境界 $\pi/a$ [nm⁻¹]。

**背後のモデルと簡略化**
クローニッヒ・ペニー模型(式 E7)。井戸幅 $w = a - b$、障壁高さ $U_0$、$\alpha = \sqrt{E/C}$、$\beta = \sqrt{(U_0-E)/C}$、$\gamma = \sqrt{(E-U_0)/C}$、$C = \hbar^2/2m$ として

$$f(E) = \cos(\alpha w)\cosh(\beta b) + \frac{\beta^2-\alpha^2}{2\alpha\beta}\sin(\alpha w)\sinh(\beta b) \quad (E < U_0)$$
$$f(E) = \cos(\alpha w)\cos(\gamma b) - \frac{\alpha^2+\gamma^2}{2\alpha\gamma}\sin(\alpha w)\sin(\gamma b) \quad (E > U_0)$$

で $\cos(ka) = f(E)$。$\lvert f(E)\rvert > 1$ の $E$ が禁制帯である。実装上は $\sin(\alpha w)/\alpha = w\,\mathrm{sinc}(\alpha w)$ の形に書き換え、$\alpha \to 0$・$\gamma \to 0$ でも安全に評価する。バンド端は $f(E) = \pm1$ の根、バンド内の $E(k)$ は $f(E) - \cos(ka) = 0$ の根で、**いずれも区間二分法**(固定反復回数 60 回)で求める。フレーム内の新規割当ては行わない(結果は使い回す `Float64Array` に書く)。
簡略化(図注に明示): **1 次元の理想模型**であり、実際の 3 次元結晶のバンドはこれより複雑で対称点ごとに異なる(S7・図7 と対比させる)。電子間相互作用は無視している(1 電子近似)。

**実装方式**: 2D Canvas / `requestRender`。パラメータ変更時のみ再計算。

**図注(案)**: 「図4. 周期的な障壁を並べた 1 次元模型(クローニッヒ・ペニー模型)のバンド構造。右の帯は、電子が取れるエネルギー(許容帯)と取れないエネルギー(禁制帯)。障壁の高さを 0 に戻すと、図1 の放物線に戻る。実際の 3 次元結晶のバンドはこれより複雑で、方向ごとに違う。」

**alt(案)**: 「上に周期的な障壁と原子の並び、左下にエネルギーと波数の曲線、右下にエネルギー軸の帯。障壁を高くすると曲線の切れ目が広がり、帯の許容帯が狭く、禁制帯が広くなる。障壁の高さを 0 にすると曲線は 1 本の放物線に戻る。」

**受け入れ基準**
- [ ] $U_0 \to 0$ で全バンドが自由電子の放物線に一致する(ゴーストと重なる。単体テストでも担保)
- [ ] $U_0$ を上げると第 1 ギャップが単調に増え、第 1 バンド幅は単調に減る
- [ ] $a$ を変えるとゾーン境界の位置と読み取り値 $\pi/a$ が連動する
- [ ] 右の帯の許容帯 / 禁制帯の境界が、左の $E$-$k$ 図のバンド端と同じ高さに来る(誤差 1px 未満)
- [ ] スライダー操作中も 60fps を保つ(再計算は 1 回 / 変更)

**表示するもの / 初期状態**

右(幅 110px)= $E$ 軸の帯。許容帯(`--mat-band`)、占有部分の塗り(`--mat-electron`)、禁制帯(破線)、$E_F$ 線。
初期は価電子数 1(金属)、$U_0 = 4$ eV。

**操作パラメータ**

| 名前 | 部品 | 範囲 | 初期値 | 単位 |
|---|---|---|---|---|
| 1 原子あたりの価電子数 | stepper(± ボタン) | 1〜4 | 1 | 個 |
| 障壁の高さ $U_0$(= ギャップの大きさ) | slider | 0〜10(step 0.1) | 4 | eV |
| 空席を示す | toggle | — | on | — |
| リセット | reset | — | — | — |

読み取り値: 分類(金属 / 半導体 / 絶縁体)、最高被占バンドの埋まり具合 [%]、ギャップ [eV]、300 K で飛び越える割合の目安 $\exp(-E_g/2k_BT)$。

**背後のモデルと簡略化**
バンドは図4 と同じ KP(§5.4)。1 次元の 1 バンドには 1 原子(1 周期)あたり 2 個の電子が入る(スピン 2 重)。価電子数 $Z$ に対し、$\lfloor Z/2 \rfloor$ 本のバンドが満杯になり、$Z$ が奇数なら次のバンドが半分だけ埋まる。分類は次の規則で行い、**しきい値は表示上の便宜であって物理的な定義ではないことを図注と本文に明示する**:

- 最高被占バンドが部分的に埋まっている → **金属**
- 埋まりきり、かつ $E_g < 3$ eV → **半導体**
- 埋まりきり、かつ $E_g \ge 3$ eV → **絶縁体**

$\exp(-E_g/2k_BT)$($T = 300$ K)を並べて表示し、境界が連続的であることを数値でも見せる(この量は真性キャリア密度の温度依存の指数部分であり、絶対数ではないことを図注に書く)。

**実装方式**: 2D Canvas / `requestRender`。

**図注(案)**: 「図6. 同じバンド構造でも、電子の詰まり方で性質が変わる。価電子数が奇数ならバンドの途中まで埋まり(すぐ上に空席がある = 金属)、偶数なら埋まりきる。埋まりきったときは隙間の大きさが効き、小さければ熱で少数が飛び越える(半導体)。半導体と絶縁体の境界は連続で、ここでの 3 eV は表示の便宜であって定義ではない。」

**alt(案)**: 「左にバンド図、右にエネルギー軸の帯。価電子数を 1 から 2 に変えると、途中まで埋まっていたバンドがちょうど埋まりきり、分類の表示が金属から半導体に変わる。ギャップを大きくすると絶縁体になる。」

**受け入れ基準**
- [ ] 価電子数 1・3 で金属、2・4 で半導体または絶縁体になる
- [ ] $U_0$ を上げるとギャップが増え、半導体 → 絶縁体の表示に切り替わる
- [ ] 占有部分の上端(最高被占準位)と $E_F$ 線が一致する
- [ ] 「空席を示す」で最高被占準位のすぐ上の空席が見える(金属のときだけ同じバンド内に現れる)

### 5.7 図7 `real-band-diagram` — 本物のバンド図を読む(発展)

**表示するもの / 初期状態**
横軸を対称点 L–$\Gamma$–X に取った $E$-$k$ 図。価電子帯(頂上を $E = 0$ に取る)と伝導帯を `--mat-level` の実線で描く。伝導帯の最小と価電子帯の最大に印を付け、両者を結ぶ遷移矢印(`--mat-beam`)を描く。直接遷移なら垂直な矢印 1 本、間接遷移なら「垂直な光の矢印 + 水平なフォノンの矢印」の 2 本に分けて描く。有効質量の放物線(接触放物線)を on にすると、伝導帯の底と価電子帯の頂上に $E = \pm\hbar^2(k-k_0)^2/2m^*$ の破線を重ねる。
初期は GaAs(直接遷移)。

**操作パラメータ**

| 名前 | 部品 | 範囲 | 初期値 | 単位 |
|---|---|---|---|---|
| 材料 | segmented: GaAs / Si | — | GaAs | — |
| 有効質量の放物線を重ねる | toggle | — | off | — |
| 遷移の矢印を表示 | toggle | — | on | — |
| リセット | reset | — | — | — |

読み取り値: $E_g$ [eV]、遷移の型(直接 / 間接)、$m_e^*/m$、$m_h^*/m$。

**背後のモデルと簡略化**
**このバンド図は模式である**(実測・第一原理計算の結果ではない)。$E_g$ と有効質量は実測値(GaAs: $E_g = 1.42$ eV・$m_e^* = 0.067m$・$m_h^* = 0.51m$、Si: $E_g = 1.12$ eV(間接、伝導帯の底は $\Gamma$-X 線上の X 寄り)・$m_e^* = 0.26m$(横方向)・$m_h^* = 0.49m$)を使い、曲線は**バンド端の曲率がその有効質量に一致するように**構成する(式 E11)。したがって読み取り値と図の曲率は常に整合する。実際のバンドは縮退・スピン軌道分裂・複数の谷を持つが、ここでは各帯 1 本ずつに簡略化していることを図注に明示する。この簡略化と数値の出典は §8 の参考文献に委ねる。

**実装方式**: 2D Canvas / `requestRender`。

**図注(案)**: 「図7. GaAs と Si のバンド図(模式)。GaAs は伝導帯の底と価電子帯の頂上が同じ k にあり(直接遷移)、光をそのまま出せる。Si はずれているので(間接遷移)、光を出すには格子の振動(フォノン)の助けが要る。曲線は各帯 1 本ずつに簡略化した模式で、ギャップと有効質量の値だけを実測値に合わせてある。」

**alt(案)**: 「左から L、中央に Γ、右に X を取った横軸のバンド図。GaAs では伝導帯の最小が Γ の真上にあり、価電子帯の頂上と垂直に結ばれる。Si に切り替えると伝導帯の最小が X 寄りに移り、光の矢印に加えて横向きのフォノンの矢印が必要になる。」

**受け入れ基準**
- [ ] GaAs で伝導帯の底が $\Gamma$、Si で $\Gamma$-X 線上(X の 85% 付近)に来る
- [ ] 読み取りの $E_g$ が図上のバンド端の差と一致する(0.01 eV 以内)
- [ ] 接触放物線の曲率が読み取りの $m^*$ と一致する(単体テストで 2% 以内)
- [ ] 間接遷移では矢印が 2 本(光 + フォノン)に切り替わる
- [ ] 価電子帯の頂上で曲率の符号が逆(負の有効質量)であることが図から読める
