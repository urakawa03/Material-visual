# 記事仕様書 01 — コットレル雰囲気(v1.0)

**slug**: `cottrell-atmosphere` | **カテゴリ**: B. 転位と材料の強さ | **主な描画**: 2D Canvas

本書は母体サイト仕様書(`00_base_site_spec.md`)§12 のフォーマットに従う個別仕様書である。デザイン原則・図版契約・意味パレット等はすべて母体仕様書に準拠する。

**記事仮題**: 「コットレル雰囲気 — 鋼の降伏点はなぜ『歯』になるのか」

---

## 1. 学習目標

読み終えた読者が、次のことをできるようになる。

1. 刃状転位のまわりに圧縮側と引張側があり、溶質原子との相互作用エネルギーが $U \propto \sin\theta / r$ で表されることを、図を操作しながら説明できる。
2. コットレル雰囲気の濃さが「結合エネルギー $U_b$ と熱エネルギー $k_BT$ の競争」(ボルツマン分布)で決まり、その形成速度が拡散(アレニウス型)で決まることを説明できる。
3. 雰囲気による転位の固着(pinning)と引き離し(breakaway)から、軟鋼の上降伏点・下降伏点・リューダース帯を微視的に説明できる。
4. ひずみ時効による降伏点の回復を時間・温度の関数として見積もり、焼付硬化(BH)鋼やスキンパス圧延といった実用技術と結びつけられる。
5. (発展)動的ひずみ時効(セレーション、青熱脆性)を「転位の速度と溶質の拡散速度の追いかけっこ」として説明できる。

## 2. 前提知識と関連記事

- **仮定する知識**: 高校物理(力・応力・ひずみの初歩)、指数関数。結晶格子のイメージ。
- **前提記事**: [フランク・リード源](/articles/frank-read-source/)(推奨)。転位そのものに馴染みがあると §S2 が滑らかに読めるが、本記事は S2 で最小限の転位の説明を自給するため、未読でも完結する。
- **相互リンク**: GPゾーン記事(溶質原子と強化のもう一つの形)、オストワルド成長記事(拡散つながり)へ「まとめ」から言及。

## 3. 章立てとナラティブ

記事全体の筋: **「引張曲線の『歯』の謎」を冒頭に提示し、原子スケールに降りて部品(転位の応力場 → 溶質の居心地 → 雰囲気 → 固着と引き離し)を1つずつ組み立て、最後に試験片スケールへ戻って謎を回収する。** 実用の締めとして焼付硬化まで到達する。

### S1. 鋼の曲線にある「歯」(導入)

焼なまし軟鋼の引張試験を読者自身に「実行」させ、弾性直線の先に現れる小さな歯(上降伏点→下降伏点)と、波打つ平坦部(降伏伸び)を観察させる。アルミニウム合金に切り替えると歯が消えることを見せ、「なぜ鋼にだけ歯があるのか?」を記事の問いとして立てる。プレス成形時のストレッチャーストレイン(表面の縞模様の不良)に一言触れ、答えは炭素原子1個ぶんのスケールにあると予告する。

- 使用図版: 図1 `yield-tooth`
- 必ず触れる点: 上降伏点/下降伏点/降伏伸び(プラトー)という用語の導入。アルミとの対比。「歯」と「縞」が同じ原因であること(詳細は後述と予告)。

### S2. 転位 — 結晶のなかの余分な半面

刃状転位を「余分な半原子面の端」として導入する(⊥記号)。転位が滑って動くことで金属は塑性変形する、という一文で位置づけ、深入りはフランク・リード源記事へ委ねる。本題は転位の**まわり**: 半面が押し込まれた上側は詰まって**圧縮**、下側は間延びして**引張**になっており、この歪みは $1/r$ でしか減衰せず遠くまで届く(遠達性)。オーバーレイ表示と変位の誇張スライダーで体感させる。

- 使用図版: 図2 `edge-dislocation-field`
- 必ず触れる点: ⊥記号の読み方。圧縮側(青)/引張側(赤)の色は以後の全図で共通であること。$1/r$ の遠達性。

### S3. 炭素原子の居心地

BCC鉄の格子間隙間(八面体位置)は炭素原子より小さく、炭素は「どこにいても窮屈」であることを静的図で示す。すると転位の下側=引張側は隙間が広がっていて居心地がよいはずだ、と仮説を立てさせ、読者にドラッグで炭素原子を動かしてエネルギーメーターを読ませる。結果を式 $U = A\sin\theta/r$ に整理し、変数を図中要素と同色で示す。溶質タイプを「小さい置換型原子」に切り替えると符号が反転し、圧縮側を好むことも確認させる(一般化)。

- 使用図版: 静的図 S-1(八面体位置)、図3 `solute-energy-probe`
- 必ず触れる点: $U<0$ = 安定、の符号の読み方。$U_b \approx 0.5\,\mathrm{eV}$ 程度という深さの相場。**誠実な簡略化**: 本記事は炭素の歪みを等方的な体積ミスフィットとして扱うが、実際の炭素は正方晶ひずみを生み、らせん転位とも結合する(脚注)。

### S4. 雰囲気が生まれる

居心地の差 $U_b$(〜0.5 eV)と熱運動 $k_BT$(室温で 0.025 eV)の比が指数の肩に乗るため、濃度比は桁で変わる — これがボルツマン分布であり、転位を包む溶質の雲=**コットレル雰囲気**である。平衡地図(温度スライダーで雲が凝縮/蒸発)を見せたあと、「では雲はどうやって・どれくらいの速さでできるのか」に進み、ランダムウォークする炭素たちが実時間換算つきで転位に集まっていく様子を観察させる。低温は濃いが遅い、高温は速いが薄い、その中間に「効く」温度域があるという構図をここで作る(S7・S8 の伏線)。コットレル&ビルビーの $t^{2/3}$ 則に一言触れる。

- 使用図版: 図4 `atmosphere-equilibrium`(推奨)、図5 `atmosphere-kinetics`(本記事の中心図版)
- 必ず触れる点: $c/c_0 = e^{-U/k_BT}$(飽和補正つき)。凝縮した雰囲気(core 近傍で $c\to1$)。ホップ率のアレニウス式。実時間換算表示の読み方。

### S5. 釘付けと引き離し

雰囲気に包まれた転位を動かすには、居心地のよい配置を壊すエネルギーの坂を登らねばならない。応力スライダーを上げていくと、転位はわずかに位置をずらして耐え(坂の途中で力がつり合う)、臨界値で突然引き離されて走り出す。離れた後は低い応力で動き続けられる — これが**上降伏点と下降伏点の正体**である。温度を上げると雰囲気が薄れ、歯が消えることも確認させる。

- 使用図版: 図6 `pinning-breakaway`
- 必ず触れる点: 力のつり合い($\tau b$ vs 束縛力の最大値)。「引き離し」= 上降伏点、「自由走行」= 下降伏点。高温で歯が消える理由。

### S6. 降伏の波 — リューダース帯

1本の転位の引き離しは周囲の応力を乱し、隣の転位の引き離しを誘発する — 降伏は「なだれ」として広がる。試験片スケールでは、降伏した領域と未降伏領域の境界(リューダース帯の前面)が試験片を掃引し、その間は応力がほぼ一定に保たれる。これが S1 で見た波打つ平坦部の正体である。帯が通過した表面には段差の縞=ストレッチャーストレインが残る。対策としてのスキンパス圧延(あらかじめ僅かに変形させ、可動転位を供給して歯を消す)に触れる。

- 使用図版: 図7 `luders-band`、静的図 S-2(ストレッチャーストレインの模式)
- 必ず触れる点: プラトー = 帯が掃いている区間。前面の伝播。不均一さを上げると複数の帯が核生成しプラトーがギザつくこと。

### S7. 時間が歯を取り戻す — ひずみ時効と焼付硬化

いったん降伏させた鋼を除荷して待つと、炭素が拡散して転位に戻り、歯が復活する(ひずみ時効)。回復の度合いは $W(t,T)=1-\exp[-(t/\tau)^{2/3}]$、$\tau(T)=\tau_0 e^{E_m/k_BT}$ で決まり、**室温では年単位、170 °C では分単位**という目盛り感覚をウィジェットで掴ませる。自動車外板の焼付硬化(BH)鋼 — プレス時は軟らかく、塗装焼付(170 °C × 20分)で硬くなる — は、この現象を味方につけた設計であることを示して実用に着地する。

- 使用図版: 図8 `strain-aging-cycle`
- 必ず触れる点: 直後の再引張では歯が出ない(可動転位が裸のまま)。BH量の相場(30〜60 MPa)。時効は敵(ストレッチャーストレイン再発)にも味方(BH)にもなる、という両面。

### S8. 追いかけっこの縞 — 動的ひずみ時効(発展)

転位が動き**続けている**とき、溶質が追いつける温度・速度の組合せでは「捕まえ直し→引き離し」が繰り返され、応力ひずみ曲線がギザギザになる(セレーション、ポルテバン=ル・シャトリエ効果)。鋼を 200〜300 °C で変形すると強度が上がり延性が落ちる青熱脆性もこの窓の中の現象である。温度とひずみ速度のマップ上で窓を横切る操作をさせ、「温度を上げること」と「ゆっくり引くこと」の等価性を体感させる。

- 使用図版: 図9 `dsa-serrations`
- 必ず触れる点: 待ち時間 $t_w$ と拡散時間 $\tau(T)$ の比が窓を決めること。発展節であり読み飛ばし可能である旨を冒頭に明記。

### まとめ

弾性場($\sin\theta/r$)→ ボルツマン分布 → 固着 → 引き離し(歯)→ 帯(プラトー)→ 時効(復活)の因果の鎖を 5 行で再掲し、S1 の謎を回収する。関連記事(フランク・リード源、GPゾーン)へ誘導。

### 5.1 図1 `yield-tooth` — 引張試験と「歯」

**表示するもの / 初期状態**
- 左: ダンベル形試験片(平行部を大きく)。つかみ部が上下に動き、伸びに応じて描画が変形。降伏後、平行部に降伏済み領域(薄い `--mat-tension` 塗り+細かい斜め線テクスチャ)が端から広がる簡易表現(詳細モデルは図7)。
- 右: 応力–ひずみ曲線(σ [MPa] vs ε [%]、ε は 0〜15%)。現在点をマーカー表示。
- 初期状態: 材料=焼なまし軟鋼、ε=0、一時停止(再生ボタンで開始。reduced-motion 時は既定で停止)。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 | 備考 |
|---|---|---|---|---|
| 材料 | segmented | 焼なまし軟鋼 / アルミニウム合金 | 軟鋼 | 切替時は自動 reset |
| 引張速度 | slider | 0.5×〜3× | 1× | 表示上の進行速度 |
| 再生/一時停止・リセット | playPause / reset | — | — | — |

**モデルと式(現象論・区分定義)**
- 軟鋼: 弾性 $\sigma = E\varepsilon$($E=210$ GPa)→ $\sigma_u = 270$ MPa で降伏 → $\sigma_l = 240$ MPa へ短い遷移で降下 → 降伏伸び $\varepsilon_L = 2.5\%$ の間プラトー(±3 MPa の微小なゆらぎ、シード固定)→ 以後加工硬化 $\sigma = \sigma_l + K(\varepsilon-\varepsilon_L)^{n}$($n=0.5$、$K$ は $\varepsilon=15\%$ で σ≈430 MPa となるよう校正)。
- アルミ合金: $E=70$ GPa、滑らかな Ramberg–Osgood 型で $\sigma_{0.2}=100$ MPa、歯なし。
- 簡略化の明示(図注): 模式曲線であること。くびれ・破断は扱わない。

**実装方式**: 2D / onFrame(自動進行)。曲線は事前計算した折れ線を進行度でクリップ描画。

**受け入れ基準**
- [ ] 歯(上→下降伏)とプラトーが一目で判別できる
- [ ] 材料切替で曲線と試験片表現が正しく差し替わる
- [ ] プラトー区間で試験片上の降伏領域が前進して見える
- [ ] reset で毎回同一の曲線(ゆらぎ含め)を再現

### 5.2 図2 `edge-dislocation-field` — 刃状転位の応力場

**表示するもの / 初期状態**
- 2D 格子 約 26×16 原子(`--mat-matrix`)。中央に刃状転位: 上半分にのみ存在する余分な半列。⊥記号を転位位置に重ねる。
- 初期状態: 原子のみ表示、誇張 ×2。オーバーレイなし。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| 体積ひずみを表示 | toggle | on/off | off |
| 変位の誇張 | slider | ×1〜×4 | ×2 |

**モデルと式**
- 格子点変位は等方弾性の刃状転位変位場を適用(実装用。本文には出さない):
  $u_x = \frac{b}{2\pi}\left[\arctan\frac{y}{x} + \frac{xy}{2(1-\nu)(x^2+y^2)}\right]$、
  $u_y = -\frac{b}{2\pi}\left[\frac{1-2\nu}{4(1-\nu)}\ln(x^2+y^2) + \frac{x^2-y^2}{4(1-\nu)(x^2+y^2)}\right]$。
  コア近傍(r < 2b)の数原子は発散を避けるため変位をクランプ。
- オーバーレイ: 静水圧 $p(r,\theta) = B\sin\theta/r$、$B=\frac{(1+\nu)\mu b}{3\pi(1-\nu)}$。$p>0$(圧縮)を `--mat-compression`、$p<0$(引張)を `--mat-tension` で、|p| に応じた不透明度のセル塗り。
- 簡略化の明示(図注): 実際の α-Fe は BCC で、ここでは 2D 正方格子に簡略化していること。

**実装方式**: 2D / requestRender(操作時のみ再描画)。

**受け入れ基準**
- [ ] 上=青(圧縮)/下=赤(引張)が明確で、色が以降の図と一致
- [ ] 誇張スライダーで格子が滑らかに追従(60fps 相当の応答)
- [ ] ⊥記号の位置が半面の端に正しく置かれている

**操作パラメータ**

### 5.5 図5 `atmosphere-kinetics` — 雰囲気ができるまで(中心図版)

**表示するもの / 初期状態**
- 図2 の格子(転位固定)。格子間サイトを跳び回る炭素原子 約 120 個(`--mat-solute`)。左右は周期境界。
- 読み出し: シミュレーション内経過時間の**実時間換算**(例「経過: 4.1 分(600 K 換算)」。秒/分/時間/日/年で自動整形)。
- 任意(あれば良い): 転位から 3b 以内の捕獲数 vs 時間の小プロット(log–log、傾き 2/3 の参照線つき)。
- 初期状態: 一様ランダム配置(シード固定)、T=600 K、再生中(reduced-motion 時は停止)。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| 温度 T | slider | 300〜1000 K(step 10) | 600 K |
| 時間の進み | segmented | ×1 / ×10 / ×100(内部ステップ数の倍率) | ×10 |
| 再生/一時停止・リセット | playPause / reset | — | — |

**モデルと式**
- 2D 正方格子上のランダムウォーク。1 MC ステップ = 全原子 1 試行。ホップ受理は Metropolis: 隣接 4 方向から等確率で候補を選び、$\min(1, e^{-\Delta U/k_BT})$ で受理。$U$ は図3 と同一。占有サイトへの移動は禁止(排他)。
- 実時間換算: 1 MC ステップ = $1/\Gamma(T)$ 秒、$\Gamma = \nu_0 e^{-E_m/k_BT}$。※表示にのみ使用し、描画レートは温度によらず一定に保つ(そうしないと低温で何も動かない)。この「時間の縮尺は温度ごとに違う」ことを図注で明示する。
- 簡略化の明示: 2D・正方格子・希薄(相互作用なし)・転位は動かない。

**実装方式**: 2D / onFrame + `fixedStep`。原子は位置を TypedArray で保持し 1 パス描画。移動は 80ms 程度のイージング補間(×100 時は省略して即時描画)。

**受け入れ基準**
- [ ] 400 K で観察開始から十数秒以内に下側へ雲が凝縮していく
- [ ] 900 K では雲がほぼ形成されない(まばらなまま)
- [ ] 温度を途中で変えると分布が追随(凝縮→蒸発が可逆に見える)
- [ ] reset で同一初期配置を再現。モバイルで 60fps(最低 30fps)

### 5.6 図6 `pinning-breakaway` — 固着と引き離し

**表示するもの / 初期状態**
- 横長ステージ。水平なすべり面(破線)上に転位(`--mat-defect` の ⊥)。転位の初期位置を囲んで凝縮雰囲気: `--mat-solute` の点群 N=40(ガウス分布、幅 2b。**位置固定**)。
- 上部に「力のつり合いバー」: 駆動力 $\tau b$(defect 色)vs 束縛力の現在値/最大値。
- 右: 小プロット τ vs 転位変位 x。引き離し時に上降伏→下降伏の落差が描かれる。
- 初期状態: 手動モード、τ=0、T=300 K。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| モード | segmented | 手動 τ / 自動ランプ | 手動 |
| せん断応力 τ | slider | 0〜300 MPa | 0(手動モードのみ有効) |
| 温度 T | slider | 300〜900 K(step 25) | 300 K |
| リセット(・自動時 playPause) | reset / playPause | — | — |

**モデルと式**
- 束縛ポテンシャル: $E_{pin}(x) = -N_{eff}(T)\,U_b\, e^{-x^2/2w^2}$、$w = 2b$。束縛力 $F(x) = -dE_{pin}/dx$。
- 占有率による温度依存: $N_{eff}(T) = N\,\theta(T)$、$\theta(T) = \dfrac{c_0 e^{U_b/k_BT}}{1-c_0+c_0 e^{U_b/k_BT}}$(図4 と同じ飽和式。T≈650 K 付近で急減し、歯が消える)。
- 準静的応答: 与えられた τ に対し $\tau b = F(x)$ の安定解に転位を置く(τ 増加でわずかに前進)。$\tau b > \max F$ で離脱し、以後は一定の摩擦応力 $\tau_f$(離脱直後の下降伏に相当。$\tau_c(300\,\mathrm{K})$ の 0.85 倍程度に校正)で等速滑走。
- 表示単位: 内部は無次元、表示は 300 K で $\tau_c \approx 270$ MPa・$\tau_f \approx 230$ MPa となるようスケール(図1 と整合)。
- 簡略化の明示: 溶質は動かない(十分時効済み・低温での速い負荷を仮定)。熱活性化による待ち時間は扱わない。

**実装方式**: 2D / onFrame(離脱後の滑走と自動ランプのため)。手動モードで静止中は描画停止(requestRender 的に振る舞う)。

**受け入れ基準**
- [ ] τ を上げると転位が数 b だけ「粘って」から突然離脱する
- [ ] 離脱の瞬間、つり合いバーとプロットの両方で落差(上→下降伏)が読める
- [ ] T=700 K 以上で τ_c が τ_f に近づき、落差が消える
- [ ] 自動ランプは reset→再生で毎回同じ挙動

### 5.7 図7 `luders-band` — 降伏の前線

**表示するもの / 初期状態**
- 上: 平板試験片をセル 64 個の横帯で表現。未降伏セル=無地、降伏済みセル=薄い塗り+短い斜線テクスチャ(ストレッチャーストレインの表現)。帯前面セルに `--mat-defect` のマーカー。
- 下: σ–ε 曲線(図1 と同スタイル)。
- 初期状態: 一時停止、不均一さ 3%、速度 1×。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| 引張速度 | slider | 0.5×〜4× | 1× |
| 不均一さ | slider | 0〜10 %(τ_u のセル間ばらつき、シード固定) | 3 % |
| 再生/一時停止・リセット | playPause / reset | — | — |

**モデルと式(1D セルモデル)**
- 直列セル、応力 σ は全セル共通。試験機: $\sigma = K_m(\varepsilon_{app} - \bar\varepsilon_p)$($K_m$ は装置+弾性の合成剛性、定数)。$\varepsilon_{app}$ はクロスヘッドで一定速度増加。
- 各セル i: 未降伏かつ $\sigma \ge \tau_{u,i}$ で降伏。降伏後は粘塑性 $\dot\varepsilon_{p,i} = (\sigma - \tau_{l,i})/\eta$($\sigma>\tau_{l,i}$ のとき)+ 線形硬化 $\tau_{l,i} \mathrel{+}= h\,d\varepsilon_{p,i}$。
- 前面バイアス: 降伏セルの隣接未降伏セルは $\tau_u$ を $\Delta_{front}$ だけ引き下げ(応力集中の代理)。端の 1 セルは僅かに弱くしておく(フィレットでの核生成)。
- 定数の目安: $\tau_u=270$、$\tau_l=240$ MPa、$\Delta_{front}=25$ MPa、リューダースひずみが約 2.5% になるよう $\eta, h, K_m$ を校正。
- 簡略化の明示: 1 次元・模式モデル。帯の傾き(約 50°)などの 2D 幾何は扱わない(静的図 S-2 で補足)。

**実装方式**: 2D / onFrame + `fixedStep`。

**受け入れ基準**
- [ ] 歯 → ほぼ一定応力のプラトー(帯が掃引)→ 全域降伏後に加工硬化、の順で曲線が描かれる
- [ ] プラトー中、前面マーカーの位置と ε の進行が連動して見える
- [ ] 不均一さ 8% 以上で複数の帯が核生成し、プラトーがギザつく
- [ ] reset 再現性(シード固定)

### 5.8 図8 `strain-aging-cycle` — 歯の復活

**表示するもの / 初期状態**
- σ–ε 曲線パネル(サイクルを重ね描き。過去の引張は淡色、現在を濃色)。
- 手順ステッパー表示: 「① 2% 引張 → ② 除荷 → ③ 時効 → ④ 再引張」。現在の段階を強調。
- 時効パネル: 温度・時間の 2 スライダーと、換算表示(「170 °C・20 分 → 回復率 63%」のような読み出し)。
- 初期状態: 未変形。ボタン「引張する」のみ有効。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| 操作ボタン | button 群 | 引張(2%)/ 除荷 / 時効して再引張 | — |
| 時効温度 | slider | 20〜300 °C(step 5) | 170 °C |
| 時効時間 | log slider | $10^0$〜$10^8$ s(表示は 秒/分/日/年 自動整形) | $1.2\times10^3$ s(20 分) |
| はじめから | reset | — | — |

**モデルと式**
- 回復率 $W(t,T) = 1 - \exp[-(t/\tau)^{2/3}]$(コットレル・ビルビーの $t^{2/3}$ 則を JMAK 形に取り込んだ現象論)。$\tau(T) = \tau_0\, e^{E_m/k_BT}$、$\tau_0 = 8\times10^{-8}$ s(→ $\tau(170°C)\approx10$ 分、室温では年オーダー)。
- 再引張の曲線: 図1 の現象論を再利用し、上降伏点の増分 $\Delta\sigma = \Delta\sigma_{max} W$($\Delta\sigma_{max}=40$ MPa)、降伏伸び $\varepsilon_L' = \varepsilon_L W$。W≈0 なら歯なしで滑らかに continuación(除荷点から弾性で立ち上がり流動応力に接続)。
- 簡略化の明示: 転位密度の増加・回復など他の時効因子は無視。数値は典型値。

**実装方式**: 2D / onFrame(引張の進行アニメ)。時効はボタン押下で即時に W を確定し、換算読み出しを更新。

**受け入れ基準**
- [ ] ①→②→④(時効スキップ相当: t 最小)では歯が出ない
- [ ] 170 °C・20 分で歯が復活し、上降伏点が初回より約 +35〜40 MPa 高い
- [ ] 20 °C で同等の回復には「年」単位が必要と読み出しから分かる
- [ ] サイクルを 2 回以上重ねても曲線の重ね描きが破綻しない

### 5.9 図9 `dsa-serrations` — 追いかけっこの窓(発展)

**表示するもの / 初期状態**
- 左: 横軸 T(20〜400 °C)・縦軸 $\log\dot\varepsilon$($10^{-5}$〜$10^{-1}$ /s)のマップ。セレーション窓(帯状領域)を `--color-accent` の薄塗りで表示。現在の (T, ε̇) を十字マーカーで表示。
- 右: その条件で生成される σ–ε 曲線(進行描画)。窓内ではのこぎり歯状。
- 初期状態: T=25 °C、ε̇=10⁻³/s(窓外・滑らか)、一時停止。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| 温度 T | slider | 20〜400 °C | 25 °C |
| ひずみ速度 | log slider | $10^{-5}$〜$10^{-1}$ /s | $10^{-3}$ /s |
| 再生/一時停止・リセット | playPause / reset | — | — |

**モデルと式(現象論)**
- 転位の平均待ち時間 $t_w = \Omega/\dot\varepsilon$($\Omega = 10^{-4}$: 1 回の解放で稼ぐひずみ)。
- 窓の条件: $0.1 < t_w/\tau(T) < 10$($\tau(T)$ は図8 と同じ)。窓の中心で効果最大。
- 曲線: ベースは滑らかな硬化曲線。窓内では間隔(シード付き乱数)ごとに応力が $\Delta\sigma_{max} W(t_w,T)$ 上昇→急落するのこぎり歯を重畳。振幅は窓中心からの距離で減衰。
- 図注: 待ち時間モデルによる模式であること。青熱脆性(200〜300 °C で強度↑・延性↓)への言及は本文で。

**実装方式**: 2D / onFrame。マップは requestRender 的に T・ε̇ 変更時のみ再計算。

**受け入れ基準**
- [ ] 窓内に入るとリアルタイムに曲線がギザつき、出ると滑らかに戻る
- [ ] 「T を上げる」ことと「ε̇ を下げる」ことが等価に窓を横切ると確認できる
- [ ] マーカーと窓の位置関係が数式(t_w/τ 比)と一致
