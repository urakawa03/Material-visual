**叩き台からの変更点**(依頼プロンプト §3 に対して):

3. 図6 は「せん断 / 迂回」をユーザーが選ぶのではなく、**現在の粒子半径と応力から安い方の機構が自動的に選ばれる**構成にした(デザイン原則 4: 直感が先)。読者が半径を変えると機構が切り替わる体験そのものが S5 の主張である。

## 1. 学習目標

読み終えた読者が、次のことをできるようになる。

1. 溶体化 → 焼入れ → 時効という熱処理の 3 段階を、Al–Cu 状態図の固溶限(solvus)の上を動く点として説明でき、焼入れで**溶質と過剰空孔がまとめて凍結される**ことを述べられる。
2. GP ゾーンが室温でも生成できる理由を、「母相と**整合**だから界面エネルギーが小さく、核生成の障壁が低い」+「凍結された過剰空孔が室温での拡散を可能にする」の 2 点で説明できる(「溶質が多いから」では不十分だと分かる)。
3. 整合な粒子の周囲に弾性ひずみ場ができること、および GP → θ″ → θ′ → θ の析出シーケンスが「整合 → 半整合 → 非整合」への移行であり、界面エネルギーとひずみエネルギーのトレードオフであることを説明できる。
4. 転位が粒子に出会ったときの 2 つの道 — **せん断**($\tau \propto \sqrt{rf}$、$r$ の増加関数)と**迂回**(オロワン機構、$\tau_c \approx \mu b/L$、$r$ の減少関数)— を区別し、**2 曲線の交点がピーク時効**であることを図で示せる。
5. 時効曲線(硬さ vs 時間)の形と温度依存を、上の機構競合から説明でき、「高温は早いがピークは低い」という実務上のトレードオフを述べられる。ピークの先が過時効([オストワルド成長](/articles/ostwald-ripening/))であることを理解する。

## 3. 章立てとナラティブ

記事全体の筋: **「置いておいたら硬くなった」という 1906 年の観察を謎として立て、状態図(何が凍結されたか)→ 原子(なぜ集まれるか)→ ひずみ場(集まると何が起きるか)→ 転位(なぜ硬いのか)と 1 段ずつ降り、最後に時効曲線を読者自身に描かせて謎を回収する。そしてピークの先(過時効)をオストワルド成長へ渡す。**

### S1. 置いておいたら硬くなった(導入・謎)

1906 年、Alfred Wilm は焼入れしたアルミ合金の硬さを測り、週明けに測り直して硬くなっていることに気づいた。加熱も加工もしていない。室温に置いただけである。まず時効硬化曲線そのものを見せ、「この曲線の正体を突き止める」を記事の目標として宣言する。図1 は S6 で再登場し、そこで読者自身が描くことになる、と予告しておく。

- 使用図版: 図1 `aging-curve`
- 必ず触れる点: 焼入れ直後は軟らかいこと。室温でも硬化が進むこと(数日スケール)。ピークがあり、その先では下がること(過時効の予告)。硬さはモデル値であること。

### S2. 溶けきらない量を溶かす — 溶体化と焼入れ

Al–Cu 状態図の Al 側を見る。高温では 4 wt% の Cu が α 相に固溶できるが、室温の固溶限はほぼゼロ。**溶体化処理**(固溶限の上、単相 α の領域まで加熱して均一固溶)→ **焼入れ**(急冷)で、本来なら析出するはずの Cu が過飽和のまま凍結される。読者に状態図上の点をドラッグさせ、溶体化 → 焼入れ → 時効の経路をなぞらせる。

続いて、凍結されるのは溶質だけではないことを示す。平衡空孔濃度は温度とともに指数的に増える($c_v = e^{-E_f/k_BT}$)。500 °C の空孔濃度は室温平衡の **10⁷ 倍**であり、急冷するとこれも凍結される。この**過剰空孔**が、室温という低温でも Cu 原子を動かす。徐冷と急冷を比べさせ、「急冷したから硬くなれる」という逆説を体感させる。

- 使用図版: 図2 `phase-diagram`、図3 `quench-supersaturation`
- 必ず触れる点: 固溶限(solvus)の温度依存。過飽和(supersaturation)の定義。空孔機構(カーケンドール記事 S2 に対応。未読でも分かるよう最小限を自給)。**過剰空孔がなければ室温時効は起きない**こと。徐冷では粗大な平衡析出物ができて硬化しないこと。

### S3. 溶質が集まる — GPゾーンの誕生

過飽和の Cu 原子は、母相の {100} 面上に**板状に集まる**。これが GP ゾーン(Guinier–Preston zone)である。ここで強調すべきは大きさではなく**整合(coherent)**であること — GP ゾーンは母相の格子の上にそのまま乗っており、格子面が連続してつながっている。だから界面エネルギーが小さく、**核生成の障壁が低い**。低温でも越えられる障壁だからこそ、室温で起きる。

図4 で、凍結空孔の助けを借りて Cu 原子が動き、板状のクラスターが育つ様子を観察させる。空孔濃度を平衡値に落とすと何も起きないことも試させる(S2 の回収)。

- 使用図版: 図4 `zone-formation`(本記事の中心図版)、静的図 S-1(整合界面の模式)、静的図 S-2(核生成障壁の比較)
- 必ず触れる点: **整合であることが本質**(単なる「小さい析出物」ではない)。板状になる理由(整合ひずみを小さくする向きに広がる)。バラバラの溶質(`--mat-solute`)と集まって別の相になったもの(`--mat-precip`)の違い。コットレル雰囲気との対比(集まる先が転位か、溶質同士か)。

### S4. 整合ひずみと析出シーケンス

Cu 原子は Al より小さい(原子半径比 約 0.89)。だから整合な GP ゾーンの周囲では母相の格子が引き込まれ、**弾性ひずみ場**ができる。転位はこのひずみ場とも相互作用する(コットレル雰囲気と同じ理屈)。

時間とともに GP → θ″ → θ′ → θ と変化し、整合 → 半整合 → 非整合へ進む。整合を捨てると界面エネルギーは上がるが、ひずみエネルギーは下がる。どちらが得かは粒子が大きくなるほど変わる(界面は $r^2$、ひずみは $r^3$ で効く)ため、粒子は育つにつれて整合を手放していく。図5 でこのトレードオフを操作させる。

- 使用図版: 図5 `coherency-strain`
- 必ず触れる点: 整合ひずみの向き(小さい溶質 → 周囲は引き込まれる)。`--mat-tension` / `--mat-compression` の意味。半整合界面のミスフィット転位。実在のシーケンスを 4 段階に簡略化していること(図注)。

### S5. なぜ硬くなるのか — 切るか、迂回するか

**ここがフランク・リード源記事の直接の続き**である。同記事 S6 で「障害物の間隔を詰めれば材料は強くなる」と予告した、その障害物を人工的に撒いたのが析出強化である。転位が粒子に出会ったとき、道は 2 つしかない。

- **せん断(cutting)**: 小さく軟らかい整合粒子は、転位が切って通る。粒子を切ると新しい界面ができ、整合ひずみ場も横切るので、必要応力は粒子が大きいほど**上がる**($\tau \propto \sqrt{rf}$)。
- **迂回(Orowan bowing)**: 大きい粒子・硬い粒子は切れない。転位は粒子の間を張り出して回り込み、粒子の背後で腕どうしが相殺して、粒子を取り巻くループ(オロワンループ)を残して進む。**これはフランク・リード源そのものの動作**であり、必要応力は障害物間隔 $L$ で決まる: $\tau_c \approx \mu b/L$。

体積分率一定で粒子が粗大化すると $L = \beta r/\sqrt f$ が広がるので、迂回に必要な応力は**下がる**。転位は常に安い方の道を選ぶから、材料の強さは 2 曲線の**下側の包絡線**であり、その**交点が最大強度 = ピーク時効**である。これが S1 の曲線の正体。

- 使用図版: 図6 `cutting-vs-bowing`、図7 `strength-vs-radius`
- 必ず触れる点: 迂回はフランク・リード源と同じ機構・同じ式であること(リンクを張る)。オロワンループが残ること。$\tau \propto \sqrt{rf}$ と $\tau = \mu b\sqrt f/(\beta r)$ の $r$ 依存が逆向きであること。ピークは「ちょうどいい大きさがある」ではなく**2 機構の交点**であること。

### S6. 時効曲線を作る

S1 の図をもう一度出し、今度は読者に描かせる。温度を選んで時計を進めると、その温度の硬さ曲線が 1 本ずつ溜まっていく。観察されるのは:

- 高温ほど**早く**ピークに達する(拡散が速い)。
- しかし高温ほど**ピークは低い**(粗大化が析出に追いつき、体積分率が育ちきる前に粒子が交点半径を越えてしまう)。
- 室温では、ピークではなく**ゆるやかな頭打ち**になる(粗大化がほとんど進まないので、粒子は交点半径まで育たない)。Wilm が見たのはこれである。

ここで S1 の謎を回収する。

- 使用図版: 図1 `aging-curve` を再掲(同じ図版 ID を再利用する。DOM の id が衝突するので `Figure` に明示的な `id` を渡す)
- 必ず触れる点: 「早いがピークは低い」のトレードオフ。実務(T6 処理)での温度・時間管理。時間軸が対数であること。時間スケールを強く加速していること(図注)。

### S7. 硬さの峠を越えて — 過時効

ピークを過ぎても粒子は成長を続け、材料は軟化する。ここで起きているのは、大きい粒子が小さい粒子を「食べて」育つ過程 — [オストワルド成長](/articles/ostwald-ripening/)である。図1 のピーク右側は、その記事の入口そのものである。次記事へバトンを渡す。

- 使用図版: なし(図1 の右側を参照させる)
- 必ず触れる点: 過時効(overaging)の定義。強さが $1/\bar r$ で衰えること。オストワルド成長記事への誘導。

### まとめ

「溶かして、凍らせて、ひそかに集めさせる」で回収する。析出強化が材料設計の中心的手法であること(ジュラルミン、7000 系、Ni 基超合金の γ′)を述べ、ピークの先の物語としてオストワルド成長へ、転位側の物語としてフランク・リード源へ誘導する。

#### 時効モデル(`aging.ts`)

析出の進行度(Avrami 型)、平均半径、体積分率を次で与える。

$$X(t) = 1 - \exp\left[-\left(\frac{t}{t_p(T)}\right)^{n}\right],\quad n = 1.2,\quad t_p(T) = t_{p0}e^{Q_p/k_BT}$$

$$f(t) = f_{eq}(T)\,X(t),\qquad f_{eq}(T) = \frac{c_0 - c_s(T)}{c_\theta - c_s(T)}$$

$$r(t) = \left[r_0^3 + (r_1^3 - r_0^3)X(t) + K(T)\,t\right]^{1/3},\qquad K(T) = K_0e^{-Q_K/k_BT}$$

強化応力は 2 機構の小さい方(転位は安い道を選ぶ):

$$\tau_{cut}(r, f) = k_{cut}\sqrt{r f},\qquad \tau_{or}(r, f) = \frac{\mu b}{L} = \frac{\mu b\sqrt f}{\beta r},\qquad \Delta\tau = \min(\tau_{cut}, \tau_{or})$$

$$HV = HV_0 + C\,\Delta\tau$$

**校正**(コード内で導出し、マジックナンバーを置かない):

- $t_{p0}$: 20 °C で $t_p = 1$ 日(Wilm の「週明け」に対応)。
- $K_0$: 130 °C で $r$ が交点半径 $r^\times$ に達するのが約 10 時間。
- $k_{cut}$: $\tau_{cut}(r^\times, f) = \tau_{or}(r^\times, f)$(両者とも $\sqrt f$ に比例するので、**交点半径は $f$ によらない**。この事実は §5.7 の図注と本文で明示する)。
- $C$: 130 °C のピークで $HV = HV_{peak}$。

**この模型が再現すること**(単体テストで検証する):

- 20 °C: 粗大化が事実上進まないので $r \to r_1 < r^\times$。曲線はピークを作らず頭打ち(ピークの約 8 割)。数日スケール。
- 130〜150 °C: 数時間でピーク。$X \approx 1$ なので体積分率が育ちきり、ピークが最も高い。
- 250 °C: 数十秒〜数分でピーク。$Q_K > Q_p$ のため粗大化が析出を追い越し、$X < 1$ のままピークを迎えるのでピークは低い。

**誠実な簡略化**(全図の図注または本文で明示):

- 現象論モデルであり実測データではない。硬さは校正済みのモデル値。
- 実際の析出シーケンス(GP → θ″ → θ′ → θ)を「1 種類の粒子が育つ」に簡略化している。
- 時間スケールを強く加速して表示する(現実の時効は数時間〜数日)。
- 粒子は球として計算する(実際の GP ゾーンは {100} 上の板)。

#### 色(母体仕様 §6.2 — 既に予約済み。新色を作らない)

**表示するもの / 初期状態**

| 名前 | UI | 範囲 | 初期値 |

| 冷却の速さ | segmented | 急冷(水焼入れ)/ 徐冷(炉冷) | 急冷 |

**モデルと式**

### 5.4 図4 `zone-formation` — GP ゾーンの誕生(中心図版・S3)

**表示するもの / 初期状態**

- 正方格子(約 64 × 40 サイト)。母相サイトは淡い `--mat-matrix` の点、Cu 原子は `--mat-solute` の円、空孔は破線縁の円。
- しきい値以上の大きさに育ったクラスタは **`--mat-precip` で塗り**、板状の輪郭で囲む(= GP ゾーンになった、の視覚的宣言)。
- 読み出し: 経過時間(実時間換算)、ゾーンの数、最大ゾーンの原子数、固溶したままの Cu の割合。
- 右に小さな棒グラフ: クラスタサイズの分布(1 個 / 2〜4 個 / 5 個以上)。
- 初期状態: 焼入れ直後(Cu がランダム分散、過剰空孔あり)、温度 20 °C、再生中。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 | 備考 |
|---|---|---|---|---|
| 温度 | slider | 20〜200 °C(step 5) | 20 °C | 拡散の速さに効く |
| 空孔 | segmented | 焼入れまま(過剰)/ 平衡 | 焼入れまま | **平衡では室温で何も起きない**(S2 の回収) |
| {100} 面上に並ぶ | toggle | on/off | on | off で異方性を切り、板状にならないことを見せる |
| 再生/一時停止・リセット | playPause / reset | — | 再生 | シード固定 |

**モデルと式(`zones.ts`)**

- 格子気体モデル。Cu 原子は空サイトへ最近接ホップする。ホップ確率は $\nu\,c_v\,e^{-(E_a + \Delta E^+)/k_BT}$ に比例($\Delta E^+$ = 結合エネルギー差の正部分)。
- 結合エネルギー: 同種(Cu–Cu)最近接 1 本あたり $\varepsilon$。**{100} 面上に並ぶ**を on にすると、水平方向の結合を $\varepsilon_\parallel > \varepsilon_\perp$ とし、板状(1〜2 原子層の水平な帯)が安定になる。
- クラスタ抽出: Union–Find で最近接連結成分を求め、3 原子以上を「GP ゾーン」とする(色の切り替えしきい値)。
- 時間換算: 1 モンテカルロステップ = $\Delta t(T, c_v)$ 実秒。$c_v$ を平衡に落とすと室温では 10⁶ 倍以上遅くなり、画面上では実質停止する。
- 乱数はシード固定(`mulberry32`)。`reset` で完全再現。

**簡略化の明示(図注)**: 2D 格子・原子数の大幅削減・時間の強い加速。実際の GP ゾーンは 3 次元の {100} 板(直径数 nm・厚さ 1〜2 原子層)。空孔は 1 個だけ描いているが、モデル上の空孔濃度はメーターの値を使う。

**実装方式**: 2D / onFrame(1 フレームあたり固定回数のモンテカルロ試行)。格子は `Uint8Array`、描画は状態ごとに 1 パスでまとめ描き(母体仕様 §8.3)。

**受け入れ基準**

- [ ] 「焼入れまま」20 °C で、数十秒の観察のうちに板状のクラスタが育ち、色が solute → precip に切り替わる
- [ ] 「平衡」に切り替えると、20 °C では実質的に何も起きない(読み出しの経過時間が桁で長くなる)
- [ ] 異方性 off では等方的なクラスタになり、板状にならない
- [ ] reset で同じ初期配置・同じ成長経路を再現する
- [ ] 中位スマートフォンで 60fps(最低 30fps)

### 5.5 図5 `coherency-strain` — 整合ひずみと析出シーケンス(S4・推奨)

**表示するもの / 初期状態**

- 中央: 母相格子(`--mat-matrix` の格子線と原子)と、その中の粒子(`--mat-precip`)。粒子まわりの格子線は整合度に応じて**引き込まれて歪む**。
- ひずみ場の塗り: 粒子の外側で引張(`--mat-tension`)・粒子内部と直上下で圧縮(`--mat-compression`)を淡く塗り分ける(小さい Cu が入って周囲を引き込む向き)。
- 半整合では界面にミスフィット転位(`--mat-defect` の ⊥)を等間隔に描く。非整合では格子線が界面で断絶する。
- 右: エネルギーの内訳バー(界面エネルギー $\propto \gamma r^2$ と ひずみエネルギー $\propto \varepsilon^2 r^3$、合計)。段階ごとに 3 本を比較表示。
- 下: 析出シーケンスの帯(GP → θ″ → θ′ → θ)。現在段階をハイライト。
- 初期状態: 段階 = GP ゾーン、粒子半径 = 2 nm。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| 段階 | segmented | GP / θ″ / θ′ / θ | GP |
| 粒子の大きさ | slider | 1〜20 nm | 2 nm |
| ひずみ場を表示 | toggle | on/off | on |

**モデルと式**

- 整合度 $\phi$: GP = 1.0、θ″ = 0.8、θ′ = 0.35(半整合)、θ = 0(非整合)。界面エネルギー $\gamma(\phi) = \gamma_{inc} - (\gamma_{inc}-\gamma_{coh})\phi$($\gamma_{coh}$ = 0.02、$\gamma_{inc}$ = 0.8 J/m² — オストワルド記事 図8 のレバー値と同じ数値を使う)。
- ひずみエネルギー $\propto \phi^2\varepsilon_0^2 r^3$、界面エネルギー $= \gamma(\phi)\cdot 4\pi r^2$。合計を比べると、小さいうちは整合が得・大きくなると非整合が得になる(トレードオフの可視化)。
- 格子線の歪みは、粒子中心からの距離に対する $1/r^2$ 型の変位場(2D の弾性介在物の模式)。厳密解は用いない。

**簡略化の明示(図注)**: 2D 模式。ひずみ場は弾性論の厳密解ではない。実在のシーケンスにはさらに中間段階があり、θ″/θ′ は板状。エネルギー比較はモデル値で、桁の関係を示すためのもの。

**実装方式**: 2D / requestRender。

**受け入れ基準**

- [ ] 段階を進めると格子の歪みが弱まり、ミスフィット転位 → 界面の断絶へと移る
- [ ] エネルギーバーで、小粒子では整合が有利・大粒子では非整合が有利に逆転する
- [ ] ひずみ場トグルで引張・圧縮の色分けが現れ、母体仕様 §6.2 の意味と一致する
- [ ] キーボードのみで全操作できる

### 5.6 図6 `cutting-vs-bowing` — 切るか、迂回するか(S5)

**表示するもの / 初期状態**

- ステージ: すべり面の上面視。中央に間隔 $L$ で並ぶ 2 個の析出粒子(`--mat-precip`)と、その間に張られた転位線(`--mat-defect`)。フランク・リード源記事 図3〜図5 と同じ視覚言語。
- 上部の 2 本の応力バー: 現在の $\tau$ に対して、$\tau_{cut}$ と $\tau_{or}$ のしきい値マーク。**低い方のバーが「安い道」としてハイライト**される。
- 読み出し: 粒子半径 $r$、間隔 $L$、$\tau_{cut}$、$\tau_{or}$、現在の機構。
- 通過に成功すると:
  - **せん断**: 粒子が $b$ だけずれた 2 つの半円として描き直され、「切った」ラベル。
  - **迂回**: 粒子のまわりに `--mat-defect` のループが残り(オロワンループ)、「迂回した」ラベル。
- 初期状態: $r$ = 1.5 nm(せん断側)、$\tau$ = 0、静止。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 | 備考 |
|---|---|---|---|---|
| 粒子半径 r | slider | 0.5〜12 nm(log) | 1.5 nm | $f$ 一定なので $L$ も連動 |
| せん断応力 τ | slider | 0〜400 MPa | 0 | しきい値超で通過が始まる |
| 応力を上げていく | button | τ を 0 から自動ランプ | — | しきい値到達で自動停止 |
| リセット | reset | — | — | 粒子を元通りにする |

**モデルと式**

- しきい値は `aging.ts` の $\tau_{cut}(r,f)$ / $\tau_{or}(r,f)$($f$ は 0.07 固定 = ピーク時効相当)。機構は $\min$ で決まる。
- **迂回の動力学は `frank-read-source/lib/line.ts` の `FrankReadSim` をそのまま使う**(固定点 = 粒子)。無次元応力 $\tau^{sim} = 2\,\tau/\tau_{or}$(同モジュールの $\tau_c^{sim} = 2$ に合わせる)を与え、張り出し・回り込み・相殺・ループ放出をそのまま見せる。放出されたループを粒子を取り巻くオロワンループとして描く。
- **せん断は解析解**: 円弧の張り出し($R = T/(\tau b)$、`line.ts` の `sagFromRadius` / `sampleArcPoints` を使う)で線を描き、$\tau \ge \tau_{cut}$ になった瞬間に粒子を切って線を解放する。
- 半径を上げると $\tau_{cut}$ が上がり $\tau_{or}$ が下がるので、$r > r^\times$ で機構が自動的に切り替わる。

**簡略化の明示(図注)**: 理想化モデル(等方弾性・一定線張力・過減衰・格子摩擦なし)。せん断の抵抗則は $\sqrt{rf}$ の現象論。粒子は球で代表。**迂回の動きはフランク・リード源記事 図5 と同じ数値コアである**。

**実装方式**: 2D / onFrame + fixedStep(迂回時)。待機中はアイドル。

**受け入れ基準**

- [ ] $r$ = 1.5 nm ではせん断で通り、$r$ = 8 nm では迂回になる(切り替わりが $r^\times$ = 3 nm 付近)
- [ ] 迂回時に粒子を取り巻くループが残り、次の通過に必要な応力の話(残留ループ)へ本文でつなげられる
- [ ] $\tau$ をしきい値未満に戻すと線が張り出したまま止まり、0 で直線に戻る
- [ ] 2 本の応力バーの高低と実際に起きる機構が常に一致する
- [ ] 連続動作で数値破綻(NaN)がない

### 5.7 図7 `strength-vs-radius` — 交点がピーク(S5)

**表示するもの / 初期状態**

- 主プロット: 横軸 = 粒子半径 $r$(対数、0.3〜100 nm)、縦軸 = 必要せん断応力 [MPa] 0〜400。
  - $\tau_{cut} \propto \sqrt{r}$ の上り曲線と、$\tau_{or} \propto 1/r$ の下り曲線。
  - 実際に効くのは低い方 — **下側の包絡線を太線**で描き、交点に accent の縦線と「ピーク時効」ラベル。
  - 交点の左を「切って通る」、右を「迂回する」と領域ラベル。
- 現在半径のマーカー(スライダー連動)と読み出し: $r$、$L$、$\tau_{cut}$、$\tau_{or}$、$\Delta\tau$、硬さ換算。
- 初期状態: $r$ = 3 nm(交点)、$f$ = 0.07。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 |
|---|---|---|---|
| 粒子半径 r | slider | 0.3〜100 nm(log) | 3 nm |
| 体積分率 f | slider | 0.02〜0.12(step 0.005) | 0.07 |
| 硬さ目盛りを重ねる | toggle | on/off | off |

**モデルと式**: §5.0 の $\tau_{cut}$ / $\tau_{or}$。**両者とも $\sqrt f$ に比例するため、$f$ を変えても交点半径 $r^\times$ は動かず、ピークの高さだけが変わる** — これは本モデルの構造そのものであり、図注と本文で明示する(実際の合金では $f$ を上げると強くなるが最適サイズはほぼ変わらない、という設計上の示唆)。

**簡略化の明示(図注)**: せん断側は $\sqrt{rf}$ の現象論(整合ひずみ・規則度など複数の寄与をまとめたもの)。オロワン式は対数係数を落とした簡略形で、$\beta$ は板状粒子を球で代表するための実効値。

**実装方式**: 2D / requestRender。

**受け入れ基準**

- [ ] 2 曲線の交点が $r^\times$ = 3 nm 付近にあり、accent の縦線と一致する
- [ ] $f$ を変えると両曲線が上下し、交点の横位置が動かないことが目視で確認できる
- [ ] 現在半径のマーカーと読み出しが常に一致し、$\Delta\tau$ が低い方の曲線の値になる
- [ ] 硬さ目盛りトグルで図1 の縦軸と対応が取れる

## 6. 静的図・数式リスト

**静的図(SVG、意味パレット準拠)**

| ID | 節 | 内容 |
|---|---|---|
| S-1 | S3 | 整合界面と非整合界面の対比。整合では母相の格子面が粒子を貫いて連続し、非整合では界面で断絶する。「格子がつながっている = 界面のコストが小さい」を一目で示す |
| S-2 | S3 | 核生成の自由エネルギー障壁 $\Delta G(r)$ の比較。整合(小さい $\gamma$)では障壁 $\Delta G^*$ が低く臨界核も小さい。非整合では高い山になる。「室温でも越えられる山」であることを示す |

**本文に表示する数式**(KaTeX。変数色は §5.0 の対応に従う)

1. $c_s(T) = c_{s0}\,e^{-Q_s/k_BT}$(固溶限。溶体化温度と過飽和の根拠)
2. $c_v^{eq}(T) = e^{-E_f/k_BT}$(平衡空孔濃度。500 °C と室温で 10⁷ 倍の差)
3. $\Delta G(r) = -\frac{4}{3}\pi r^3\,\Delta G_v + 4\pi r^2\gamma$、$\Delta G^* = \dfrac{16\pi\gamma^3}{3\Delta G_v^2}$(核生成障壁。$\gamma^3$ で効くことが要点)
4. $\tau_{cut} \approx k\sqrt{r f}$(せん断。$r$ の増加関数)
5. $\tau_{or} = \dfrac{\mu b}{L}$、$L = \beta\dfrac{r}{\sqrt f}$(オロワン機構。フランク・リード源記事の $\tau_c \approx \mu b/L$ と**同じ式**、オストワルド成長記事の $L$ と**同じ式**)
6. $\Delta\tau = \min(\tau_{cut}, \tau_{or})$(転位は安い道を選ぶ。交点がピーク時効)
