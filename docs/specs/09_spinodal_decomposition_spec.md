## 0. この記事の存在意義と、叩き台からの変更点

**存在意義は「対比」である**(プロンプト 09)。GP ゾーンとオストワルド成長が「核ができて、成長し、粗大化する」話なのに対し、スピノーダル分解は**核生成の障壁なしに、微小なゆらぎが勝手に育つ**話である。両者の違いが読者に刻まれることを最優先に構成する。

プロンプトからの変更点:

1. **核生成側の析出物を `--mat-precip` で描かない**。図1 で核生成した粒子とスピノーダルの迷路は**同じ B リッチ相**であり、別の色にすると「別の物ができた」と誤読させる。どちらも濃度場の 2 色補間(`--mat-matrix` ↔ `--mat-second`)で描き、違いは**形(離散した島 か 連結した迷路 か)**だけで見せる。GP ゾーン記事の「溶質(ばらばら)と析出物(集まった別の相)」の色分けとは目的が違う(そちらは原子 1 個ずつを描く図)ことを §2.3 に明記した。
2. **図4(上り坂拡散)を、連続体の 1 次元プロファイルではなく、原子の交換モンテカルロ(格子気体)で描く**。プロンプトの最重要の注意「上り坂拡散でも個々の原子はランダムに跳んでいる(カーケンドール記事 S1 を裏切らない)」を、文章ではなく粒子の絵で直接見せるため。原子は隣とランダムに入れ替わるだけで、受け入れの確率がエネルギーで偏るだけ — それでも濃度差が育つ。濃度プロファイル(列平均)はその下に重ねる。
3. **図6 に「核を置く」操作を加える**。準安定の領域では小さなゆらぎは消えてしまい、臨界半径より大きな核を置いたときだけ育つ — 核生成の障壁を、スピノーダルと同じ方程式・同じ画面で体験させる(本記事の対比を 1 つの図版の中で完結させる)。

前提: `90_remaining_work.md` §3 の P0(`src/core/units.ts`・`src/core/plot.ts`)がマージ済みであること。本記事は**新規に `src/core/fft.ts`(汎用の高速フーリエ変換)を追加する**(§5.0)。

## 1. 学習目標

読了・操作後に、読者が次のことをできるようになる。

1. 2 相への分かれ方に**核生成・成長**と**スピノーダル分解**の 2 通りがあり、組織の形(離散した粒子 / 連結した迷路)が違うことを述べられる。
2. 混合の自由エネルギー曲線 $G(X)$ の**共通接線**から分離後の 2 相の組成と割合(てこの原理)を読み、**バイノーダル**(共通接線の接点)と**スピノーダル**($\partial^2G/\partial X^2 = 0$)の 2 本の線を状態図に引ける。
3. スピノーダルの内側では**上り坂拡散**(濃い方へ向かう原子の流れ)が起きることを、**個々の原子はランダムに跳んでいるまま**、感じるエネルギーの地形が変わったためとして説明できる(カーケンドール記事 S1 と矛盾させない)。
4. 界面エネルギー(勾配エネルギー)が短い波長を抑え、拡散が長い波長を遅らせるため、**最も速く育つ特性波長 $\lambda_m$** が決まることを説明できる。
5. バイノーダルとスピノーダルの間(準安定)では、**臨界半径より大きな核がないと分離が始まらない**ことを、スピノーダルの内側との対比で言える(GP ゾーン記事の舞台はこの領域)。
6. 分離の後期には界面を減らす粗大化が続き、代表長さが $t^{1/3}$ で育つことを、オストワルド成長の記事と結び付けて述べられる。実材料の例(Fe–Cr の 475 ℃ 脆化、ガラスの分相)を挙げられる。

### 2.3 表記と慣習(記事全体の約束)

**模型**: 2 成分 A–B の正則溶体。組成 $X$(または $c$)= B の割合(0〜1)。混合の自由エネルギーを $RT$ 単位で

$$g(c) = \chi\,c(1-c) + c\ln c + (1-c)\ln(1-c),\qquad \chi = \Omega/RT$$

と書く。臨界温度は $\chi = 2$($T/T_c = 2/\chi$)。読者向けのスライダーは $\chi$ ではなく **$T/T_c$** で出す。

**代表値**($T/T_c = 2/3$、すなわち $\chi = 3$): バイノーダル $c_b = 0.0707$(と 0.9293)、スピノーダル $c_s = 0.2113$(と 0.7887)。

**単位**: 長さ・時間は無次元(格子間隔 = 1、拡散の時間単位)。図注で「実際の金属合金では特性波長は数 nm、分離は数分〜数時間」と目安を添える。

**色**:

| 対象                           | 色                                                                                                 |
| ------------------------------ | -------------------------------------------------------------------------------------------------- |
| A 原子・A リッチ相             | `--mat-matrix`                                                                                     |
| B 原子・B リッチ相             | `--mat-second`(カーケンドール記事の「B 原子」と同じ意味)                                           |
| 連続的な濃度場                 | **`--mat-matrix` と `--mat-second` の 2 色間の補間**(虹色のカラーマップは使わない — 母体仕様 §2-7) |
| 自由エネルギー曲線・状態図の線 | `--color-text-2`(バイノーダルは実線、スピノーダルは破線)                                           |
| 共通接線                       | `--color-accent`(参照の線。オストワルド記事の臨界半径の線と同じ扱い)                               |
| 状態点・置いた核の目印         | `--color-accent` の輪                                                                              |

核生成で生じた粒子もスピノーダルの迷路も同じ B リッチ相なので、同じ色で描く(§0-1)。

各節の要旨:

**1. 二種類の分かれ方(導入)** — 「2 相に分かれる」といっても、顕微鏡で見ると 2 通りある。図1 の左は、母相の中に**離散した粒子が散らばる**組織(核生成・成長 — GP ゾーンの記事で見たもの)。右は、**2 つの相が連結して絡み合った迷路**のような組織。驚くべきことに、2 つは**同じ合金・同じ方程式**で、違うのは組成(と、それで決まる出発点の安定性)だけである。なぜこんなに違う形になるのかを、記事の問いとして立てる。

**2. 混ざるか分かれるか — 自由エネルギー曲線** — 組成 $X$ に対する混合の自由エネルギー $G(X)$ を描く。高温では下に凸の 1 つの谷で、混ざったままが得。低温では**谷が 2 つある形**になり、真ん中の組成では 2 つの組成に分かれたほうが $G$ が下がる。分かれた後の 2 相の組成は、2 つの谷に同時に接する**共通接線**の接点で決まり、それぞれの量は「てこの原理」で決まる。図2 で組成をドラッグさせ、その組成で「分かれたほうが得か」を、曲線と接線の高さの差として読ませる。

**3. 2 本の線 — バイノーダルとスピノーダル** — $G(X)$ から状態図に 2 本の線が引ける。共通接線の接点を温度ごとにつないだ**バイノーダル**(= 溶解度線。GP ゾーン記事の固溶限と同じもの)と、$G(X)$ の曲がり方(曲率)がゼロになる点をつないだ**スピノーダル**。図3 で状態点を動かすと、3 つの領域が分かる: バイノーダルの外は**安定**(混ざったまま)、バイノーダルとスピノーダルの間は**準安定**(分かれたほうが得だが、始めるには核が要る — 障壁がある)、スピノーダルの内側は**不安定**(曲率が負で、どんな小さなゆらぎも育つ — 障壁がない)。**GP ゾーンの記事の舞台は準安定の領域**だったことを明示し、2 記事を結ぶ。

**4. 上り坂拡散(記事の山場)** — スピノーダルの内側では、濃度差を広げるほうが自由エネルギーが下がる。拡散を押すのは濃度の勾配ではなく**化学ポテンシャルの勾配**なので、ここでは原子が**濃い方へ向かって**流れる — 上り坂拡散。フィックの法則の形に無理に書けば拡散係数が負になる。カーケンドール記事 S1 で「原子は濃度を知らずにランダムに跳ぶだけ、それでも統計として濃度が均される」と学んだ読者に、その逆を納得させる必要がある。図4 では原子が**隣とランダムに入れ替わるだけ**で、ただし入れ替わりが受け入れられる確率が、同種の原子と隣り合うほど少し高い(エネルギーの地形)。**原子は濃度を知らない、という原則は破れていない** — 変わったのは各原子が感じるエネルギーの地形であり、その統計の結果として正味の流れが濃い方へ向く。高温にすると同じ原子の跳び方で濃度差が均されるのを、同じ図で確かめさせる。

**5. どの波長が育つか** — すべての濃度の波が同じ速さで育つわけではない。波長が短いほど A と B の境目(界面)が増え、界面のエネルギー(勾配エネルギー $\kappa$)がそれを抑える。逆に波長が長いと、原子を遠くまで運ばなければならず時間がかかる。この競合で、**増幅率が最大になる特性波長 $\lambda_m$** が決まる(式 E6・E7)。図5 で増幅率と波数のグラフを読み、短い波・長い波・ちょうどよい波の育ち方を比べる。これが組織の「模様の細かさ」を決める。実験ではこの波長は、散乱強度のピーク(小角散乱)として測られる([構造因子](/articles/structure-factor/)の考え方)。

**6. 迷路が育つ — カーン・ヒリアード(中心図版)** — 図6 で 2 次元の数値計算(カーン・ヒリアード方程式、式 E8)を回す。ランダムな微小ゆらぎから、特性波長の模様が浮かび上がり、連結した迷路に育つ。組成を変えると模様の形が変わる: **50:50 付近では連結した迷路、偏った組成では孤立した島**(島でもスピノーダルなら核生成とは別物 — 障壁なしに一斉に現れる)。状態点を準安定の領域に移すと、**ゆらぎは消えて何も起きない**。そこへ「核を置く」で B リッチの小さな円を置くと、**臨界半径より小さい核は溶けて消え、大きい核だけが育つ** — GP ゾーンの記事の核生成の障壁を、同じ方程式・同じ画面で体験させる。初期の模様の波長が S5 の $\lambda_m$ と一致することも、画面の隅の散乱強度のグラフで確かめる。

**7. その後 — 粗大化と実材料** — 模様ができたあとも、界面を減らす方向に**模様が粗くなり続ける**。ここから先はオストワルド成長と同じ論理(界面エネルギーの削減)であり、代表長さは $t^{1/3}$ で育つ(オストワルド成長の記事の図6 と同じ形)。図7 の両対数のグラフで確かめる。実材料の例: Fe–Cr 合金の 475 ℃ 脆化(ステンレス鋼の使用温度の上限を決める)、ガラスの分相(バイコールガラスは分相させた一方の相を酸で溶かして作る多孔質ガラス)、Cu–Ni–Fe や Alnico 磁石。静的図 S-2 で、分相ガラスの製法を模式化する。

**8. まとめ** — 「障壁を越えて始まる分離(核生成・成長)」と「障壁なしに始まる分離(スピノーダル)」の対比で回収する(静的図 S-3)。[GP ゾーン](/articles/gp-zones/)と[オストワルド成長](/articles/ostwald-ripening/)へ相互リンク。

| $A$                    | 8                                          | 既定の温度範囲で自由エネルギーが単調に減るのに十分な値(試作で確認) |
| $\Delta t$             | 0.5(図6・図7)                              | **定数として固定し、読者には触らせない**(発散させない)             |
| 1 フレームのステップ数 | 図6: 4、図7: 8〜16(自動)                   | 描画とソルバのステップ数を分離する                                 |

**本仕様の作成時に Python で試作して確認した振る舞い**(同じスキーム・同じ定数、128²):

- 平均組成のずれ $5\times10^{-15}$(20000 ステップ)、自由エネルギーは全区間で単調減少。
- 線形成長率: 単一の波を入れたときの数値の増幅率は、**離散スキームの増幅率** $\frac{1 - \Delta t k^2 (g'' - A)}{1 + \Delta t A k^2 + \Delta t \kappa k^4}$ と一致する(0.2243 / 時間単位)。連続の理論値 $R(k) = -k^2(g'' + \kappa k^2)$(0.2497)との差は安定化の時間刻み誤差で、$\Delta t$ を小さくすると一致する。
- 粗大化: 局所指数 0.21〜0.34、$t$ = 100〜6000 の通しで約 0.30。系の大きさの半分に近づくと飽和する。
- 準安定($\chi = 3$): $c_0 = 0.15$ で微小なゆらぎは完全に消える。置いた核の臨界半径は $c_0$ = 0.15 で 2 格子未満、0.12 で 2〜3、0.10 で 3〜4、**0.09 で約 7(半径 6 は消え、8 は残る)**。0.085 では系全体の過飽和が足りず、どの大きさの核も維持できない(有限の箱の効果)。

**`lib/latticegas.ts`(図4)**: 正方格子の A/B 格子気体、最近接の相互作用 $J$(同種どうしが隣り合うと $-J$)。**隣どうしの原子を交換する**試行を、メトロポリス法($\min(1, e^{-\Delta E/k_BT})$)で受け入れる(カワサキ動力学 — 組成は厳密に保存)。周期境界、64×32 サイト。$T_c = 2.269\,J/k_B$(2 次元イジング模型の厳密値)で $T/T_c$ を表示する。**本仕様の作成時の試作**: 初期に波長 16 サイト・振幅 0.13 の濃度の波を入れると、$T/T_c = 0.6$ で 600 掃引後に 0.21 へ育ち、1.5 では 0.04(雑音の床)へ減衰した。組成は全ステップで保存された。

**共通規約**

- 乱数(初期のゆらぎ・核の発生・原子交換)はすべて `mulberry32`・シード固定。`reset` で同じ模様が再現される。
- 濃度場の描画は `ImageData` への直接書き込み(画素ごとの `fillRect` を使わない — 母体仕様 §8.3)。2 色の補間テーブル(256 段)を初期化時に 1 度だけ作る。
- 格子・時間は無次元。図注に「実際の合金では特性波長は数 nm」を添える。
- 状態点を表すドラッグ点(図2・図3)は `reciprocal-lattice/_shared2d.ts` の `attachDragPoints`(キーボード操作つき)を使う。

組成・温度を変えたら、その条件の一様な初期状態(+ シード固定のゆらぎ)からやり直す。
読み取り値: 領域(安定 / 準安定 / 不安定)、経過時間、代表長さ $L$(散乱強度から)、予測される $\lambda_m$、自由エネルギーの減少量。

**背後のモデルと簡略化**
§5.0 のスキーム。代表長さは $L = 2\pi\,\sum S(k) / \sum k\,S(k)$。組成の下限 0.09 は、それより平衡組成(0.0707)に近いと有限の箱では核が維持できないため(§5.0 の試作結果)。**誠実な簡略化(図注に明示)**: 2 次元の計算で 3 次元の組織の断面ではない(模様の見え方は 3 次元と異なる)、弾性ひずみなし、熱ゆらぎなし(準安定域で自然に核ができないのはこのため — 核は読者が置く)、長さ・時間は無次元。

**実装方式**: 2D Canvas / `onFrame`。FFT は `src/core/fft.ts`。`Float64Array` をフレーム間で使い回し、毎フレームの新規割当てをしない。散乱強度の計算は 10 フレームに 1 回。

**図注(案)**: 「図6. カーン・ヒリアード方程式の 2 次元の数値計算。不安定の領域では、ごく小さなゆらぎから最も速く育つ波長の模様が浮かび、連結した迷路に育つ(右下のグラフのピークが予測の波長に乗る)。準安定の領域では、ゆらぎは消えて何も起きない。小さな核は溶け、臨界半径より大きな核だけが育つ。2 次元・弾性ひずみなし・熱ゆらぎなしの計算で、長さと時間は無次元。」

**alt(案)**: 「正方形の濃度の地図。再生すると、一様な灰色から細かいまだら模様が浮かび上がり、青と灰色のつながった迷路に育っていく。組成を偏らせると孤立した島になる。準安定の条件にすると何も起きず、小さな円を置くと消え、大きな円を置くと育つ。」

**受け入れ基準**

- [ ] 平均組成が保存される(表示しないがテストで担保)
- [ ] 不安定の領域で、初期の $S(k)$ のピークが予測の $k_m$ と 15% 以内(§5.8 T7)
- [ ] $c_0 = 0.09$・$T/T_c = 2/3$ で、半径 6 の核は消え、半径 8 の核は残る(§5.8 T6)
- [ ] 準安定でゆらぎだけのときは何も育たない
- [ ] 中位スマホで 30fps 以上(必要なら格子を自動で縮小)
- [ ] `reset` で同じ模様が再現される

### 5.7 図7 `coarsening-transition` — その後(発展)

**表示するもの / 初期状態**
左(幅 50%): 長時間の濃度場($c_0 = 0.5$、$T/T_c = 2/3$)。時間とともに迷路の模様が粗くなる。
右(幅 50%): 代表長さ $L$ と時間 $t$ の両対数グラフ。点を自動で打ち(時間の対数で等間隔)、**傾き 1/3 の参照直線**(オストワルド成長記事の図6 と同じ描き方)を重ねる。初期(線形の段階)・中間・後期の 3 区間を薄いラベルで示す。系の大きさの半分に近づいた区間には「箱の大きさの影響」の斜線。
初期は停止、時刻 0。

**操作パラメータ**

| 名前            | 部品                     | 範囲 | 初期値 | 単位 |
| --------------- | ------------------------ | ---- | ------ | ---- |
| 再生 / 一時停止 | playPause                | —    | 停止   | —    |
| 早送り          | segmented: ×1 / ×4 / ×16 | —    | ×4     | —    |
| リセット        | reset                    | —    | —      | —    |

読み取り値: 経過時間、$L$、直近の局所的な傾き、通しの傾き(後期)。

**背後のモデルと簡略化**: §5.0 のスキーム(1 フレームのステップ数を早送りで増やす)。試作では局所の傾きが 0.21〜0.34 で揺れ、通しで約 0.30 になった — **1/3 にゆっくり近づく**こと、揺れは有限の系の統計であることを図注に書く。早送りは端末の性能に合わせて自動で抑える(1 フレームの計算 8 ms 以内)。

**実装方式**: 2D Canvas / `onFrame`。

**図注(案)**: 「図7. 模様ができた後も、界面を減らす向きに組織は粗くなり続ける。代表長さは時間の 1/3 乗で育つ — オストワルド成長と同じ形である。傾きは有限の大きさの計算のため揺れ、終盤は箱の大きさで頭打ちになる。」

**alt(案)**: 「左の迷路の模様が時間とともに太く粗くなっていく。右の両対数グラフでは、点が傾き 3 分の 1 の参照直線に沿って並び、最後は箱の大きさの影響で寝ていく。」

**受け入れ基準**

- [ ] 後期の通しの傾きが 0.25〜0.38
- [ ] 箱の大きさの影響の区間が表示される
- [ ] 早送りで 1 フレームの計算が 8 ms を超えない(超えるなら自動で抑える)
