**記事仮題**: 「オストワルド成長 — なぜ大きな粒子だけが生き残るのか」

---

## 1. 学習目標

読み終えた読者が、次のことをできるようになる。

1. 界面がエネルギーを持つこと、および球の界面積/体積比 $A/V = 3/r$ から、「総量が一定のまま総界面を減らす」という粗大化の駆動力を説明できる。
2. ギブス・トムソン効果 — 小さい粒子ほど周囲の平衡溶質濃度が高い($c(r) = c_\infty e^{l_c/r}$)— を、曲率と原子の離脱しやすさから説明し、毛管長 $l_c \sim 1\,\mathrm{nm}$ という目盛り感覚を持てる。
3. 「濃度差 → 拡散流 → 大が小を食う」の機構を、臨界半径 $r^*$ と「$r^*$ 自身が上がり続ける」事実を含めて説明でき、LSW の $t^{1/3}$ 則($\bar r^3 - \bar r_0^3 = Kt$)で粗大化の速さを見積もれる。
4. 過時効による強さの低下を、体積分率一定のもとでの粒子間隔の拡大とオロワン機構($\Delta\tau = \mu b / L$)で微視的に説明し、時効処理の温度・時間管理という実務に結びつけられる。
5. (発展)速度定数 $K = \frac{4}{9} D c_\infty l_c$ の3因子(拡散・固溶度・界面エネルギー)がすべて掛け算で効くことから、Ni基超合金や ODS 鋼の「粗大化に抗う設計」を説明できる。

## 2. 前提知識と関連記事

- **仮定する知識**: 高校物理(力・エネルギーの初歩)、指数・対数関数。「拡散=原子のランダムウォーク」という素朴なイメージ。
- **前提記事**: [GPゾーン](/articles/gp-zones/)(推奨)。時効硬化の「登り」(析出粒子がなぜ強くするか)に馴染みがあると S1・S7 の文脈が濃くなる。[コットレル雰囲気](/articles/cottrell-atmosphere/)(推奨)。拡散のランダムウォーク描像とアレニウス式は同記事 §S4 が丁寧。いずれも未読で読み通せるよう、本記事内で最小限を自給する。
- **相互リンク**: 「まとめ」から GPゾーン(強化の立ち上がり)・コットレル雰囲気(溶質と拡散のもう一つの物語)へ。S7 本文からフランク・リード源(転位の張り出しの物理)へ。

## 3. 章立てとナラティブ

記事全体の筋: **「閉じた系なのに、組織が一方向に変わり続ける」という謎を冒頭に提示し、原子スケールに降りて部品(界面のコスト → 曲率と濃度 → 2粒子の綱引き → 臨界半径)を1つずつ組み立て、$t^{1/3}$ 則で定量化したのち、試験片スケールへ戻って強さの衰え(過時効)で謎を回収し、耐熱材料の設計という実用へ着地する。**

### S1. 何もしていないのに、変わってゆく(導入)

ピーク時効に達した Al–Cu 合金の「その後」を読者自身に観察させる。高温に保持すると、析出粒子の総量(体積分率)は一定のまま、粒子の数が減り、平均サイズが育ち、そして強さが下がっていく。溶質を足しても引いてもいない閉じた系で、なぜ組織は一方向に変わり続けるのか — これを記事の問いとして立てる。身近な同類として、冷凍庫に長くあったアイスクリームがジャリジャリになる現象(氷結晶の粗大化)に一言触れ、答えは「界面」と「曲率」にあると予告する。

- 使用図版: 図1 `coarsening-timelapse`
- 必ず触れる点: 「数が減る・平均が育つ・総量は不変」の3点セット。強さの低下=過時効という実害。閉じた系で自発的に進む以上、駆動力があるはずだ、という問いの立て方。

### S2. 界面というコスト

駆動力の正体の半分: 界面はエネルギーを持つ。界面の原子は粒子と母相の「どちらつかず」で、結合の相手が足りない(静的図 S-1)。同じ量の析出物でも、細かく分けるほど総界面積は増える — 球なら $A/V = 3/r$ で、総量一定のまま数を8倍にすると総界面は2倍になる。だから系は「まとまって界面を減らしたい」。しかし粒子どうしは母相を隔てて離れており、直接合体はできない。ではどうやって物質をやり取りするのか? を次節への引きにする。

- 使用図版: 図2 `interface-budget`
- 必ず触れる点: 界面エネルギー $\gamma$ の意味。$A/V = 3/r$ と $A_{tot} \propto N^{1/3}$。駆動力=総界面エネルギーの削減。小粒子では原子のかなりの割合が界面にいる、という数字の驚き。「直接合体できない」という制約(輸送は拡散頼み)。

### S3. 小さい粒ほど、こらえ性がない — ギブス・トムソン効果

離れた粒子間で物質をやり取りする仕掛けが曲率である。強く曲がった界面にいる原子は同種の隣が少なく、離脱しやすい(図3のズーム/静的図 S-2)。その結果、小さい粒子ほど周囲の平衡溶質濃度が高くなる: $c(r) = c_\infty e^{l_c/r}$。毛管長 $l_c = 2\gamma\Omega/k_BT$(本モデルで約 1 nm)を導入し、$r$ が数 nm を切るあたりから効きが急に立ち上がる感覚を、半径スライダーと濃度メーターで掴ませる。

- 使用図版: 図3 `gibbs-thomson-probe`、静的図 S-2
- 必ず触れる点: 指数形と線形近似($c \approx c_\infty(1+l_c/r)$)の使い分け。$l_c$ の数値感覚(〜1 nm)。「小さい → 離脱しやすい → 周囲が濃い」という因果の向き。

### S4. 隣どうしの綱引き

小さい粒子の周りは濃く、大きい粒子の周りは薄い。二つを母相でつなげば濃度勾配が生まれ、溶質は小から大へ拡散で流れる。小さい方は削られてさらに小さく=さらに周囲が濃く=さらに速く削られる、という正のフィードバックで、最後は一気に消える(「最後のひと呑み」)。同じ大きさなら引き分けだが、わずか 5% の差が運命を分ける — この不安定性こそ機構の心臓である。距離が遠いほど遅いことも確認させ、輸送を担うのが拡散であることを押さえる。

- 使用図版: 図4 `two-particle-tug`
- 必ず触れる点: 準定常の濃度プロファイル(両界面の $c(r)$ を端点とする勾配)。$1/r$ に由来する終盤の加速。等サイズは不安定平衡であること。距離依存(遠いと遅い)。

### S5. 生き残りの線は、上がり続ける — 臨界半径

多数の粒子では、各粒子は母相の平均濃度と溶質をやり取りする(平均場)。周囲の平衡濃度が平均より高い(=小さい)粒子は溶け、低い(=大きい)粒子は育つ。境目が臨界半径 $r^*$ であり、体積保存から $r^*$ は平均半径 $\bar r$ に等しい(一行導出は脚注)。平均は育つから、$r^*$ も上がり続ける。すると、いま成長中の粒子もやがて上がってきた $r^*$ に追い抜かれ、溶ける側に回る — 「今日の勝ち組は明日の負け組」。1個の粒子を追跡し、成長→失速→溶解という生涯を見届けさせる。

- 使用図版: 図5 `ripening-arena`(本記事の中心図版)
- 必ず触れる点: $r^*$ の定義($dr/dt = 0$ となる半径)。$r^* = \bar r$(体積保存の帰結)。$r^*$ の上昇と順位の入れ替わり。温度は本モデルでは「時計の速さ」だけを変えること(実時間換算表示の読み方、図注)。

### S6. 3分の1乗の法則 — LSW理論

成長速度は $\frac{dr}{dt} = \frac{Dc_\infty l_c}{r}\left(\frac{1}{r^*}-\frac{1}{r}\right)$。これをスケーリングすると、平均半径は $\bar r^3 - \bar r_0^3 = Kt$、$K = \frac{4}{9}Dc_\infty l_c$ に従う(LSW 理論)。$t^{1/3}$ は「遅い」法則 — 半径を2倍にするには8倍の時間がかかる。$K$ には拡散の速さ・溶けやすさ・界面の張りが全部掛け算で入っている(S8 への伏線)。もう一つの驚きとして、サイズ分布が形を保ったまま拡大していく自己相似性を、規格化ヒストグラムの重ね合わせで見せる。数密度が $t^{-1}$ で減ること($f$ 一定と $\bar r^3 \propto t$ の帰結)にも触れる。

- 使用図版: 図6 `one-third-law`
- 必ず触れる点: なぜ 1/3 か(拡散律速のスケーリング。厳密導出はしない)。$K$ の3因子。自己相似分布。**誠実な簡略化**: LSW は希薄極限(体積分率→0)の理論で、実合金(有限 $f$)では係数が大きく分布は広い(脚注)。界面反応律速なら $t^{1/2}$ になる、という対比も脚注で可。

### S7. 間隔が開けば、するり — 過時効

S1 の「強さの低下」を回収する。析出強化の効き目を決めるのは粒子の「間隔」である: 転位は粒子間を張り出して通り抜け(オロワン機構。張り出しの物理はフランク・リード源記事)、必要応力は $\Delta\tau = \mu b/L$。粗大化は $f$ 一定のまま $\bar r$ を育てるので、間隔 $L \approx \beta\bar r/\sqrt f$ も開き、強さは $1/\bar r \propto t^{-1/3}$ で衰える。時効時間・温度スライダーで組織と強さ曲線の連動を観察させ、「時効処理とは、登り(GPゾーン記事)と下り(本記事)の間の頂上で止める、時間との勝負」という実務の視点で締める。

- 使用図版: 図7 `overaging-strength`
- 必ず触れる点: $f$ 一定での $L \propto \bar r$。$\Delta\tau = \mu b/L$。強さの $t^{-1/3}$ 減衰。温度を上げると曲線が log t 軸上で左へ平行移動すること。切断→張り出しの遷移(登り側)は前提記事に委ね、本図は過時効側のみをモデル化する旨(図注)。

### S8. 粗大化に抗う — 耐熱材料の設計(発展)

ジェットエンジンのタービン翼は 900 °C 超で1万時間、強さを保つ。秘密は $K = \frac{4}{9}Dc_\infty l_c$ の3因子をそれぞれ潰す設計にある: ① $\gamma$ を下げる(Ni基超合金 γ′ の整合界面は非整合の数十分の一)、② $D$ を下げる(Re など動きの遅い元素の添加)、③ $c_\infty$ を下げる(ODS 鋼の酸化物粒子はほぼ固溶しない — 溶けない粒子は太れない)。掛け算ゆえ、どれか一つを一桁下げれば寿命が一桁延びる。締めに普遍性: ビールの泡、アイスの氷、エマルションの油滴 — 「曲率が周囲を濃く(圧を高く)し、大が小を食う」は物質を選ばない。

- 使用図版: 図8 `coarsening-design`、静的図 S-3
- 必ず触れる点: 3レバーと $K$ の積構造。整合界面の $\gamma$ の桁の小ささ。ODS の発想。発展節であり読み飛ばし可能である旨を冒頭に明記。

### まとめ

因果の鎖を5行で再掲する: 界面はコスト($A/V=3/r$)→ 曲率が周囲を濃くする(ギブス・トムソン)→ 濃度差が小→大の拡散流を生む → $r^*=\bar r$ が上がり続け、大だけが残る($t^{1/3}$)→ 間隔が開いて強さが衰える(過時効)。そしてこの鎖のどこかを断つのが耐熱設計である。S1 の謎を回収し、GPゾーン・コットレル雰囲気へ誘導する。

- **校正**: $K(T)=\frac{4}{9}Dc_\infty l_c$ の前係数は「$\bar r$(200 °C・10 h)≈ 15 nm」となるよう校正してよい(画面上の時間・寸法の目盛り感覚を教科書的な範囲に保つため)。温度依存はみかけの活性化エネルギー $Q_K$ で与えて構わない。
- **無次元化と実時間換算**: 長さを $l_c$、時間を $l_c^3/K(T)$ で無次元化すると、成長方程式から温度が消える。エンジンは無次元で1本走らせ、**表示だけ**を温度に応じて実時間へ換算する(秒/分/時間/日/年の自動整形。コットレル記事・図5 と同じ流儀)。したがって本モデルでは温度は進化の「形」を変えず「時計の速さ」だけを変える — この事実自体を各図の図注で明示する。
- **数値処理の注意**: $dr/dt$ は $r\to r_{dis}$ で急峻になるため、最小半径に応じたサブステップ(または dr のクランプ)を行う。$r<r_{dis}$ の粒子は「溶解」としてアンサンブルから除去する(除去に伴う微小な体積誤差は図注で明示するか、残余を $r^*$ 計算で吸収する)。**単体テスト推奨**: (a) 2粒子系で大が育ち小が消える、(b) 溶解イベント間で $\sum r^3$ が保存(相対誤差 < 10⁻³)、(c) 長時間で log $\bar r$–log t の傾きが 1/3 ± 0.03。
- **色**: 母体仕様 §6.2 に従う。母相背景 `--mat-matrix`(薄)、析出粒子・溶質原子 `--mat-solute`、濃度場は `--mat-solute` の不透明度で表現、臨界半径 $r^*$ のマーカー・参照線 `--color-accent`、転位(図7)`--mat-defect`。成長/収縮の区別は塗り色でなく矢印・輪郭で表し、圧縮/引張の意味色は本記事では使わない(意味の混線を避ける)。数式の変数色: $c, c_\infty, c(r), l_c$ → solute 色、$r^*$ → accent 色、$\mu, b$ → defect 色、その他は本文色。
- **レイアウト**: 「ステージ+プロット」の横並び構成(図1・4・5・7)は、600 px 以下で縦積みに切り替える。
- **モデルの位置づけ**: すべての曲線・数値は「典型値による現象論モデル」であり実測データではない。各図注にその旨を明示する(母体仕様 §2-5)。

### 5.4 図4 `two-particle-tug` — 大は小を食う

**表示するもの / 初期状態**
- 上: 左に粒子1(小)、右に粒子2(大)、中心間距離 d。母相の溶質ドットは濃度に応じて分布し、平均として小→大へ流れて見える(ドリフト付きランダムウォークの見かけ)。
- 下: 濃度プロファイル $c(x)$(両界面の $c(r_i)$ を端点とする準定常勾配)+ $c_\infty$ の参照線。流れの向き矢印。
- 読み出し: $r_1, r_2$ [nm]、経過時間(200 °C 換算)。
- 初期状態: $r_1$=6 nm、$r_2$=9 nm(比 1.5)、d=60 nm、一時停止。

**操作パラメータ**

| 名前 | UI | 範囲 | 初期値 | 備考 |
|---|---|---|---|---|
| 初期サイズ比 $r_2/r_1$ | slider | 1.0〜3.0(step 0.05) | 1.5 | $r_1$=6 nm 固定。変更時は自動 reset |
| 距離 d | slider | 30〜120 nm | 60 nm | 変更時は自動 reset |
| プリセット「ほぼ互角」 | button | 比 1.05 に設定 | — | 不安定平衡の演出 |
| 再生/一時停止・リセット | playPause / reset | — | — | — |

**モデルと式**
- $\dfrac{dr_i}{dt} = \dfrac{Dc_\infty l_c}{r_i}\left(\dfrac{1}{r^*_2}-\dfrac{1}{r_i}\right)g(d)$、$r^*_2 = (r_1+r_2)/2$(2粒子の体積保存閉包)、$g(d) = d_0/d$($d_0$=60 nm。距離が遠いほど遅い、という模式係数)。
- $r_1 < r_{dis}$ で溶解演出(縮んで消え、残った溶質が流れ込む見かけ)。
- 簡略化の明示(図注): 1対1・準定常・模式配置。実際は3次元の拡散場での多体問題。$g(d)$ と閉包式は実装用で本文非掲載。

**実装方式**: 2D / onFrame + `fixedStep`。

**受け入れ基準**
- [ ] 比 1.5 で小が縮み大が育ち、終盤に縮小が加速して消える(「最後のひと呑み」)
- [ ] 比 1.0 では何も起こらず、比 1.05 では長い均衡ののちに崩れる
- [ ] d を2倍にすると進行が約半分に遅くなる
- [ ] プロファイルの勾配が常に小→大の向きで、半径の変化と整合している
