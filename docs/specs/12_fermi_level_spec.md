## 1. 学習目標

読了・操作後に、読者が次のことをできるようになる。

1. フェルミ準位 $E_F$ を、「絶対零度で埋まった最上位」から「**占有確率がちょうど 1/2 になる高さ = 電子の化学ポテンシャル**」へ定義を広げて説明できる。**ギャップの中に $E_F$ があっても、そこに電子がいるわけではない**と言える。
2. フェルミ・ディラック分布の裾の幅が $k_BT$ の数倍であること、室温の $k_BT \approx 26$ meV が Si のギャップ 1.12 eV の **約 1/43** であることから、伝導帯に上がる電子がごくわずかな理由を説明できる。
3. キャリア密度が「状態密度 × 占有確率」の積分であり、その積が意味を持つのは**バンド端から数 $k_BT$ の狭い範囲だけ**であることを図で示せる。
4. 真性半導体で $n = p = n_i$ となり、$n_i \propto \exp(-E_g/2k_BT)$ の **「2」が生成と再結合のつり合いから来る**ことを説明できる。
5. ドーピングで $E_F$ が動き、n 型・p 型になることを述べ、**500 万分の 1 の不純物で導電率が約 70 万倍**になることを数値で言える。
6. 熱平衡で $np = n_i^2$ が成り立つこと、それが**平衡でなければ破れる**こと、2 つの材料を接触させると $E_F$ が揃うことを述べられる(次記事への伏線)。

### 2.3 表記と慣習(記事全体の約束)

**エネルギーの原点**: 価電子帯の頂上を $E_v = 0$、伝導帯の底を $E_c = E_g$ とする(バンド理論記事の図7 と同じ取り方)。図版の縦軸はすべて「上がエネルギー高」。

**単位**: エネルギーは eV(熱エネルギーの読み取りだけ meV)、温度は K、**キャリア密度は cm⁻³**(半導体分野の慣習)。バンド理論記事は 1 次元の電子数を nm⁻¹ で数えていたので、本文で一度「1 nm⁻³ = 10²¹ cm⁻³」と対応を示す。

**モデル材料(定数は `_shared/semiconductor.ts` の `SILICON` に 1 箇所だけ置く)**:

| 量                       | 値                                      | 備考                                                                          |

| バンドギャップ $E_g$     | 1.12 eV                                 | **温度によらず一定**とする簡略化(実際は 700 K で約 1.0 eV に縮む)。図注で明示 |
| 有効状態密度 $N_c$       | $2.86\times10^{19}$ cm⁻³(300 K)         | $\propto T^{3/2}$                                                             |

各節の要旨:

**1. 下から詰める** — バンド理論の記事では、電子を「下から順に」詰めた。その理由がパウリの排他律である: 1 つの席にはスピン ↑ と ↓ の 2 個までしか入れない。図1 の「席のはしご」に電子を 1 個ずつ足していくと、最後に埋まった席と最初の空席の**中間**にフェルミ準位 $E_F$ の印が付く。隙間のない材料では、これは「埋まった最上位」とほぼ同じ高さである。ところが隙間のある材料で下の帯をちょうど埋めきると、$E_F$ の印は**ギャップのど真ん中** — 席が 1 つもない高さ — に跳ぶ。「席がないところに $E_F$ がある」のは変ではないか? と問いを残して次節へ。

**2. 温度がぼかす(中心図版)** — 有限温度では、$E_F$ の少し上の席にも電子が入り、少し下の席が空く。占有確率はフェルミ・ディラック分布 $f(E)$(式 E1)で、階段がなだらかな坂になる。**$f(E_F) = 1/2$ はどの温度でも変わらない** — これが $E_F$ の一般的な定義であり、S1 の「中間」はその $T \to 0$ の極限だった。坂の幅はおよそ $4.4\,k_BT$。室温の $k_BT$ は 26 meV で、Si のギャップ 1.12 eV はその **43 倍**。Si のバンド端を重ねて表示すると、伝導帯の底での $f$ は $4\times10^{-10}$ しかないことが読み取れる。$E - E_F$ が $k_BT$ の数倍以上なら $f$ は指数関数で近似できる(ボルツマン近似、式 E3)ことも重ねて見せる。

**3. 席の数 × 埋まり具合 = 電子の数** — $f(E)$ は「その高さの席が埋まっている確率」にすぎない。実際の電子数には、その高さに席がいくつあるか(状態密度 $g(E)$)を掛けて足し合わせる(式 E4)。図3 は $g$・$f$・その積を、同じエネルギー軸で横に並べる。積が意味を持つのは**伝導帯の底から数 $k_BT$ の狭い範囲だけ** — 席はもっと上にもたくさんあるが、そこまで上がれる電子がいない。この細い山の面積をまとめた量が有効状態密度 $N_c$ で、$n \approx N_c\exp[-(E_c-E_F)/k_BT]$(式 E5)と書ける。価電子帯の空席(次節で正孔と呼ぶ)も同じ形になる(式 E6)。

**4. 混ぜ物のない半導体 — 真性キャリア** — 純粋な Si では、伝導帯の電子は必ず価電子帯から上がってきたものなので、上がった電子の数と、価電子帯に残った空席の数が等しい。この空席は**正の電荷をもつ粒子のようにふるまう**(バンド理論記事の「負の有効質量」の一言がここで効く)ので、**正孔**(hole)と呼ぶ。図4 では熱で電子が上がり(生成)、電子と正孔が出会うと消える(再結合)。両者がつり合うと $n = p = n_i$ に落ち着き、$E_F$ はギャップのほぼ中央に来る(S1 の違和感の回収: $E_F$ はそこに電子がいる高さではなく、上と下の数を釣り合わせる「水位」である)。読者に「熱の強さ」を変えて平均の数を記録させると、**$n_i \propto \exp(-E_g/2k_BT)$ の「2」** が現れる — 生成は $\exp(-E_g/k_BT)$ に比例し、再結合は $n \times p = n^2$ に比例するので、つり合いの $n$ は平方根になる。正孔は実在の粒子ではなく、空席の集団的なふるまいを粒子として扱う便利な描像であることを図注で明示する。

**5. 不純物を少し混ぜる — ドーピング** — Si(4 価)に P(5 価)を混ぜると、結合に使われない 5 個目の電子が余る。この電子は P のまわりに弱く束縛されているだけで(約 45 meV、軌道は格子間隔の 4〜5 倍に広がる — 静的図 S-2)、室温の $k_BT$(26 meV)でほぼすべて伝導帯へ上がる。結果として $n \gg p$ の **n 型**になり、$E_F$ は伝導帯側へ動く。B(3 価)なら逆に **p 型**。ドーピング量は極めて少ない: $10^{16}$ cm⁻³ は Si 原子 $5\times10^{22}$ cm⁻³ の **500 万分の 1** だが、導電率は真性の **約 70 万倍**になる。図5 の右の n–T グラフで、低温では電子がドナーに戻って減り(凍結)、高温では真性キャリアが上回る(真性領域)ことを見せ、その間の「$n \approx N_D$ でほぼ一定」の広い領域が半導体を使える温度帯であると述べる。ドーピングを $10^{19}$ cm⁻³ 以上にすると $E_F$ がバンドに入り込み、ボルツマン近似が使えない(**縮退**)ことにも一言触れる。

**6. 積は変わらない** — n 型にして $n$ を増やすと、$p$ は減る。しかも**積 $np$ は温度だけで決まり、$n_i^2$ に等しい**(式 E11、質量作用の法則)。図6 で $E_F$ を動かすと、対数目盛の上で $n$ と $p$ が同じ量だけ逆向きに動き、その真ん中が $n_i$ の線から離れないことを確かめる。少ない側のキャリアを**少数キャリア**と呼ぶ。最後に「光を当てる」をオンにすると、生成が増えて $np > n_i^2$ になる — **この法則は熱平衡でのみ成り立つ**。このとき電子と正孔には別々の「水位」(擬フェルミ準位)が要ることを一言だけ示し、次の記事で使うと予告する。

**7. フェルミ準位の本当の意味(次記事への伏線)** — $E_F$ は「どこまで埋まっているか」の目印である以上に、**電子の電気化学ポテンシャル**である。だから決定的な性質が 1 つある: 2 つの材料を接触させて平衡に達すると、**$E_F$ は必ず一直線に揃う**。図7 で $E_F$ の違う 2 つの Si(左に p 型、右に n 型)を接触させると、電子が $E_F$ の高い側から低い側へ移り、その結果として生じた電位差の分だけ**バンドが曲がって**、$E_F$ が揃う。曲がりの段差は、接触前の $E_F$ の差にちょうど等しい。**ここで説明を止める**: 「バンドが曲がった。この坂が何を意味するのかは次の記事で」と締める(曲がりの形・空乏層・電場は #13 の主題なので先取りしない)。

**8. まとめ** — 静的図 S-3(真性・n 型・p 型の 3 つのバンド図に、$E_F$ を「水位」として描いた 1 枚絵)で振り返る。「席の並び(バンド理論)+ 埋まり方(フェルミ準位)= 半導体の性質」で回収し、[pn 接合](/articles/pn-junction/)へ誘導する。

### 5.3 図3 `dos-times-f` — 席の数 × 埋まり具合

**表示するもの / 初期状態**
**同じ縦軸**($E$ = −0.4〜1.52 eV、$E_v = 0$・$E_c = 1.12$)を共有する横並びの 3 パネル(狭幅でも縦積みにしない — 縦軸の共有がこの図の要点。代わりに各パネルを細くする)。

1. **席の数 $g(E)$**: 伝導帯 $g_c \propto \sqrt{E - E_c}$、価電子帯 $g_v \propto \sqrt{E_v - E}$ を `--mat-level` の曲線で。帯域を `--mat-band` で薄く塗り、ギャップは禁制帯の破線。
2. **埋まり具合 $f(E)$ と $1 - f(E)$**: $f$ を `--mat-electron` の実線、$1-f$ を `--mat-hole` の破線。
3. **その積**: $n(E) = g_c f$ を `--mat-electron` の塗り(伝導帯の底のすぐ上の細い山)、$p(E) = g_v(1-f)$ を `--mat-hole` の塗り(価電子帯の頂上のすぐ下)。**両者を同じ倍率で規格化**し(両方の最大値のうち大きい方を 1 とする)、倍率をパネル上部に「最大値で規格化(上下の比は正しい)」と明記する。

$E_F$ の線(§2.3)は 3 パネルを貫いて引く。初期は $E_F = 0.56$ eV(真性に近い位置)、$T = 300$ K。

**操作パラメータ**

| 名前         | 部品   | 範囲                    | 初期値 | 単位 |
| ------------ | ------ | ----------------------- | ------ | ---- |
| $E_F$ の高さ | slider | −0.20〜1.32(step 0.005) | 0.56   | eV   |
| 温度 $T$     | slider | 100〜1000(step 10)      | 300    | K    |
| リセット     | reset  | —                       | —      | —    |

読み取り値: $n$ [cm⁻³]、$p$ [cm⁻³]、$np$、$n_i^2$(S6 の伏線として並べるだけで説明はしない)、「電子の山の幅」(山の 90% が収まる $E - E_c$ の範囲 [$k_BT$ 単位])。

**背後のモデルと簡略化**
放物線バンドの 3 次元状態密度 $g_c(E) = (2/\sqrt\pi)\,N_c\,(E-E_c)^{1/2}/(k_BT)^{3/2}$(価電子帯も同形)。この規格化で $\int g_c f\,dE = N_c\,\mathcal{F}_{1/2}(\eta)$ が厳密に成り立ち、読み取りの $n$ は `electronDensity` と一致する(§5.8 T5)。放物線バンドはバンド端の近く($k_BT$ の数倍以内)でだけ良い近似であり、まさにその範囲しか積に効かないので問題にならない、と図注で述べる(この図自体がその根拠を見せている)。

**実装方式**: 2D Canvas / `requestRender`。積の数値積分(400 点、$E_c$ 〜 $E_c + 20k_BT$)はパラメータ変更時のみ。

**図注(案)**: 「図3. 左から、席の数(状態密度)、その席が埋まっている確率、両者の積。積が電子(上)と正孔(下)の数を表す。積は最大値で規格化して描いたが、上下の山の大きさの比は正しい。席は上にもたくさんあるのに、積が効くのはバンド端から数 $k_BT$ の範囲だけである。」

**alt(案)**: 「同じエネルギー軸を共有する 3 枚のグラフ。左は上下の帯で根号の形に増える席の数、中央は埋まっている確率、右は両者の積で、伝導帯の底のすぐ上と価電子帯の頂上のすぐ下にだけ細い山がある。フェルミ準位を上げると上の山が大きく、下の山が小さくなる。」

**受け入れ基準**

- [ ] 読み取りの $n$ が `electronDensity` と 0.5% 以内で一致する(数値積分と解析式の整合)
- [ ] $E_F = E_i$(≈ 0.559 eV)で $n \approx p \approx 1.1\times10^{10}$ cm⁻³(300 K)

- [ ] 3 パネルの縦位置(バンド端・$E_F$)が 1px 未満の誤差で揃う

### 5.4 図4 `intrinsic-carriers` — 生成と再結合

**表示するもの / 初期状態**
左(主領域): 横軸を結晶内の位置 $x$(0〜1、無次元)、縦軸を $E$ に取ったバンド図。上に伝導帯、下に価電子帯の帯(`drawBandBox`)。価電子帯には電子の丸を格子状に敷き詰めて「満席」を表す(背景として 1 回だけ描いたオフスクリーン画像を使い回す)。伝導帯の電子(`--mat-electron`)と価電子帯の正孔(`--mat-hole`、`kind: "hole"`)が横方向にランダムに動く。

- **生成**: ある位置の価電子帯の電子が伝導帯へ縦に跳ぶ(0.15 秒の移動)。跳んだ跡に正孔が残る。
- **再結合**: 同じ位置(横方向の距離が捕獲幅以内)にいる電子と正孔が出会うと、電子が価電子帯へ縦に落ち(0.15 秒)、両方が消える。

右(幅 38%、狭幅では下): **測定グラフ** — 横軸 $E_g/k_BT$(4〜12)、縦軸 平均キャリア数(対数)。「この条件を記録」で現在の時間平均を点として打つ。**点が 3 つ以上たまってから**理論直線を重ねる。直線は**傾きを $-1/2$(自然対数で)に固定し、切片だけを記録した点に最小二乗で合わせる** — 比例定数はモデルの細部で決まるが、傾きは決まらない、という区別そのものを見せる(フランク・リード源 図6・カーケンドール 図5 と同じ「測定 → 法則の発見」の設計)。

初期は $E_g/k_BT = 5$、再生中。初期化時にシミュレーションを定常まで内部で進めておき(3000 ステップ)、最初のフレームから定常状態を見せる(省モーション時の静止フレームもこれ)。

**操作パラメータ**

| 名前                        | 部品      | 範囲            | 初期値 | 単位 |
| --------------------------- | --------- | --------------- | ------ | ---- |
| ギャップと熱の比 $E_g/k_BT$ | slider    | 4〜12(step 0.5) | 5      | —    |
| 再生 / 一時停止             | playPause | —               | 再生   | —    |
| この条件を記録              | button    | —               | —      | —    |
| リセット                    | reset     | —               | —      | —    |

読み取り値: 伝導帯の電子の数(= 正孔の数)、その時間平均(直近 900 ステップ = 15 秒)、記録した点の数、(3 点以上で)当てはめた直線の傾き。スライダーの下に固定の注記「実際の Si(300 K)は $E_g/k_BT \approx 43$ — この目盛りのはるか右」。$x \ge 10$ では平均が数個以下になり時間平均が揺らぐので、読み取りに「長めに待ってから記録」の注記を出す。

**背後のモデルと簡略化**
`lib/genrec.ts` の `GenRecSim`(純クラス・シード固定。位置は結晶の幅を 1 とした無次元):

- 時間刻み $\Delta t = 1/60$(`fixedStep` で 16.7 ms 刻み)。
- 生成: 1 ステップあたり平均 $G_0\,e^{-x}\,\Delta t$ 件(ポアソン、$x = E_g/k_BT$)の対を、一様乱数の位置に作る。電子と正孔は**同じ位置**に生まれる。
- 移動: 速度に揺らぎを与える滑らかな熱運動(オルンシュタイン=ウーレンベック過程。速さの目安 0.4/秒、方向の記憶時間 0.2 秒)。両端で反射。位置にじかに乱数を足す方式は画面上でガタつくので使わない。
- 再結合: 各電子について、捕獲幅 $w = 0.01$ 以内にいる正孔の数を $k$ とし、確率 $1 - (1 - p_c)^k$($p_c = 0.02$)で、そのうち最も近い 1 個と対消滅させる。
- この規則は、よく混ざった極限で再結合の速さが $r_\text{eff}\,n\,p$($r_\text{eff} = 2w\,p_c/\Delta t$)に厳密に比例する形に作ってある。生成とつり合うと $n = p = \sqrt{G_0/r_\text{eff}}\;e^{-x/2}$ — **指数の「2」がここで現れる**。1 ステップの移動量(約 0.007)が捕獲幅と同程度で、相手との距離は毎ステップ入れ替わるので「よく混ざった」条件はおおむね満たされる。生まれたばかりの対どうしの再結合(同じ位置で生まれるため)も起こりうるが、その割合は $x$ によらないので傾き $-1/2$ は変わらない(比例定数だけが変わる — 直線の切片を当てはめる理由)。
- $G_0$ は $x = 4$ で平均 30 個前後になるよう選ぶ($G_0 = r_\text{eff}\cdot 30^2\cdot e^{4} \approx 1180$ /秒)。このとき 1 組の寿命は約 1.4 秒で、目で追える。$x = 12$ では平均 0.5 個程度になり、「ほとんど誰もいない」状態も体験できる。
- **試作で確認済みの期待値**(本仕様の作成時に同じ規則を Python で 60000 ステップ回した結果): $x = 4, 6, 8$ で時間平均 29.5・10.8・3.97 個、$\ln n$ の傾き −0.502、寿命 1.39 秒。生まれたばかりの対どうしの再結合はこのパラメータでは無視できる程度で、比例定数まで理論と 3% 以内で一致した。実装の値がこれから大きく外れたら、規則の転記ミスを疑う。
- キャリア数の上限 400(配列は事前確保、削除は末尾との入れ替え)。

**誠実な簡略化(図注に明示)**: (1) 温度そのものではなく比 $E_g/k_BT$ を動かしている。実際の Si は 43 で、この図の範囲ではまったく足りない(生成は図より桁違いにまれ)。(2) 位置は 1 次元、時間は大きく加速している。(3) 正孔は実在の粒子ではなく、空席の集団的なふるまいを粒子として描いたもの。(4) 実際の Si の再結合は多くが欠陥を介する(間接遷移なので電子と正孔が直接出会っても光を出しにくい — バンド理論記事 S7)。ここでは「出会うと消える」最も単純な形にしている。

**実装方式**: 2D Canvas / `onFrame`(連続)。画面外・タブ非表示で停止。省モーション時は自動再生せず、定常状態の静止フレームを表示。

**図注(案)**: 「図4. 熱で電子が価電子帯から伝導帯へ上がり(生成)、電子と正孔が出会うと消える(再結合)。両者がつり合ったところで、数は $e^{-E_g/2k_BT}$ に比例する。ここでは温度の代わりにギャップと熱エネルギーの比を動かしており、実際の Si(比 43)ではこの図よりはるかにまれにしか起きない。位置は 1 次元、時間は加速している。正孔は空席のふるまいを粒子として描いたものである。」

**alt(案)**: 「上に伝導帯、下に満席の価電子帯。ときどき下の電子が上へ跳び、跡に正孔が残る。上の電子と下の正孔が同じ位置で出会うと、電子が落ちて両方消える。熱の比を小さくする(熱を強くする)と、跳ぶ回数が増えて上下のキャリアが多くなる。右のグラフには記録した条件ごとの平均の数が点で打たれ、3 点以上で理論の直線が重なる。」

**受け入れ基準**

- [ ] 電子数と正孔数が常に等しい(対で生まれ、対で消える)
- [ ] $x = 4, 6, 8$ で十分長く回した時間平均の $\ln$ が、$x$ に対して傾き −0.5 ± 0.08 の直線に乗る(§5.8 T7。乱数シード固定で決定的)
- [ ] 記録した点への当てはめ直線の傾きが −0.5 に固定され、切片だけが点に合う
- [ ] `reset` で同じ乱数列・同じ初期状態に戻る
- [ ] 中位スマホで 60fps(キャリア 400 個上限で)

### 5.6 図6 `mass-action` — 積は変わらない

**表示するもの / 初期状態**
左(幅 35%): 小さなバンド図(帯と $E_i$・$E_F$ の線)。「光を当てる」が on のときは $E_F$ の代わりに 2 本の擬フェルミ準位 $E_{Fn}$(`--mat-electron` の破線)と $E_{Fp}$(`--mat-hole` の破線)を描き、上から `--mat-beam` の短い波線の矢印 3 本を置く。
右(主領域): 縦の対数軸($10^{0}$〜$10^{20}$ cm⁻³)に 2 本の棒 — $n$(`--mat-electron`)と $p$(`--mat-hole`)— を並べ、$n_i$ の高さに水平の破線。両者の**対数の中点**($\sqrt{np}$)に小さな菱形の目印を置き、それが $n_i$ の線上にあることを示す(光を当てると線から上に離れる)。

| 温度 $T$               | slider | 200〜500(step 10)        | 300    | K    |
| 光を当てる(平衡を崩す) | toggle | —                        | off    | —    |
| リセット               | reset  | —                        | —      | —    |

読み取り値: $n$、$p$、$np$、$n_i^2$、$np/n_i^2$、多数キャリア / 少数キャリアの別、(光 on のとき)$E_{Fn} - E_{Fp}$ [eV]。

**背後のモデルと簡略化**
光 off: 与えた $E_F$ から `electronDensity`・`holeDensity`。スライダー範囲 ±0.40 eV は $E_F$ がバンド端から $6k_BT$ 以上離れる非縮退域に限ってあり、そこでは $np = n_i^2$ が 1% 以内で成り立つ(§5.8 T6)。光 on: 平衡の値に一定の過剰キャリア $\Delta n = \Delta p = 10^{14}$ cm⁻³ を足す(生成と再結合のつり合いを解かない簡略化 — 図注に明示)。擬フェルミ準位は $n = N_c\mathcal{F}_{1/2}((E_{Fn}-E_c)/k_BT)$ を $E_{Fn}$ について逆に解いて求める(`semiconductor.ts` に逆関数 `fermiLevelForElectrons` / `fermiLevelForHoles` を足す)。

**実装方式**: 2D Canvas / `requestRender`。

**図注(案)**: 「図6. フェルミ準位を動かすと、電子と正孔の数は対数目盛の上で同じだけ逆向きに動き、積 $np$ は $n_i^2$ のまま変わらない(菱形の目印が $n_i$ の線上にとどまる)。光を当てて電子と正孔を余分に作ると、積は $n_i^2$ より大きくなる — この法則は熱平衡でだけ成り立つ。過剰キャリアの量は一定値とした簡略モデル。」

**alt(案)**: 「対数目盛の縦軸に、電子の数と正孔の数の 2 本の棒。フェルミ準位を上げると電子の棒が伸び、正孔の棒が同じだけ縮み、両者の中点の目印は真性キャリア密度の線上から動かない。光を当てると両方の棒が伸び、中点の目印が線より上に離れる。」

**受け入れ基準**

- [ ] 光 off でスライダー全範囲・全温度にわたり $np/n_i^2$ が 1.00 ± 0.01
- [ ] 光 on で $np/n_i^2 > 1$、かつ $E_{Fn} - E_{Fp} = k_BT\ln(np/n_i^2)$(表示 0.001 eV 単位で一致)
- [ ] $E_F - E_i = 0$ で $n = p = n_i$、多数 / 少数の表示が「どちらでもない(真性)」になる

### 5.7 図7 `equilibration` — 接触すると揃う

**表示するもの / 初期状態**
左右 2 つのブロック(左 = 材料 A、右 = 材料 B)のバンド図を横に並べる。両者は同じ Si なので**伝導帯の底・価電子帯の頂上の高さは接触前は揃えて描く**(真空準位と電子親和力が同じ — この前提は図注に書く)。各ブロックに自分の $E_F$ の線。接触前はブロックの間に 8% の隙間。
「接触させる」を押すと `tween`(1.6 秒)で次が同時に進む: ブロックの隙間が閉じる → 接合面の付近で電子の流れを示す矢印(`--mat-electron`、$E_F$ の高い側から低い側へ)が現れて消える → 左ブロックを固定したまま、右ブロックのバンド全体が $E_{F,A} - E_{F,B}$ だけ上下に動き(正なら持ち上がる。電子を受け取った側は負に帯電して電位が下がり、電子のエネルギーが上がるため)、接合面の付近でバンドが**滑らかにつながって曲がる** → 2 本の $E_F$ が 1 本に揃う。
曲がりの形は `smoothstep` による**模式**(全幅の 30% にわたる S 字)で、正しい形は #13 で扱う。曲がりの帯は `drawBandRibbon`。
初期は**左 = p 型、右 = n 型**(#13 の全図版と同じ向き。順バイアスは左が正)、濃度 $10^{16}$ cm⁻³、接触前。このとき電子は右から左へ流れ、右ブロックのバンドが下がる。

**操作パラメータ**

| 名前              | 部品                          | 範囲                 | 初期値    | 単位 |
| ----------------- | ----------------------------- | -------------------- | --------- | ---- |
| 左の材料          | segmented: p 型 / 真性 / n 型 | —                    | p 型      | —    |
| 右の材料          | segmented: p 型 / 真性 / n 型 | —                    | n 型      | —    |
| 濃度(両側共通)    | slider(対数)                  | $10^{14}$〜$10^{18}$ | $10^{16}$ | cm⁻³ |
| 接触させる / 離す | button(ラベルが切り替わる)    | —                    | —         | —    |
| リセット          | reset                         | —                    | —         | —    |

接触中に材料・濃度を変えたら、いったん「離した」状態に戻してから新しい値で描き直す(遷移中の状態を残さない)。
読み取り値: 接触前の $E_F$ の差 [eV]、接触後の段差 [eV](接触後のみ)、電子が流れた向き(「左 → 右」など。差がなければ「流れない」)。

**背後のモデルと簡略化**
各ブロックの $E_F$ は `solveFermiLevel`(300 K)。接触後の段差 = 接触前の $E_{F,A} - E_{F,B}$(**厳密に一致させる** — この一致が本図の主張)。曲がりの形・幅・空乏層は模式であり、ここでは扱わない(図注に明示し、#13 へリンク)。

**実装方式**: 2D Canvas / `requestRender` + `tween`(P0 の `src/core/anim.ts`)。省モーション時は即座に最終状態へ。遷移が終われば描画は止まる。

**図注(案)**: 「図7. フェルミ準位の違う 2 つの Si を接触させると、電子がフェルミ準位の高い側から低い側へ移り、その結果生じた電位差の分だけバンドが曲がって、フェルミ準位が 1 本に揃う。段差は接触前のフェルミ準位の差にちょうど等しい。曲がりの形は模式で、正しい形と、曲がった部分で何が起きているかは次の記事で扱う。」

**alt(案)**: 「左に p 型、右に n 型の Si のバンド図が離れて並び、フェルミ準位の高さが違う(右の n 型のほうが高い)。接触させると、電子が右から左へ移り、右側のバンドが下がって接合面の付近で曲がり、2 本のフェルミ準位が 1 本の水平線に揃う。」

**受け入れ基準**

- [ ] 接触後の段差が、接触前の $E_F$ の差と表示桁(0.001 eV)で一致する
- [ ] 左右が同じ材料・同じ濃度なら段差 0・「流れない」
- [ ] p | n と n | p で段差の符号と流れの向きが反転する
- [ ] 既定の p | n で、接触後の右(n 側)のバンドが左より低い(#13 の図と同じ見た目)
