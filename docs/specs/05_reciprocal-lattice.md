## 1. 学習目標

読了・操作後に、読者が次のことをできるようになる。

1. 逆格子を「格子と同じ周期をもつ縞(平面波)の集合」として、1次元 → 2次元 → 3次元の順で自分の言葉で説明できる。
2. 逆格子ベクトル g_hkl が格子面 (hkl) に垂直で |g_hkl| = 1/d_hkl であることを使い、面間隔を計算できる。
3. 実格子を「回す・伸ばす・ずらす(斜交させる)」と逆格子がどう応答するか(回転は連動、スケールは逆転、b_i は a_j (i≠j) に直交)を、操作する前に予測できる。
4. 双対基底の関係 a_i·b_j = δ_ij と、3次元での構成 b_1 = (a_2×a_3)/V を説明できる。
5. 単純立方・体心立方・面心立方の逆格子の形(FCC ⇄ BCC の入れ替わり)を知り、回折図形の読解(次記事以降)への準備とする。

### 2.3 表記と慣習(記事全体の約束)

- **結晶学の慣習**を採用する: a_i·b_j = δ_ij、|g_hkl| = 1/d_hkl、波は空間周波数 q = 1/λ で表す(2π を付けない)。物理学の慣習(G = 2πg)はコラム(式 E11)で 1 回だけ言及する。エヴァルト球以降もこの慣習で続ける前提(付録 A-1)。
- 単位: 実空間 nm、逆空間 nm⁻¹。図版では両空間に必ずスケールバーを置き、単位の逆転を常に目に入れる。
- 記号と色: 探り(プローブ)に使う縞の空間周波数ベクトルは **q**(`--mat-beam`)、逆格子点・逆格子ベクトルは **g**, **b_i**(`--mat-recip`)と書き分ける。「q は連続に動かせる変数、g はその中の当たりの離散集合」という対比を、色でも一貫して支える。

各節の要旨:

**1. 結晶のもうひとつの姿** — 結晶に電子線や X 線を当てると、点が規則正しく並んだ像(回折図形)が得られる。それは原子の写真ではないのに、結晶の向き・対称性・寸法を完全に映している。図1 で実格子と点図形のペアを回し、格子定数を変えて遊ばせ、「向きは連動するのに、大きさは逆に動く」という謎を体験させる。この点の格子の正体 = 逆格子を、この記事で 1 次元から自分の手で組み立てる、と宣言して本編へ入る。

**2. 縞で格子を測る** — 周期をもつものを調べる基本は、周期をもつ「ものさし」= 縞(平面波)を当てて比べること。1 列の原子に縞を重ね、空間周波数 q = 1/λ をスライダー(または自動掃引)で動かす。すべての原子が縞の山に乗る q は 1/a の整数倍に限られる。一致した q を周波数軸に記録すると、等間隔の点列 = 1 次元の逆格子が現れる。a を縮めると点列は広がる(逆転の初体験)。原子数が有限だと一致の山に幅が出ることにも触れ、のちの回折ピーク幅への伏線とする(図注で明示)。

**3. 縞に向きが生まれる** — 2 次元では縞は向きをもつ。1 枚の縞は「法線方向を向き、長さが 1/(縞間隔) のベクトル q」で過不足なく表せる。ここが本記事最大の抽象化ステップなので、図3 の左(縞)と右(q 平面のプローブ)を同時に見せ、「矢 1 本 ⇄ 縞 1 枚」の対応を手で覚えさせる。q 平面を探検して一致点を集めると、点はとびとびの正方格子をなす — 逆格子の発見。

**4. 点は面の族** — 一致したとき、縞の山の中心線は原子の並ぶ列にぴったり重なっている。つまり逆格子点 1 つは「向きと間隔をもつ平行線(= 2 次元の格子面)の族」1 つと同じ情報である。結晶学で習うミラー指数 (hk) をここで再導入し、g_hk ⊥ (hk) 面、d = 1/|g| を読み取り値で確認する。(20) は (10) の「2 倍波」で、節 2 の n/a(高調波)と同じものだと接続する。族の中に原子を通らない線があることも隠さず見せる。

**5. 逆格子も格子** — 集めた点の全体は 2 本のベクトル b_1, b_2 の整数結合で書ける。実格子の a_1, a_2 をドラッグで変形し、(i) 回転は連動する、(ii) 伸ばすと縮む、(iii) 斜交させても b_1 ⊥ a_2, b_2 ⊥ a_1 が保たれる、を確認する。単位胞面積 S と逆単位胞面積 1/S の逆転も読み取り値で示す。ここで初めて a_i·b_j = δ_ij を定義として言葉にする(操作で得た性質の言い換えとして与える)。

**6. 3次元へ** — 縞は平面波に、平行線の族は平面の族 (hkl) になる。b_1 = (a_2×a_3)/V の構成を「a_2 と a_3 の両方に直交し、a_1 との内積が 1 になるベクトル」と読み下す。図6 の立方格子で (hkl) を選び、実空間の面の束と逆空間の 1 点の対応を回して眺める。d_hkl = a/√(h²+k²+l²) を読み取り値で検算する。

**7. 結晶が変われば逆格子も変わる** — 同じ「立方」でも、BCC と FCC では逆格子の形が変わる。FCC の逆格子は BCC 配列、BCC の逆格子は FCC 配列という入れ替わりを図7 で見る。単純立方の逆格子(全整数点)に重ねると「現れない点」があることが分かる — これが回折図形で特定の反射が消える現象(系統的消滅)として再登場することを 1 文予告する(仕組みの説明は回折系の記事に委ねる。付録 A-5)。

**8. まとめ** — 逆格子の三つの顔(① 格子と同じ周期をもつ縞の集合、② 面の族のカタログ、③ 双対基底が張る格子)を静的図 S2 で 1 枚に振り返る。最後に、回折とは「入射波と出射波の差 k′ − k が g に一致する現象」だと 1 文で予告し、エヴァルト球の記事へ渡す。

### 5.1 図1 `intro-duality` — 結晶のもうひとつの姿

**表示するもの / 初期状態**
左パネル = 実格子(選択中の 2D ブラベー格子。円形窓 半径 1.6nm 内の原子を描画。スケールバー 1nm)。右パネル = その逆格子点(|h|,|k| ≤ 4。原点 000 をひと回り大きく描く。点の不透明度は exp(−|g|²/g₀²)、g₀ = 6nm⁻¹ で外側ほど薄くする。スケールバー 5nm⁻¹)。初期は正方格子 a = 0.40nm、回転角 −15°、毎秒 +4° で両パネルが連動して自動回転する。

**操作パラメータ**

| 名前 | 部品 | 範囲 | 初期値 | 単位 |
|---|---|---|---|---|
| 回転 θ | パネル上ドラッグ + スライダー併設(双方向同期) | −180〜180 | −15 | ° |
| 格子定数 a | slider | 0.25〜0.60 | 0.40 | nm |
| 格子タイプ | segmented: 正方 / 長方(b=1.4a) / 斜交(γ=105°) | — | 正方 | — |
| 再生・リセット | playPause / reset | — | 再生 | — |

読み取り値: a と 1/a を並記(tabular-nums)。

**背後のモデルと簡略化**
逆格子点は式 E8(§6.2)で厳密に計算する(飾りではない)。点の濃淡の減衰だけは見やすさのための装飾で、回折強度ではない — 図注に明示。本図は「回折図形の模式」であり、実際の回折像に現れる強度差や消滅は扱わないことも図注に書く(装置固有の話はしない。付録 A-6)。

**実装方式**

**図注(案)**: 「図1. 実格子(左)とその逆格子(右)。ドラッグで回転、スライダーで格子定数を変えられる。点の濃淡は見やすさのための装飾で、回折強度ではない。」

**alt(案)**: 「左に原子が並んだ実格子、右に対応する逆格子の点配列。回転させると両者が同じ向きに回り、格子定数を小さくすると右の点間隔が広がる。」

**受け入れ基準**
- [ ] 回転が左右で同角・同方向に連動する
- [ ] a を半分にすると右の点間隔が 2 倍になる(読み取り値 1/a と一致)
- [ ] 長方格子で「実空間の長い方向 ⇄ 逆空間の短い方向」の反転が見える
- [ ] キーボード(スライダー・ボタン)のみで回転を含む全操作ができる
- [ ] reduced-motion では自動回転せず、再生ボタンで開始する

### 5.2 図2 `wave-1d` — 縞で格子を測る

**表示するもの / 初期状態**
上段 = 幅 10.5nm の窓に原子列(間隔 a、N 個、中央寄せ)+ 縞。縞は cos(2πqx) の山を `--mat-beam` の低不透明度(12% 目安)の帯で塗り、山の中心線を細線で重ねる。一致度 M の読み取り(百分率、tabular-nums)。
下段 = 空間周波数軸 0〜12nm⁻¹。現在の q マーカー(`--mat-beam`)と発見済みの一致点(`--mat-recip` の点)。未発見の候補位置は表示しない(発見の驚きを残す)。
初期は自動掃引モード: q が 0→12→0 を片道約 15 秒で往復し、一致点を通過するたびに点灯・記録していく。

**操作パラメータ**

| 名前 | 部品 | 範囲 | 初期値 | 単位 |
|---|---|---|---|---|
| 空間周波数 q | slider(下段マーカーと連動) | 0〜12(step 0.02) | 1.2 | nm⁻¹ |
| 格子間隔 a | slider | 0.25〜0.50 | 0.40 | nm |
| 原子の数 N | slider | 4〜20(step 1) | 12 | 個 |
| 自動掃引 | playPause | — | 再生 | — |
| すべての一致点を表示 / リセット | button / reset | — | — | — |

**背後のモデルと簡略化**
原子位置 x_j = j·a(完全格子)。一致度 M(q) は式 E2(ラウエ関数)。一致点の点灯条件: |q − n/a| ≤ 0.05nm⁻¹ かつ M ≥ 0.98。a・N を変更したら発見状態はリセットする。q = 0(一様な縞 = 変化なし)も一致点として扱い、本文で「原点も逆格子の仲間」と述べる。簡略化: 原子は 1 次元の点として描き、熱振動は無視 — 図注に明示。有限の N による一致の山の幅(≈ 1/(Na))は隠さず、「実際の回折ピークに幅がある理由の先取り」として本文と図注で触れる。

**実装方式**
2D Canvas。自動掃引中は onFrame、それ以外は requestRender。掃引中にスライダーへ触れると自動停止する。

**図注(案)**: 「図2. 原子列(間隔 a)に空間周波数 q の縞を重ねる。全原子が山に乗る q だけが下の軸に記録される。原子は点として描き、熱振動は無視している。原子の数が有限なので、一致の山にはわずかな幅がある。」

**alt(案)**: 「上に等間隔の原子列と縦縞、下に周波数軸。縞の周波数を変えると、1/a の整数倍のときだけ全原子が縞の山と一致し、軸の上に等間隔の点が並んでいく。」

**受け入れ基準**
- [ ] M は q = n/a でちょうど 100% になり、点は n/a の位置に正確に点灯する
- [ ] a を変えると点列の間隔が 1/a で再スケールされる(発見はリセット)
- [ ] N を増やすと一致の山が細くなることが M の応答で分かる
- [ ] reduced-motion では自動掃引せず、スライダー操作で 1 フレーム更新される
- [ ] 全操作がキーボードのみで可能

| すべての一致点を表示 / リセット | button / reset | — | — | — |

**背後のモデルと簡略化**
一致度 M(q) は式 E4(窓内の原子で計算)。点灯条件: 最寄りの (h/a, k/a) との距離 ≤ 0.06nm⁻¹ かつ M ≥ 0.97。「すべて表示」で |h|,|k| ≤ 3 を点灯する。円形窓による端の効果(一致の山のすその形)は物理ではなく窓の都合であることを図注で明示。a は本図では固定する(スケールの逆転は図1・図2 で学習済み。パラメータを絞って q の探索に集中させる)。

**実装方式**
2D Canvas / requestRender。縞は q に直交する平行帯の path 塗りで描く(ピクセル走査はしない)。ドラッグ 1 回あたりの再計算は約 130 原子の複素和のみで軽量。

**図注(案)**: 「図3. 左の縞は右のベクトル q 1 本で表せる。向き = 縞の法線、長さ = 1/(縞間隔)。プローブを動かして、格子と一致する q をすべて見つけよう。円い窓の縁の効果で、一致の山にはすそが出る。」

**alt(案)**: 「左に 2 次元格子と向きをもつ縞、右に q 平面。プローブを動かすと縞の向きと間隔が変わり、とびとびの位置でだけ縞が全原子と一致して、右の平面に正方格子状の点が集まっていく。」

**受け入れ基準**
- [ ] 一致点は厳密に (h/a, k/a) の位置に点灯する
- [ ] 一致時、縞の山の中心線が原子列を貫く(視認 + 一致時に中央列の原子中心と中心線の距離が 0.5px 未満)
- [ ] プローブがタッチ(44px 標的)・マウス・キーボードで動かせ、スライダーと双方向同期する
- [ ] 発見点はリセットまで保持され、「すべて表示」で |h|,|k| ≤ 3 の格子が現れる

### 5.4 図4 `planes-2d` — 点は面の族

**表示するもの / 初期状態**
左 = 正方格子(a 可変)+ 選択中 (hk) の格子線族(`--mat-recip` 60% の線。間隔 d の寸法線とラベル付き)+ 面法線方向を示す短い矢印。
右 = 逆格子点の全体(|h|,|k| ≤ 3 をゴースト表示)+ 選択点の強調と原点からの g 矢印 + ラベル g_hk。
読み取り値: (hk)、d [nm]、|g| [nm⁻¹]、d×|g|(常に 1.00 になることを見せる)。初期 (h,k) = (1,0)、a = 0.40nm。

**操作パラメータ**

| 名前 | 部品 | 範囲 | 初期値 | 単位 |
|---|---|---|---|---|
| h / k | stepper ×2(±ボタン) | −3〜3 | 1 / 0 | — |
| 格子定数 a | slider | 0.30〜0.50 | 0.40 | nm |
| 逆格子点をタップで選択 | canvas タップ(近道。キーボード経路は stepper) | — | — | — |

**背後のモデルと簡略化**
g_hk = (h/a, k/a)、d = 1/|g| = a/√(h²+k²)(式 E5・E6。正方格子)。線族は g·r = n(n ∈ ℤ)の直線群として描く。(h,k) = (0,0) では「(00) は一様成分(面はない)」という説明を表示し、線族と矢印は描かない。(20) などの高次では、原子を通らない中間の線も同格で描き、図注で「同じ向きの 2 倍波(高次の点)」と明示して図2 の n/a に接続する。

**実装方式**
2D Canvas / requestRender。

**図注(案)**: 「図4. 逆格子点 1 つは、向きと間隔をもつ格子線(面)の族 1 つに対応する。(20) では線の間隔が (10) の半分になり、原子を通らない線も族に含まれる — 図2 の 2 倍波と同じものだ。」

**alt(案)**: 「左の格子に、選んだミラー指数の平行線族と間隔 d。右の逆格子に対応する 1 点と原点からの矢印。指数を変えると線の向き・間隔と点の位置が連動し、d と g の大きさの積は常に 1 になる。」

**受け入れ基準**
- [ ] d の読み取り値が式と 0.5% 以内で一致し、d×|g| = 1.00 と表示される
- [ ] g 矢印と線族の直交が保たれる(内部検証で角度誤差 0.5° 未満)
- [ ] (20) で線間隔が (10) の半分になり、中間の線が原子を通らないことが見える
- [ ] 右パネルの点タップと stepper が双方向同期し、stepper のみでも全選択が可能

### 5.5 図5 `basis-2d` — 逆格子も格子

**表示するもの / 初期状態**
左 = a_1, a_2 の矢印(先端に `--color-accent` のハンドル)と、それが生成する格子点(窓内)、単位胞の淡い塗り。
右 = b_1, b_2 の矢印(`--mat-recip`)と逆格子点、逆単位胞の淡い塗り。
直交補助線(初期 on): b_1 と a_2、b_2 と a_1 の間に破線と直角マーク。
読み取り値: |a_1|, |a_2|, γ(a_1 と a_2 のなす角)、S [nm²]、1/S [nm⁻²]。初期は正方 a = 0.40nm。

**操作パラメータ**

| 名前 | 部品 | 範囲 | 初期値 | 単位 |
|---|---|---|---|---|
| a_1, a_2 ハンドル | canvas ドラッグ(§5.0 規約。矢印 0.01、Shift+矢印 0.05) | 各長さ 0.25〜0.60、γ 25〜155(クランプ) | 正方 0.40 | nm, ° |
| プリセット | segmented: 正方 / 長方 / 斜交 | — | 正方 | — |
| 単位胞を表示 / 直交補助線 | toggle ×2 | — | on / on | — |
| リセット | reset | — | — | — |

**背後のモデルと簡略化**
S = a_{1x}a_{2y} − a_{1y}a_{2x}、b_1 = (a_{2y}, −a_{2x})/S、b_2 = (−a_{1y}, a_{1x})/S(式 E8)。これは a_i·b_j = δ_ij(式 E7)の 2 次元での解。γ のクランプは、退化(S→0 で逆格子が画面外へ発散)を避けるための操作上の制限であり物理的限界ではないことを図注に明示する。プリセット切替は補間なしで即時反映(省モーション配慮)。

**実装方式**
2D Canvas / requestRender。開発ビルドでは毎更新時に a_i·b_j の誤差 < 1e-9 を assert する。

**図注(案)**: 「図5. 実格子の基本ベクトル a_1, a_2 をつまんで動かすと、逆格子の b_1, b_2 が応答する。b_1 は常に a_2 に直交し、伸ばすほど縮む。なす角は 25°〜155° に制限している(それ以上つぶすと逆格子が発散して画面に収まらないため)。」

**alt(案)**: 「左で 2 本の基本ベクトルをドラッグすると、右の逆格子の 2 本のベクトルが、回転には連動し、伸縮には逆向きに応答する。斜めにしても、互いに相手のベクトルとの直交関係を保つ。」

**受け入れ基準**
- [ ] 直交状態で |a_1| を 2 倍にすると |b_1| が 1/2 になる(読み取り値で確認)
- [ ] 斜交させても b_1⊥a_2, b_2⊥a_1 が保たれる(直交補助線の視認 + 内部 assert 通過)
- [ ] S と 1/S の読み取りが常に逆数関係にある
- [ ] ハンドルが Tab 巡回 + 矢印キーで操作でき、タッチ標的 44px を満たす
- [ ] reset で正方 0.40nm に完全復帰する

### 5.6 図6 `hkl-3d` — 3次元へ(three.js)

**表示するもの / 初期状態**
単一 canvas を左右 2 ビューポートに分割(renderer の scissor を使用)。
左 = 単純立方格子 5×5×5(InstancedMesh の球、`--mat-matrix`。外形の箱の稜線を細線で表示)。選択中 (hkl) の面束: 箱と交差する平面のうち中央から最大 9 枚(`--mat-recip` 12% の塗り + 縁線)。面上に乗る原子は縁取りを `--mat-recip` で強調。原点から面法線方向の矢印。
右 = 逆格子点 5×5×5(|h|,|k|,|l| ≤ 2、`--mat-recip`。000 は大きめ)+ 選択点の強調と原点からの g 矢印 + 軸ラベル(単位 nm⁻¹)。
両ビューポートのカメラ回転は連動(方位 30°・仰角 20° で開始)。読み取り値: (hkl)、d、|g|、d×|g|。初期 (hkl) = (100)、a = 0.40nm。

**操作パラメータ**

| 名前 | 部品 | 範囲 | 初期値 | 単位 |
|---|---|---|---|---|
| h / k / l | stepper ×3 | −2〜2 | 1 / 0 / 0 | — |
| 格子定数 a | slider | 0.30〜0.50 | 0.40 | nm |
| 面を表示 | toggle | — | on | — |
| 視点 | ドラッグ(慣性つき、three-helpers)+ キーボード(矢印 = 3°/押下、+/− = 10% ズーム) | 仰角 ±80° | 30 / 20 | ° |
| リセット | reset(視点・パラメータ) | — | — | — |

**背後のモデルと簡略化**
g = (h, k, l)/a(単純立方)、d = a/√(h²+k²+l²)(式 E10)。面束は g·r = n の平面群。表示は 9 枚までに制限しており、高次では族の一部しか描いていないことを図注に明示する。(000) は「面なし」のメッセージを出し、矢印・面束を描かない。原子球の半径は見やすさ優先で実寸比ではない(図注)。

**実装方式**
3D。three.js は `_shared3d.ts` 経由で動的 import する(このページで最初に three を要求する図版)。描画はダーティフラグ方式: パラメータ変更またはカメラ操作(慣性減衰中を含む)のあいだだけ onFrame 内でレンダリングし、静止したらフレームをスキップして GPU 消費をゼロにする。DPR 上限 2。

**図注(案)**: 「図6. 左の面の束と右の 1 点は同じ情報をもつ。面は中央から 9 枚までしか描いていない。原子の大きさは誇張してある。」

**alt(案)**: 「左に立方格子と選んだ (hkl) 面の束、右に逆格子点の立体配列。指数を変えると面の向き・間隔と右の 1 点が連動して変わり、ドラッグすると両方の視点が一緒に回る。」

**受け入れ基準**
- [ ] このページで three.js のチャンクが読み込まれるのは図6 への接近時が最初(Network パネルで確認)
- [ ] d・|g| の読み取りが式と一致し、面束が g 矢印と直交して見える

- [ ] キーボードのみで視点操作を含む全操作ができる

### 5.7 図7 `bravais-3d` — 結晶が変われば逆格子も変わる(three.js)

**表示するもの / 初期状態**
図6 と同じ 2 ビューポート構成・連動カメラ。
左 = 選択したブラベー格子の慣用単位胞 2×2×2 個分の原子(すべて同色 `--mat-matrix`。単一元素の格子として描く)。胞の稜線を表示。
右 = その逆格子点((h,k,l)/a、|h|,|k|,|l| ≤ 3、存在則でフィルタ)。
トグル「単純立方の逆格子を重ねる」を on にすると、全整数点を `--color-hairline` 系の微小点でゴースト表示し、「現れない点」の位置が見えるようにする(初期 off。本文が節の後半で on を促す)。
(hkl) 照会ステッパ: 指定した点が存在すれば強調、不在ならその位置に中抜きマーカーを置き、読み取り値に「この点は現れない」と表示する。初期は単純立方、照会 (hkl) = (100)。

**操作パラメータ**

| 名前 | 部品 | 範囲 | 初期値 | 単位 |
|---|---|---|---|---|
| 格子 | segmented: 単純立方 / 体心立方 / 面心立方 | — | 単純立方 | — |
| 照会 h / k / l | stepper ×3 | −3〜3 | 1 / 0 / 0 | — |
| 単純立方の逆格子を重ねる | toggle | — | off | — |
| 視点 / リセット | 図6 と同じ | — | — | — |

**背後のモデルと簡略化**
存在則 — SC: すべての整数 (hkl)。BCC: h+k+l が偶数のもののみ。FCC: h, k, l の偶奇が揃うもののみ。これは各格子の基本並進ベクトル(BCC: a/2(−1,1,1) ほか、FCC: a/2(0,1,1) ほか)から式 E9 で逆格子を作った結果と同値であり、実装は偶奇則で直接行ってよい。ただし実装時に、式 E9 由来の点集合と偶奇則の点集合が |h|,|k|,|l| ≤ 3 で完全一致することを単体テストで確認する。格子定数は a = 0.40nm 固定。強度・構造因子は扱わず、「なぜ消えるのか」は回折系の記事に委ねることを図注に明示する。

**実装方式**
3D。`_shared3d.ts`(シーン雛形・連動カメラ・InstancedMesh)を図6 と共用する。

**図注(案)**: 「図7. 体心立方の逆格子は面心立方の並びに、面心立方の逆格子は体心立方の並びになる。薄い点は、単純立方なら現れるはずの位置。なぜ消えるのかは、回折の記事であらためて扱う。」

**alt(案)**: 「左に選んだ立方格子の単位胞、右にその逆格子の点配列。体心と面心を切り替えると右の並び方が入れ替わり、重ね表示にすると現れない点の位置が分かる。」

**受け入れ基準**
- [ ] BCC 選択時に右が FCC 配列、FCC 選択時に BCC 配列になる(視認 + 偶奇則の単体テスト)
- [ ] 偶奇則と式 E9 由来の点集合が |h|,|k|,|l| ≤ 3 で完全一致する単体テストが通る
- [ ] 照会ステッパで不在点が中抜き表示され、読み取り値に不在の旨が出る
- [ ] 重ね表示 on で不在位置が視認できる
