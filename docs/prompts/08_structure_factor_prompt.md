## 2. 記事の内容(叩き台)

**記事仮題**: 「構造因子 — あるはずの反射が消えるのはなぜか」

**筋**: エヴァルト球は「どこで回折が起こりうるか」を教えてくれた。ところが実際の回折パターンを見ると、**条件を満たしているはずの反射がいくつも欠けている**。犯人は単位格子の中の原子配置である。格子点は「場所」を決めるだけで、そこに何をどう置くかは別の問題だった — 逆格子空間記事で導入した「格子 + 基底」の分業が、ここで効いてくる。

### S1. 欠けている線(導入・謎)
単純立方・BCC・FCC の粉末回折パターンを並べる。同じ立方晶なのに、BCC では (100) が無く、FCC では (100) も (110) も無い。**格子の形は同じなのに線が消える。** なぜかを問いとして立てる。

- 図1 `missing-reflections`

### S2. 格子点には何が置いてあるか
逆格子空間記事で学んだ「結晶 = 格子 + 基底」を復習する。BCC は「単純立方の格子点 + 体心にもう 1 個」、FCC は「+ 各面心に 3 個」と見なせる。**格子は同じでも基底が違う**。単位格子の中を 3D で回して見せ、原子の分数座標 $(x_j, y_j, z_j)$ を読み取らせる。

- 図2 `basis-in-cell`

### S3. 散乱波を足し合わせる — 構造因子
単位格子内の各原子が散乱した波は、**位置に応じた位相差**を持って重なる。位相差は $2\pi(hx_j + ky_j + lz_j)$。全部足したものが構造因子:

$$F_{hkl} = \sum_j f_j \exp\!\left[2\pi i\,(hx_j + ky_j + lz_j)\right]$$

複素平面上で矢印(フェーザ)を順に継ぎ足していく操作として見せる。$hkl$ を変えると矢印の向きが変わり、**きれいに打ち消し合って和がゼロになる組み合わせがある** — これが消滅の正体。本記事の中心図版。

- 図3 `phasor-sum`(中心図版)

### S4. 消滅則を自分で見つける
$hkl$ を動かしながら $|F|$ を記録していくと、規則が浮かび上がる:

- **BCC**: $h+k+l$ が奇数のとき $F = 0$
- **FCC**: $h,k,l$ の偶奇が揃っていないとき $F = 0$

読者が数式を導く前に**表を埋めて法則を発見する**流れにする(フランク・リード源記事の図6、カーケンドール記事の図5 と同じ「測定 → 法則発見」の設計思想)。発見してから、S3 の式で $\exp(i\pi n) = (-1)^n$ を使って 2 行で証明する。

- 図4 `extinction-rules`

### S5. 原子ごとの散乱能 — 原子散乱因子
$f_j$ は定数ではない。電子の数にほぼ比例し(重い原子ほど強く散乱する)、散乱角が大きいほど減衰する(電子雲の広がりのため)。**軽元素は X 線ではほとんど見えない** — 水素の位置を X 線で決めるのが難しい理由。中性子回折では事情が違う(核による散乱なので軽元素も見える)ことを一言添える。

- 図5 `atomic-form-factor`

### S6. 回折パターンを組み立てる
観測される強度は $I \propto |F_{hkl}|^2 \times m_{hkl} \times L(\theta)$(多重度・ローレンツ偏光因子)。構造・格子定数・波長を操作して、粉末パターンが組み上がるのを見せる。S1 の謎をここで完全に回収する。

- 図6 `pattern-builder`

### S7. 消えていた反射が現れるとき — 超格子反射(発展)
CuZn(β 黄銅)は高温では Cu と Zn がランダムに座る(平均すると BCC → $h+k+l$ 奇数は消える)。低温で規則化すると Cu と Zn が別々のサイトを占め、基底が変わって **消えていたはずの (100) が現れる**。規則度パラメータを動かして反射が育つのを見せる。構造因子が組織を見る道具になる、という締め。

- 図7 `superlattice`

### まとめ
「格子が場所を決め、基底が明暗を決める」で回収。カテゴリ A(逆格子 → エヴァルト球 → 構造因子)が一周したことを述べる。

## 3. この記事に固有の注意

### 色(**既存トークンのみ。新色を作らない**)

| トークン | 用途 |
|---|---|
| `--mat-matrix` | 基底の原子(A サイト) |
| `--mat-second` | 基底のもう一方の原子(B サイト・CuZn の Zn など) |
| `--mat-recip` | 逆格子点・回折スポット |
| `--mat-beam` / `--mat-beam-ink` | 入射・回折ビーム(**文字は `-ink` 側**) |

消滅した反射は「色を変える」のではなく、**描かない or 輪郭だけ**にする。存在しないものを色で表さない。

### 物理的に外してはいけない点

- **消滅則は「格子の性質」ではなく「基底の性質」である。** BCC を「体心立方格子」と呼ぶ習慣があるが、消滅則の議論では「単純立方格子 + 2 原子基底」と見るほうが正しく、この記事の主張そのものになる。ここを曖昧にしない。
- $\exp[2\pi i(hx+ky+lz)]$ の $2\pi$ の有無は、**逆格子空間記事の $\mathbf{k}$ の流儀と必ず一致させる**。`05_reciprocal-lattice.md` を確認し、仕様書に明記すること。
- $|F|^2$ が強度に比例するのであって $|F|$ ではない。図6 で取り違えない。
- 消滅則は**運動学的回折理論**の結果である。実際には多重散乱(動力学的効果)で禁制反射が弱く現れることがある(電子線回折では顕著)。図注に一言入れる。

### 実装

- 3D(図2)は `_shared3d.ts` と `lattice.ts` を**必ず再利用**する。three.js は動的 import。
- 図3 のフェーザ図は複素平面の 2D 描画。矢印は母体仕様 §6.5(線幅 2px・先端は塗り三角)に従う。
- 図1・図6 の粉末パターンは、エヴァルト球記事の `powder-rings` と計算が重なる可能性がある。**先に実装された方を `_shared/` へ昇格させて共用**する(母体仕様 §5、フランク・リード源仕様 §5.0 の前例に倣う)。
- 構造因子の計算そのものは純関数として `lib/` に切り出し、**単体テストを書く**(BCC/FCC の既知の消滅則を検証するテストは書きやすく、価値が高い)。
