## 3. 記事の内容(叩き台)

**記事仮題**: 「カーケンドール効果 — 動かないはずの目印が動いた」

**筋**: 拡散を「濃度が均される話」で終わらせない。**2 種類の原子の足の速さが違うと、格子そのものが動く**。1947 年の実験(目印のモリブデン線が動いた)を再現し、その裏で空孔が逆向きに流れていることを示し、最後に「余った空孔が集まって穴になる」= 現代のはんだ接合の信頼性問題とナノ中空粒子の合成まで繋ぐ。

### S1. 拡散 — 目的を持たない歩みが濃度を均す
原子はランダムに跳ぶだけで「濃い方から薄い方へ行こう」とはしていない。にもかかわらず濃度差が消えるのはなぜか、をランダムウォークの粒子で体感させる。跳ぶ回数を増やすと濃度プロファイルが誤差関数状に均されること、フィックの第一法則 $J = -D\,\partial C/\partial x$ が「統計の結果」であることを示す。

- 図1 `random-walk`

### S2. 原子はどうやって動くのか — 空孔機構
置換型原子は**隣が空いていなければ動けない**。空孔(vacancy)が隣に来たときだけ席を交換でき、結果として「空孔が格子中を渡り歩く」。跳躍頻度が $\exp(-Q/RT)$ で温度に強く依存すること、拡散係数 $D = D_0\exp(-Q/RT)$ を温度スライダーで体感させる。侵入型(C, N)は隙間を通るので桁違いに速い、という対比も置く。

- 図2 `vacancy-hop`

### S3. 1947 年の実験 — 目印が動いた
Smigelskas と Kirkendall の実験を再現する。銅の塊に真鍮(Cu-Zn)を接合し、界面にモリブデン線を巻いて目印にする。加熱すると、**目印が真鍮側へ動いた**。当時の常識(拡散は 2 元素が同じ速さで入れ替わる)ではこれは説明できない。「なぜ動いたのか」を読者への問いとして残す。

- 図3 `diffusion-couple`(中心図版)

### S4. 足の速さが違うと、格子が動く
$D_{Zn} > D_{Cu}$。Zn が右へ出ていく量が、Cu が左へ入ってくる量より多い。**差し引きの原子の流れ**が生じ、それを埋め合わせるように**逆向きの空孔の流れ**が起きる。空孔が消滅・生成することで格子面そのものが移動する(ラティスシフト)。目印は格子に固定されているので一緒に動く。ここが記事の核心。3 本の流束(A の流れ・B の流れ・空孔の流れ)を同じ画面で色分けして見せる。

- 図4 `flux-balance`

### S5. ダルケンの式 — 動く速さを測る
マーカー速度 $v = (D_A - D_B)\,\partial X_A/\partial x$、相互拡散係数 $\tilde{D} = X_B D_A + X_A D_B$。読者に $D_A/D_B$ 比を変えさせ、マーカー速度を測って両者の関係を確かめさせる(「測定 → 法則発見」の流れ。フランク・リード源記事の図6と同じ設計思想)。$D_A = D_B$ にすると目印が止まることを必ず試させる。

- 図5 `darken`

### S6. 余った空孔のゆくえ — カーケンドールボイド
速い方の側では空孔が過飽和になる。それが凝集すると**ボイド(空隙)**になる。これは教科書上の話ではなく、はんだ接合部(Cu/Sn)の断線や、めっき界面の剥離として現実に起きる信頼性問題である。過飽和度としきい値を操作させ、どの条件でボイドが出るかを探らせる。

- 図6 `void-formation`

### S7. 欠点を利用する — 中空ナノ粒子(発展)
ナノ粒子で同じことを起こすと、粒子の**内側が空洞**になる。これを積極的に使って中空ナノ粒子・ナノシェルを合成する手法がある。「欠陥現象が合成手段に変わる」という締め。

- 図7 `hollow-nanoparticle`

### まとめ
「拡散は濃度を均すだけでなく、格子そのものを動かす」で回収。次記事 [GPゾーン](/articles/gp-zones/) へ「では溶質が集まると何が起きるか」として誘導。

## 4. この記事に固有の注意

### 色(母体仕様 §6.2 — **既に予約済み。新色を作らないこと**)

| トークン | 用途 |
|---|---|
| `--mat-matrix` | 母相の原子(A 原子 = Cu) |
| `--mat-second` | **拡散対のもう一方の元素(B 原子 = Zn)** — 母体仕様に「カーケンドールの B 原子など」と明記されている |
| `--mat-vacancy` | **空孔**(塗りなし + `--mat-matrix` の破線縁) |
| `--mat-defect` | ボイドの縁など欠陥 |

空孔は**塗らない**(破線の輪郭のみ)。これは「そこに原子が無い」ことの視覚表現であり、全記事共通の約束。

### 物理的に外してはいけない点

- **ランダムウォークに「意図」を持たせない。** 粒子は濃度勾配を知らない。均一化は統計の結果であり、この点を実装でごまかすと記事の主張が崩れる。個々の粒子は等方的に跳ばせること。
- マーカーが動くのは**格子面が動く**からであって、マーカー自体が拡散するからではない。混同させない。
- 空孔の生成・消滅サイト(転位・粒界がソース/シンクとして働く)を無視した簡略化をしているなら、図注に明示する(母体仕様 §2-5「誠実な簡略化」)。
- 実験の史実(Smigelskas & Kirkendall, 1947, Cu/真鍮, Mo 線)は正確に記述する。参考文献に原著を挙げること。

### 実装

- 2D 格子は `src/widgets/_shared/lattice2d.ts` を**必ず再利用**する。
- 粒子数が多い図(図1・図3)は母体仕様 §8.3 に従い **1 パスでまとめ描き**。画面幅で粒子数を自動スケール。
- 乱数は**シード固定**。`reset` で完全に同じ初期状態へ戻ること(§8.2)。
- 拡散の時間スケールは現実には極めて遅い。**時間を強く加速している**ことを必ず図注に書く。
