## 3. 記事の内容(叩き台)

**記事仮題**: 「エヴァルト球 — どの反射が光るのかを決める作図」

**筋**: 逆格子は「回折が起こりうる場所の地図」だった。では実際に**どれが光るのか**。それを決めるのは入射波の向きと波長であり、その関係を一枚の作図に落としたものがエヴァルト球である。作図を手で回し、波長を変え、最後に「なぜ粉末法では環になり、電子線回折では一度に無数の点が出るのか」まで一気通貫で説明する。

### S1. 回折条件をもう一度 — ブラッグとラウエは同じことを言っている
ブラッグ則 $2d\sin\theta = \lambda$(実空間の鏡の像)と、ラウエ条件 $\Delta\mathbf{k} = \mathbf{G}_{hkl}$(逆格子の言葉)が**同一の条件の言い換え**であることを、両方の図を並べて対応付ける。逆格子ベクトルの長さ $|\mathbf{G}| = 2\pi/d$ が橋渡しになる。

- 図1 `bragg-vs-laue`

### S2. 波数ベクトルで考える
波を $\mathbf{k}$($|\mathbf{k}| = 2\pi/\lambda$)で表す。**弾性散乱なので $|\mathbf{k}_{in}| = |\mathbf{k}_{out}|$** — エネルギーが変わらない。散乱ベクトル $\Delta\mathbf{k} = \mathbf{k}_{out} - \mathbf{k}_{in}$ を作り、その先端が動ける範囲が球面になることを体感させる。ここがエヴァルト球の正体。

- 図2 `k-triangle`

### S3. 球を描く — エヴァルト球の作図
逆格子の原点 O から $-\mathbf{k}_{in}$ だけ戻った点を中心とし、半径 $2\pi/\lambda$ の球を描く。**この球面上に乗った逆格子点だけが回折する**。初期状態ではどの点も球面に乗っておらず「何も光らない」ところから始め、読者が結晶方位を回して点を球面に乗せると反射が点灯する、という体験にする。これが本記事の中心図版。

- 図3 `construction`(中心図版)

### S4. 結晶を回す — 回転結晶法
結晶を連続的に回すと逆格子が回転し、次々と点が球面を横切る。横切った瞬間だけ反射が光る。**回折は「常に起きている」のではなく「条件を満たした一瞬に起きる」**という感覚を作る。

- 図4 `rotation-method`

### S5. 波長を変える — 限界球とラウエ法
$\lambda$ を変えると球の半径 $2\pi/\lambda$ が変わる。短波長 → 大きな球 → 多くの点を拾える。半径を 2 倍した**限界球**(radius $4\pi/\lambda$)の内側だけが原理的に観測可能であることを示す。白色X線(連続波長)の場合は球が「殻」に太り、静止した単結晶からでも多数の反射が同時に出る(ラウエ法)。

- 図5 `wavelength-limiting`

### S6. 粉末法 — なぜ環になるのか
多結晶ではあらゆる方位の結晶が含まれる = 逆格子点が**原点まわりの球殻に塗り広げられる**。その球殻とエヴァルト球の交線が円になり、検出器上でデバイ・シェラー環として現れる。$2\theta$ と $d$ の対応を読者に測らせる。

- 図6 `powder-rings`

### S7. 電子線回折 — 球が平らに見えるとき
電子線は $\lambda \approx 2.5$ pm(200 kV)と極端に短く、球の半径が逆格子の間隔に比べて桁違いに大きい。その結果、**球面が逆格子面に対してほぼ平面**となり、一枚の断面上の点が一斉に条件を満たす — TEM の回折パターンが逆格子の断面図そのものに見える理由。X線と電子線で球の曲率を並べて比較する。

- 図7 `electron-vs-xray`

### まとめ
「逆格子 = 地図」「エヴァルト球 = その上を走る探照灯」で回収。次記事への誘導。

### 物理的に外してはいけない点

- $|\mathbf{k}_{in}| = |\mathbf{k}_{out}|$(弾性散乱)を破らない。球はこの制約の幾何的表現である。
- $\mathbf{k}$ の定義に $2\pi$ を含めるか否か(結晶学系 $1/\lambda$ vs 物理系 $2\pi/\lambda$)は**逆格子空間の記事と必ず一致させる**。`05_reciprocal-lattice.md` を確認し、仕様書に明記すること。
- 逆格子点は本来は数学的な点だが、実際の結晶は有限サイズなので**点は少し広がっている**(形状因子)。これがあるから厳密に球面に乗らなくても反射が出る。S4 か図注で「誠実な簡略化」として一言触れる。

### 実装

- 3D は `_shared3d.ts` と `lattice.ts` を**必ず再利用**する。カメラ操作・軸表示・ライティングを独自実装しないこと。
- three.js は動的 import(母体仕様 §4)。図3〜6 のみ 3D。
- エヴァルト球は半透明球面 + 輪郭線。**内部の逆格子点が透けて見えること**が最優先(不透明にしない)。
- 球面に乗った点は明確に強調(発光ではなく、サイズ・彩度・ラベルで区別)。母体仕様 §2-7「動くのは物理だけ」に反する演出を入れない。
