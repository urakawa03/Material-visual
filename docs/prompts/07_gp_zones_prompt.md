## 3. 記事の内容(叩き台)

**記事仮題**: 「GPゾーン — アルミが一晩で硬くなる」

**筋**: 1906 年、Wilm は焼入れしたアルミ合金を放置して週明けに測り直し、硬くなっていることに気づいた。**なぜ何もしていないのに硬くなるのか**。答えは、凍結された溶質原子が室温でひそかに集まり、転位の通り道に障害物を撒いているから。その障害物が大きくなりすぎると今度は軟らかくなる(過時効)ところまで見せ、オストワルド成長へ渡す。

### S1. 置いておいたら硬くなった(導入・謎)
ジュラルミンの発見の逸話から入る。焼入れ直後は軟らかく、室温で放置するだけで硬さが上がっていく。時効硬化曲線を先に見せて「この曲線の正体を突き止める」を記事の目標として宣言する。

- 図1 `aging-curve`(導入で提示 → S6 で回収する構成にすると効果的)

### S2. 溶けきらない量を溶かす — 溶体化と焼入れ
Al-Cu 状態図で、高温では固溶できる Cu が低温では固溶限を超えることを示す。**溶体化処理**(高温で均一固溶)→ **焼入れ**(急冷)で、本来なら析出するはずの Cu と、高温の平衡空孔濃度が**まとめて凍結**される。読者に状態図上の点をドラッグさせ、溶体化 → 焼入れ → 時効の経路をなぞらせる。

- 図2 `phase-diagram`、図3 `quench-supersaturation`

**重要**: 焼入れで凍結されるのは溶質だけでなく**過剰空孔**でもある。この過剰空孔が室温での高速な拡散を可能にしている(カーケンドール記事 S2 の空孔機構がここで効いてくる)。この接続を明示すること。

### S3. 溶質が集まる — GPゾーンの誕生
過飽和の Cu 原子が {100} 面上に**板状に集まる**。これが GP ゾーン(Guinier–Preston zone)。母相と整合(格子が連続してつながっている)なので**界面エネルギーが小さく、核生成の障壁が低い** — だから室温でも起きる。単なる「小さな析出物」ではなく「整合であること」が本質だと強調する。

- 図4 `zone-formation`(中心図版)

### S4. 整合ひずみと析出シーケンス
Cu は Al より小さいので、整合な GP ゾーンの周囲には**弾性ひずみ場**ができる。転位はこのひずみ場とも相互作用する。時間とともに GP → θ'' → θ' → θ と変化し、整合 → 半整合 → 非整合へ進む。整合性を失うと界面エネルギーは上がるがひずみエネルギーは下がる、というトレードオフを示す。

- 図5 `coherency-strain`

### S5. なぜ硬くなるのか — 切るか、迂回するか
**ここがフランク・リード源記事の直接の続き**。転位が粒子に出会ったとき、取りうる道は 2 つ:

- **せん断(cutting)**: 小さく軟らかい粒子は転位が切って通る。必要応力は粒子が大きいほど**上がる**($\propto \sqrt{r}$ 程度)
- **迂回(Orowan bowing)**: 大きい粒子は迂回する。必要応力は障害物間隔 $L$ で決まり $\tau_c \approx \mu b/L$ — **フランク・リード源記事で導いた式そのもの**

体積分率一定で粒子が粗大化すると $L$ が広がるので、迂回に必要な応力は**下がる**。2 本の曲線の**交点が最大強度** = ピーク時効。これが S1 の曲線の正体。

- 図6 `cutting-vs-bowing`、図7 `strength-vs-radius`

### S6. 時効曲線を作る
温度と時間を操作し、S1 で見せた曲線を読者自身に描かせる。高温ほど早くピークに達するが**ピークは低い**(粗大化が速く進むため)。ここで S1 の謎を回収する。

- 図1 `aging-curve` を再掲(同じ図版 ID を再利用してよい)

### S7. 硬さの峠を越えて — 過時効
ピークを過ぎると粒子は粗大化を続け、材料は軟化する。**大きい粒子が小さい粒子を食べて育つこの過程**が [オストワルド成長](/articles/ostwald-ripening/) であり、次記事へバトンを渡す。

### まとめ
「溶かして、凍らせて、ひそかに集めさせる」で回収。析出強化が材料設計の中心的な手法であることを述べ、オストワルド成長へ誘導。

## 4. この記事に固有の注意

### 色(母体仕様 §6.2 — **既に予約済み。新色を作らないこと**)

| トークン | 用途 |
|---|---|
| `--mat-matrix` | 母相の原子・格子(Al) |
| `--mat-solute` | **溶質原子(Cu)** — 母体仕様に「Al 中の Cu など」と明記されている |
| `--mat-precip` | **GP ゾーン・クラスター・析出物** — 母体仕様に「GP ゾーン」と明記されている |
| `--mat-defect` | 転位線 |
| `--mat-vacancy` | 空孔(塗りなし + 破線縁) |
| `--mat-tension` / `--mat-compression` | **整合ひずみ場の引張 / 圧縮**(図5 で使う) |

**溶質(`--mat-solute`)と析出物(`--mat-precip`)を色で明確に区別すること。** 「ばらばらの Cu 原子」と「集まって別の相になったもの」が視覚的に違うことが、この記事の理解の要になる。

### 物理的に外してはいけない点

- **GP ゾーンが低温で生成できる理由は「整合だから界面エネルギーが小さく、核生成障壁が低い」こと。** 単に「溶質が多いから」ではない。ここを外すと記事の主張が成立しない。
- **室温で拡散が進むのは焼入れで凍結された過剰空孔のおかげ。** 平衡空孔濃度だけでは室温の時効速度を説明できない。
- ピーク時効は**2 機構の競合の交点**であって、「ちょうどいい大きさがある」という曖昧な説明で済ませない。せん断応力が $r$ の増加関数、オロワン応力が $r$ の減少関数(体積分率一定のとき)であることを図で示す。
- オロワン応力は**フランク・リード源記事の $\tau_c \approx \mu b/L$ と同じ式**である。記号を変えず、同記事へリンクして「あの式がここで効く」と明示すること。
- 実在の析出シーケンス(GP → θ'' → θ' → θ)を簡略化している場合は図注に明示する。
