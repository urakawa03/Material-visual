## 2. 記事の内容(叩き台)

**記事仮題**: 「pn接合 — 電気が一方通行になる仕組み」

**筋**: n 型と p 型をくっつけるだけで、電流が一方向にしか流れない素子ができる。動く部品は何もない。フェルミ準位記事の最後で見た「接触すると $E_F$ が揃い、バンドが曲がる」——その曲がりが**坂**になり、電子にとっての上り坂と下り坂を作る。バイアスはこの坂の高さを変える操作にすぎない。

### S1. くっつける
n 型(電子が多い)と p 型(正孔が多い)を接触させる。**濃度差があるので拡散が始まる** — 電子は p 側へ、正孔は n 側へ。カーケンドール記事で学んだ拡散と同じ理屈が、ここではキャリアに対して働く。接触直後の様子から始める。

- 図1 `junction-formation`(中心図版・S1〜S3 を通して使う)

### S2. 空乏層ができる
拡散したキャリアは相手側で再結合して消える。残るのは**動けないイオン化した不純物**(n 側にプラスのドナーイオン、p 側にマイナスのアクセプタイオン)。この電荷が界面付近に取り残されて**電場**を作る。キャリアが払底したこの領域が**空乏層**。

**ここで見落としてはいけないのは、電場の向きが拡散を妨げる向きだということ。** 拡散が進むほど電場が強くなり、拡散を止めにかかる。

- 図2 `depletion-layer`

### S3. つり合いと $E_F$ の一直線
拡散電流(濃度差が押す)とドリフト電流(電場が押し戻す)が**釣り合ったところで正味の電流がゼロ**になる。これが熱平衡。このとき $E_F$ は接合を貫いて**一直線**になる —— フェルミ準位記事 S7 の回収。

$E_F$ が一直線であることと、n 側と p 側でバンド端の位置が違うことを両立させるには、**バンドが曲がるしかない**。この論理の順序を明確にする(バンドが曲がるから $E_F$ が揃うのではなく、$E_F$ が揃うためにバンドが曲がる)。

- 図1 の続き + 図3 `band-bending`

### S4. 坂の高さ — 内蔵電位
曲がりの総量が**内蔵電位 $V_{bi}$**。両側のドーピング濃度で決まる:

$$qV_{bi} = k_BT \ln\!\left(\frac{N_A N_D}{n_i^2}\right)$$

ドーピング濃度スライダーで $V_{bi}$ と空乏層幅が変わることを見せる。**濃くドープした側ほど空乏層は薄い**(電荷の総量が両側で等しくなる必要があるため)——この非対称性は必ず体感させること。

- 図3 `band-bending`

### S5. 順バイアス — 坂を下げる
p 側に正電圧をかけると、坂の高さが $q(V_{bi}-V)$ に下がる。**坂が低くなった分だけ、乗り越えられるキャリアが指数関数的に増える**($\exp(qV/k_BT)$)。電流が流れ出す。空乏層は狭くなる。

$k_BT$ が室温で 26 meV しかないため、**0.1 V 変えるだけで電流が約 50 倍**になる。この急峻さがダイオードの本質である。

- 図4 `forward-bias`

### S6. 逆バイアス — 坂を上げる
逆向きにかけると坂が高くなり、多数キャリアは越えられない。流れるのは少数キャリアによるごくわずかな飽和電流だけ。空乏層は広がる。

順逆をまとめて **I-V 特性**として描く:

$$I = I_0\left[\exp\!\left(\frac{qV}{k_BT}\right) - 1\right]$$

読者が電圧スライダーを動かすと、**バンド図・空乏層・キャリアの流れ・I-V 曲線上の動作点が同時に動く**構成にすること。これが本記事で最も価値のある体験になる。降伏(ツェナー・アバランシェ)にも簡単に触れる。

- 図5 `bias-and-iv`

### S7. 同じ構造から生まれるもの(発展)
pn接合は整流だけの部品ではない:

- **LED**: 順バイアスで注入されたキャリアが再結合し、ギャップに相当するエネルギーの光を出す。**材料のギャップが色を決める**(バンド理論記事 S7 の直接遷移が効く —— Si では光らない理由)
- **太陽電池**: 逆に、光がキャリアを作り、内蔵電場が分離して電流にする
- **トンネルダイオード**: 極端に濃くドープすると空乏層が薄くなり、トンネル効果が効く([トンネル効果とSTM](/articles/tunneling-stm/) へ接続)

- 図6 `led-solar`

### まとめ
「バンドの曲がりが作る坂」で回収。カテゴリ D(バンド → フェルミ準位 → pn接合)が一周したことを述べ、[トンネル効果とSTM](/articles/tunneling-stm/) へ誘導。

## 3. この記事に固有の注意

### 色(バンド理論記事が追加したトークンを使う。**新色を作らない**)

| トークン | 用途 |
|---|---|
| `--mat-electron` | 電子 |
| `--mat-hole` | 正孔 |
| `--mat-band` / `--mat-gap` / `--mat-level` | バンド図 |
| `--mat-solute` | ドーパント原子(イオン化したドナー/アクセプタ) |
| `--mat-beam` | **LED の発光・太陽電池への入射光**(既存トークンを使う) |

**イオン化したドナー/アクセプタ(動けない電荷)と、自由キャリア(動ける電荷)の区別**が空乏層の理解の要である。色を増やさず、**塗り(自由キャリア)と輪郭のみ(固定イオン)**で区別すること。これは空孔の表現(`--mat-vacancy` が塗りなし)と同じ発想であり、サイトの視覚言語として一貫する。

### 物理的に外してはいけない点

- **論理の順序を守る**: 「$E_F$ が揃う必要がある → だからバンドが曲がる」。逆に書くと、フェルミ準位記事で積み上げた話が台無しになる。
- **空乏層の電荷は動けない不純物イオンであり、キャリアではない。** ここを混同した図を描かないこと。
- $np = n_i^2$ は**熱平衡でのみ成立**する。順バイアス下では $np > n_i^2$ になる。フェルミ準位記事で「熱平衡で」と条件を付けたはずなので、ここで整合させること(擬フェルミ準位に軽く触れてもよい)。
- ダイオード式の $-1$ の項を落とさない。逆バイアスで $I \to -I_0$ になることが式から読めるようにする。
- **Si が光らない理由は間接遷移だから**であり、ギャップが小さいからではない。バンド理論記事 S7 と接続すること。
- 空乏層近似(急峻接合・完全空乏)は理想化である。図注に明示する(母体仕様 §2-5)。
- キャリアの動きは実際には拡散とドリフトの重ね合わせであり、個々のキャリアはランダムに動いている。**カーケンドール記事 S1 の「原子は濃度を知らない」と同じ原則**を破らないこと。

### 実装

- **バンド図は `_shared/banddiagram.ts` を再利用**し、曲がり(位置依存のバンド端)を描く機能を `_shared` 側に追加する。
- 図5 の**連動表示が本記事の肝**である。1 つの `bias` 状態から、バンド図・空乏層・I-V 動作点を同時に更新する設計にすること。3 つを別々のウィジェットにしない。
- キャリアのアニメーション(図1・図4)は粒子で表現する。粒子数は画面幅で自動スケールし、**1 パスでまとめ描き**する(母体仕様 §8.3)。乱数はシード固定。
- 空乏層幅・$V_{bi}$・I-V の計算は純関数として `lib/junction.ts` に切り出し、**単体テストを書く**:
  - 空乏層の**電荷中性**($N_A x_p = N_D x_n$)——最も価値の高いテスト
  - $V_{bi}$ がドーピング濃度に対して対数的に増えること
  - $V=0$ で $I=0$ になること
  - 濃くドープした側の空乏層が薄いこと
- $\exp(qV/k_BT)$ は順バイアスで容易にオーバーフローする。**指数の引数をクランプ**し、電圧スライダーを端まで動かして NaN・Infinity が出ないことを確認する。I-V は片対数表示も選べるとよい。
