## 2. 記事の内容(叩き台)

**記事仮題**: 「バンド理論 — なぜ銅は電気を通し、ダイヤモンドは通さないのか」

**筋**: 同じ「原子が規則正しく並んだ固体」なのに、電気を通すものと通さないものがある。組成でも密度でもなく、**電子が取れるエネルギーの並び方**が違う。自由な電子から出発し、周期ポテンシャルを少しずつ入れていくと、**ある特定のエネルギーに電子が存在できない隙間が開く** — その隙間の有無と大きさが、金属・半導体・絶縁体を分ける。

### S1. まず自由な電子から
ポテンシャルがゼロの箱に電子を入れると $E = \hbar^2k^2/2m$ の放物線。$k$ は逆格子空間記事で扱った波数そのもの。電子を下から詰めていくとフェルミ波数まで埋まる。**この段階では隙間はない** — どんなエネルギーも取れる。金属の電子がおおよそこれで説明できることを述べる。

- 図1 `free-electron`

### S2. 周期ポテンシャルを入れる — ゾーン境界で何かが起きる
原子核が周期 $a$ で並ぶと、電子波はそれを感じる。ここで**逆格子空間記事の回折条件がそのまま効く**: $k = \pm\pi/a$(ブリルアンゾーン境界)で電子波はブラッグ反射を受け、進行波でいられなくなって**定在波**になる。ポテンシャルの強さを 0 から上げていき、放物線がゾーン境界で割れる様子を見せる。

- 図2 `bragg-reflection-gap`

### S3. 2 つの定在波 — 隙間の正体
ゾーン境界では 2 つの定在波が作れる:

- **$\cos$ 型**: 電子密度の腹が**原子核の上**に来る → 引力を強く感じる → **エネルギーが低い**
- **$\sin$ 型**: 節が原子核の上に来る → 引力を感じにくい → **エネルギーが高い**

同じ $k$ なのにエネルギーが 2 通り。**この差がバンドギャップ**である。両方の波動関数と電子密度を重ねて描き、原子核の位置との関係を読者に確かめさせる。ここが記事の山場。

- 図3 `standing-waves`

### S4. 模型で確かめる — クローニッヒ・ペニー(中心図版)
周期的な井戸(または障壁)を並べた 1D 模型で、バンド構造を実際に計算して見せる。**井戸の深さ・幅・周期**を操作すると:

- ポテンシャルを深くする → ギャップが広がる
- 周期を変える → ゾーンの幅が変わる
- ポテンシャルを 0 に戻す → S1 の放物線に戻る(**連続性の確認は必ず入れる**)

許容帯と禁制帯が交互に現れる構造を、$E$ 軸の帯として同時表示する。

- 図4 `kronig-penney`(中心図版)

### S5. 折りたたむ — 拡張ゾーンと還元ゾーン
バンドは $\mathbf{k} \to \mathbf{k} + \mathbf{G}$ の周期性を持つので、第 1 ブリルアンゾーンに**折り返して**表示できる。拡張ゾーン表示 ⇄ 還元ゾーン表示をトグルで切り替え、同じものの別の描き方であることを見せる。ここで 3D のブリルアンゾーン(FCC の切頂八面体など)を出し、逆格子空間記事と接続する。

- 図5 `zone-folding`

### S6. 3 つに分かれる — 金属・半導体・絶縁体
バンドを電子で埋めていく。**埋まり方**で 3 つに分かれる:

- **金属**: バンドの途中まで埋まっている → すぐ上に空席がある → 電場で加速できる → 通す
- **絶縁体**: バンドがちょうど埋まりきり、次のバンドまでの隙間が大きい(ダイヤモンド 5.5 eV)→ 通さない
- **半導体**: 同じく埋まりきっているが、隙間が小さい(Si 1.1 eV)→ 熱で少数が飛び越える

電子数(価電子数)とギャップの大きさを操作させ、3 つの状態を行き来させる。**「通す/通さない」は電子の数ではなく空席の有無で決まる**ことを強調する。

- 図6 `metal-semi-insulator`

### S7. 本物のバンド図を読む(発展)
実際の半導体のバンド図($\Gamma$-X-L などの対称点に沿った $E$-$k$ 図)の読み方。**直接遷移**(GaAs: 価電子帯の頂上と伝導帯の底が同じ $k$)と**間接遷移**(Si: ずれている)の違いが、発光デバイスに使えるかどうかを決める。有効質量 $m^* = \hbar^2/(d^2E/dk^2)$ — **バンドの曲率が電子の「重さ」になる**ことにも触れる。

- 図7 `real-band-diagram`

### まとめ
「隙間の有無が世界を分ける」で回収。次記事 [フェルミ準位](/articles/fermi-level/) へ「では隙間があるとき、電子は実際にどこまで埋まっているのか」として誘導。

### 物理的に外してはいけない点

- **$\mathbf{k}$ の定義($2\pi$ の有無)は逆格子空間記事と必ず一致させる。** `05_reciprocal-lattice.md` を確認し、仕様書に明記する。ここがずれると読者は 2 記事を繋げられない。
- **ギャップが開く理由は「ブラッグ反射で定在波ができ、2 つの定在波が原子核とどう重なるかでエネルギーが分かれるから」**。「電子が原子に束縛されるから」といった曖昧な説明にしない。S3 が記事の核心である。
- クローニッヒ・ペニーは**1 次元の理想模型**である。実際の 3 次元結晶のバンドはこれより複雑で、対称点ごとに異なる。図注に明示する(母体仕様 §2-5)。
- 「半導体は絶縁体の一種で、境界は連続的」であること(明確な閾値はない)を述べる。1.1 eV と 5.5 eV は例であって定義ではない。
- 有効質量に触れる場合、**負の有効質量**(バンド頂上付近)が正孔の概念に繋がることを一言添えると次記事が楽になる。
- **1 電子近似**(電子間相互作用を平均場で扱う)の上に立った理論であることに、S7 か用語集で触れる。

### 実装

- **バンド計算は純関数として `lib/` に切り出し、必ず単体テストを書く。** クローニッヒ・ペニーの超越方程式の解は、ポテンシャル → 0 の極限で自由電子の $E=\hbar^2k^2/2m$ に収束する。**この極限を検証するテストは最も価値が高い**(物理の正しさを直接担保する)。
- 図4 の解法: 超越方程式 $\cos(ka) = f(E)$ を $E$ について数値的に解く。$|f(E)| > 1$ の領域が禁制帯。**根の探索は区間二分法で十分**。反復回数を固定し、フレーム内での割当てを避ける。
- 図1〜4 はいずれも**操作時のみ再描画**でよい。`requestRender` 方式にしてアイドル時の消費をゼロにする(母体仕様 §8.2)。
- 3D(図5)は `reciprocal-lattice/_shared3d.ts` を再利用。**3D を使うのは図5 だけ**にする。
- **バンド図の描画ヘルパを `_shared/` に切り出す**(冒頭の ⚠️ 参照)。軸・帯・準位線・占有の塗りつぶしを共通化し、フェルミ準位・pn接合の記事がそのまま使えるようにすること。
