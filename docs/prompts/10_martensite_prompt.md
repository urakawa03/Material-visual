## 2. 記事の内容(叩き台)

**記事仮題**: 「マルテンサイト変態 — 時間を与えないとどうなるか」

**筋**: 鋼を焼入れると硬くなる。ゆっくり冷やすと硬くならない。**違いは時間だけ**である。拡散する暇を与えないと、原子は移動する代わりに格子ごと変形して別の構造になる。閉じ込められた炭素が格子を歪ませ、それが硬さの正体になる。

### S1. 冷やす速さで別物になる(導入・謎)
同じ組成の鋼を、炉冷・空冷・水冷で冷やして硬さを測る。**組成が同じなのに硬さが数倍違う**。冷却速度スライダーを動かして硬さの変化を体感させ、「時間が何を変えているのか」を問いに立てる。

- 図1 `cooling-rate`

### S2. 炭素が逃げられない
高温のオーステナイト(FCC)は炭素をよく溶かすが、低温のフェライト(BCC)はほとんど溶かせない。ゆっくり冷やせば炭素は拡散して外へ出て、炭化物(セメンタイト)になる。**急冷すると炭素は動く時間がなく、その場に閉じ込められる**。カーケンドール記事 S2 の跳躍頻度 $\propto \exp(-Q/RT)$ を使い、温度が下がると跳躍が事実上止まることを示す。冷却速度と「炭素が動ける距離」を並べて見せる。

- 図2 `carbon-trapped`

### S3. 原子を運ばずに構造を変える — ベイン対応
では炭素が動けないのに、どうやって FCC から BCC になるのか。答えは**格子そのものを変形させる**こと。FCC の中には、少し潰れた正方晶(BCT)が既に埋まっている — それを $z$ 方向に縮め $x,y$ 方向に伸ばすと BCC になる(ベイン対応)。**原子は隣の原子との関係を保ったまま、全体で協調的に動く**。変形量スライダーで FCC → BCT → BCC を連続的に見せる。3D 補助図が最も効く箇所。

- 図3 `bain-distortion`

### S4. 音速で進む — 無拡散変態
この変態は熱活性化ではないので、**温度を下げたその瞬間に進む**。$M_s$(変態開始温度)以下で始まり、$M_f$ で終わる。**変態量は温度で決まり、その温度に保持した時間では増えない** — ここが拡散変態との決定的な違い。温度スライダーを上下させ、「保持しても進まない」ことを読者自身に確かめさせる(保持時間スライダーを付けて、動かしても何も起きないことを体験させるとよい)。

- 図4 `athermal-transformation`

### S5. 形が変わる — 表面起伏と自己調整
せん断を伴うので、変態した領域は**表面に起伏を作る**(研磨した面が盛り上がる。これが無拡散変態の古典的な証拠)。一方、周囲の母相はその変形を拘束するため、マルテンサイトは**互いのひずみを打ち消す向き**にラス状・レンズ状に組み合わさって成長する(自己調整)。この組織の成り立ちを見せる。

- 図5 `shape-change`

### S6. なぜ硬いのか
硬さの主因は複数あり、**炭素だけでも転位だけでもない**:

1. **過飽和炭素による正方晶ひずみ** — 閉じ込められた C が BCT の $c/a$ を 1 より大きくし、格子を歪ませる。炭素量と $c/a$ の関係を見せる
2. **高密度の転位・双晶** — 変態で導入される。転位が動きにくい
3. **微細な組織** — ラス境界が障害物として働く

炭素量スライダーで $c/a$ と硬さの関係を確かめさせる。**炭素の無い鉄(純鉄)を焼入れても硬くならない**ことを試させると効果的。

- 図6 `tetragonality-hardness`

### S7. 硬すぎるものを使えるようにする — 焼戻し
焼入れままのマルテンサイトは硬いが脆く、そのままでは使えない。**焼戻し**(再加熱)すると炭素が動けるようになり、微細な炭化物として析出する。硬さは下がるが靭性が上がる — **硬さと靭性のトレードオフ**を温度スライダーで探らせる。締めとして、可逆なマルテンサイト変態が形状記憶合金(Ni-Ti)の原理であることに触れる。

- 図7 `tempering`

### まとめ
「拡散に頼らず組織を変える」で回収。カテゴリ C が「拡散で変わる話」から「拡散させない話」まで一周したことを述べる。

## 3. この記事に固有の注意

### 色(**既存トークンのみ。新色を作らない**)

| トークン | 用途 |
|---|---|
| `--mat-matrix` | 鉄原子・母相の格子 |

| `--mat-defect` | 変態で導入される転位・双晶境界 |
| `--mat-tension` / `--mat-compression` | 正方晶ひずみ・変態ひずみ場の塗り |

炭素に `--mat-solute` を使うのは**コットレル雰囲気記事と同じ**であり、読者は既にこの色を「侵入型の炭素」として学んでいる。必ず踏襲すること。

### 物理的に外してはいけない点

- **無拡散(diffusionless)であることが記事の核心。** 原子が「入れ替わる」描画をしてはいけない。隣接関係を保ったまま格子が変形する、という描き方を厳守する。図3 の実装で原子をランダムに動かすと記事の主張が崩れる。
- **変態量は温度で決まり、時間では決まらない**(athermal)。図4 で保持時間を動かしても変態が進まないことは、バグではなく物理である。実装者がこれを「動かないバグ」と誤解しないよう、仕様書に太字で書くこと。
- ベイン対応は**格子対応の説明**であって、実際の原子の経路そのものではない。実際の変態には格子不変せん断(すべり・双晶)が伴い、現象論的結晶学理論(PTMC)で記述される。**教育的簡略化であることを図注に明示**する(母体仕様 §2-5)。
- $c/a$ と炭素量の関係は実測に基づく経験式がある。数値を出す場合は出典を参考文献に挙げること。
- 「マルテンサイト」は鋼に限らない(Ni-Ti、ZrO₂ など)。鋼を例に説明するが、一般的な変態様式であることを一言添える。

### 実装

- 2D 格子は `src/widgets/_shared/lattice2d.ts` を**必ず再利用**する。
- 図3 の 3D は `reciprocal-lattice/_shared3d.ts` を再利用する。three.js は動的 import。**この記事で 3D を使うのは図3 だけ**にし、他は 2D に留めること(バンドル肥大を避ける)。
- 図2 の拡散距離の計算($\sqrt{Dt}$ と冷却曲線の積分)は純関数として `lib/` に切り出し、**単体テストを書く**。
- 冷却曲線・変態量($M_s$ からの Koistinen–Marburger 式など)も同様にテスト可能な純関数にする。
- 時間スケールは実際の焼入れ(秒オーダー)と焼戻し(時間オーダー)で桁が違う。**加速率が節ごとに変わる**ことを各図注に明示する。
